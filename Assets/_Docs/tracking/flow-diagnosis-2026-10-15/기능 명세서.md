# 기능 명세서

## 목표
사용자가 수동 변경한 현재 씬·프리팹 기준으로 Bootstrap → Title → Core+Stage → 플레이어 생성 → 카메라 준비 → Playing 및 Ending 복귀 연결을 재점검한다.

## 참고
공식 Unity MCP의 기존 실행 로그, 네 통합 씬 Preview, 실제 플레이어 prefab/설치/Entry/연출/대화/소리 자산, AppComposition/GameFlowService/SceneService/SessionActorHost/GameRuntimeService/CoreWorldBinding/StageService/LevelCameraService, 최신 사용자 지시 및 planning-index.

## 제약
읽기 전용 검수. 제품 코드·씬·프리팹·설정·Git 변경 없음. Play/Player/물리 시뮬레이션 실행 없음. Preview는 검사 후 닫고 사용자의 일반 편집 씬은 열거나 닫거나 저장하지 않는다. 설치·Entry의 내부 경로 갱신 검증은 임시 복제본에서 수행한다.

## 완료 기준
과거 실행 실패와 현재 상태를 구분한다. 실제 연결/진입/Stage/대화/연출 계약을 검사한다. 미해결 구조 문제와 실행 확인 한계를 코드 리뷰·검증에 기록한다. 과거 성공 또는 정적 검사로 전체 실행 성공을 선언하지 않는다.
