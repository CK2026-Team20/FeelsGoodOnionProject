## 중간 실패를 구분한 기록

첫 migration은 씬 저장 뒤 비어 있던 초기 SceneManagerSetup 복원에서 실패했다. 유효한 초기 setup이 있는 경우만 복원하도록 수정하고 재실행 성공했다. 첫 검증 helper의 폐기 EntityId API 및 ephemeral 타입 JsonUtility 역직렬화 문제를 수정했다. 검증에서 남아 있던 self 정렬8개를 찾아 native로 수정한 뒤22개 모두 통과했다. 마지막 scene-verification.json만 최종 성공 증거다.

## 사람이 확인할 실제 기능

다음은 미실행이며 자동 통과로 표시하지 않는다.

1. 얇은 시작 트리거에 진입하면 저장 후 추격이 한 번 시작한다. 문에 몸이 겹치면 시작이 보류되고 안전해진 접촉에서 수락한다. 전신 시작선 투영은 없다.
2. 점프·정지·역방향 이동·높은 이동 속도에서 전면 Box 포획과 공통 사망이 한 번만 발생한다. Options/메모 정지에서는 이동·포획을 멈춘다.
3. 재시도에서 적 초기 배치·기절·기믹·퇴로가 초기화되고 마지막 위치/조각/해금 세 값과 일반 완료 대화 장부가 보존된다.
4. 추격 트리거의 일시 비활성/재활성으로 문이 열리거나 현재 Actor 연결이 소실되지 않는다.
5. 포포 접촉과 포획이 겹치면 포획이 우선한다. 최종 대화 Completed/Skipped는 Ending 한 번, 취소·낡은 callback은 거절한다.
6. 제공된 실제 애니메이션 클립을 연결한 뒤 재생·블렌드·카메라 전환과 전체 한 판을 확인한다.

이 문서는 프로그래머의 검증 범위 기록이다. 별도 QA/FunQA 평가 문서를 작성하지 않았다.
