# 테스트 및 검증 항목

2026-11-03 공식 Unity eval_file로 실제 DialogueRoot 프리팹을 PreviewScene에 복제해 실행. 실제 DialogueService/ViewModel/View를 연결하며 표시 대상 History는 검증 데이터로 주입했다. 대화 전체 진행 테스트로 해석하지 않는다.

결과: 42개 assertion 통과.

- 연속 어니/포포 포함 8행: 좌우 앵커, Frame 0/180도, 정방향 텍스트.
- Scrollbar 값 0/0.5/1 → 실제 내용 normalizedPosition 일치.
- 내용 위치 0.25/0.75 → 핸들 값 일치.
- 실제 ScrollRect.LateUpdate 및 Canvas.ForceUpdateCanvases 후 size 0.2 유지.
- Scrollbar OnPointerDown/OnBeginDrag/OnDrag/OnPointerUp 이벤트로 상단에서 하단 이동 확인.
- 빈 기록·1행 기록에서도 size 0.2 및 행 개수 확인.
- 닫기/다시 열기 중복 없음, 같은 VM 재바인딩 후 Unbind가 자기 Canvas 구독과 생성 행을 해제함.
- 1920x1080 PreviewCamera 렌더 이미지를 직접 열어 연속 화자, 우측 회전 프레임, 정방향 글자 및 상단 핸들 위치 확인.
- 컴파일 실패 없음. Tutorial은 미저장 그대로이며 Play 실행 안 함.

증거: output/Tech_SYM/DialogueLog20261103/verify.cs, checks.json, preview.png.

중간 확인: 초기 EditMode fixture에서 OnEnable 기반 콜백이 실행되지 않아 크기 검사가 실패했고, 구독 소유권을 Bind/Unbind로 일치시킨 뒤 재검사했다. 화면 캡처 fixture의 Canvas 누락도 보완했다. 최종 42개는 수정 후 실행 결과다.

한계: 자연 마우스 입력으로 본편 전체 Play 및 Player 빌드 검증은 하지 않았다. 이번 검증은 실제 Unity 컴포넌트/API 이벤트, 레이아웃, 카메라 렌더 기반이다.
