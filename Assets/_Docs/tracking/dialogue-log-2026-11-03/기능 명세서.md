# 대화 로그 화자 배치와 고정 핸들

2026-11-03 사용자 직접 지시.

목표: 어니는 왼쪽, 포포는 오른쪽 버블로 표시한다. 포포 프레임만 기존 Sprite를 Z축 180도 회전하며 텍스트는 정방향을 유지한다. 같은 화자의 연속 대사도 같은 쪽에 표시한다. Scrollbar.size는 0.2로 유지한다.

참고: Cooked!_UI기획서Ver2.1.pdf 21·31쪽, planning-index.md, DialogueView / DialogueViewModel / DialogueService, Assets/_Prefabs/UI/Dialogue/DialogueRoot.prefab.

제약: 원본 Sprite 복제·수정 없음. 로그 공개/자동 진행/완료 규칙은 기존 VM과 Service에 유지. Tutorial 미저장 씬 저장·재로드 없음. 프리팹 재생성·Apply 없음.

구현: View의 행 순번 교대 배치를 화자 이름 기준으로 변경한다. 포포 이외의 화자는 왼쪽으로 표시한다. Bubble 컨테이너 아래 Frame과 Text를 분리한다. ScrollRect의 값/기존 이벤트 연결은 유지하고 LateUpdate 및 Canvas 레이아웃 갱신 후 핸들 크기만 고정한다. Canvas 구독은 Bind/Unbind에서 소유·해제한다. 프리팹 Scrollbar 직렬화 값도 0.2로 저장한다.

완료 기준: 실제 프리팹 기반 화자·프레임·텍스트 검사, 핸들/내용 양방향 위치 연동, 드래그 이벤트, 빈/짧은 기록, 재열기·구독 해제, 실제 렌더 이미지 검토 및 컴파일 확인.
