# 코드 리뷰

- DialogueView의 표시 책임 안에서 변경. VM/Service의 도메인 규칙 변경 없음.
- 순번이 아닌 Name의 포포 일치 여부로 우측 정렬. 어니 연속/포포 연속 검사 포함.
- Frame은 중앙 피벗에서 180도 회전하며 Text는 형제라 회전을 상속하지 않음. 원본 Sprite 참조/원본 픽셀 크기 보존.
- ScrollRect의 normalizedPosition, Scrollbar.value, 기존 onValueChanged 연결을 재구현하지 않음. 크기 고정만 추가.
- CanvasUpdateRegistry 초기화 후 Canvas 렌더 콜백 등록으로 레이아웃 갱신 이후 적용. 실행 순서100으로 기본 ScrollRect LateUpdate 이후에도 반영.
- Bind의 기존 중복 방지와 Unbind의 자기 이벤트 해제 유지. 재바인딩 후 해제 검사 통과.
- 사용자 씬 미저장 상태 보존. 기존 누적 Git diff와 이번 순변경은 구별해야 함. 커밋/push 없음.
