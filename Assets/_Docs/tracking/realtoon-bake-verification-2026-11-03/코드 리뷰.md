# 검증 구성 리뷰

제품 코드는 변경하지 않았다. 공식 Unity CLI eval과 capture_game_view를 사용했다. Unity 6000.6.0f1, PC_RPAsset, Universal Render Pipeline/RealToon/Version 5/Default/Default 환경이다.

실제 프리팹의 Mesh와 원본 Material 참조를 사용했다. 메시 복사본에 UnityEditor.Unwrapping.GenerateSecondaryUVSet을 적용했으며 원본 126정점/UV2 0에서 복사본 144정점/UV2 144가 됐다. 양쪽 동일 복사본을 사용하고 대조군만 URP/Lit으로 교체했다. 표현 크기는 최대 축 3m로 통일했다. 제품 배치 품질 검증이 아닌 셰이더/베이크 호환성 검증이다.

환경광 검정, Skybox 없음, Fog 없음. Baked Directional Light 색 (1,0.55,0.25), 강도2, 회전 (50,-30,0). UnityComputeGPU, 16 texels/m, 최대512, direct/indirect/environment samples 각32. 비교 촬영에서 광원 비활성, 동일 카메라/해상도1000x600. 원본 머티리얼의 Receive Environmental Lighting and GI=1, Environmental Lighting Intensity=0.5 유지.

최초 helper 컴파일에서 ReceiveGI 네임스페이스와 lightmapCompression 타입 오류가 있었고 실행 전 수정했다. 실제 베이크 실행은 수정된 코드로 성공했다. capture 도구가 경로 앞에 Assets를 붙이므로 캡처 파일을 정규 output 경로로 옮기고 임시 폴더를 제거했다.
