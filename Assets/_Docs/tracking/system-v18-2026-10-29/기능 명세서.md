# V1.8 시스템 기획서 교체 명세

2026-10-29 / 문서 작업

## 목표와 기준 자료

Desktop의 `Cooked_시스템_기획서_V.1.8.docx`를 내용 변경 없이 `Assets/_Docs/`에 등록한다. 시스템 동작은 V1.8 활성 본문이 이전 사용자 기능 명세와 기존 구현보다 우선한다. 루트 AGENTS·CLAUDE, planning-index, 공통 문서와 관련 지역 지침을 함께 갱신한다.

원본 SHA-256: `783e356d9ec55552867c821fac37cd364aab6310c44895c9998f5642357ff4e4`.

비교 자료는 현재 OptionsService, GameFlowService, CinematicView, StageTrigger, StageService, LevelCameraService, ChaseRuntimeDriver, 저장된 Title 씬과 TitleUiRoot다. 본문의 색상·취소선과 수정 이력을 별도로 읽으며 V1.7의 이미지 내부 텍스트를 V1.8 요구로 적용하지 않는다. 타이틀 배경 효과·전환 연출·BGM 등의 추후 확정 문구는 미정으로 남긴다.

## 범위와 제약

- V1.6 DOCX와 대응 메타만 제거한다. Desktop 원본, UI·레벨 원본, 역사적 검증 기록은 보존한다.
- 삭제 문서의 과거 Markdown 링크는 삭제 전 Git blob으로 연결한다. 과거 버전명·결과·허가를 일괄 V1.8로 바꾸지 않는다.
- 시스템 명세의 변경은 게임 코드·씬·프리팹 변경 허가가 아니다. 현재 구현 사실과 목표 요구를 구별한다.
- 파일 소유권·공식 Unity 도구 사용·미저장 편집 보호를 유지하며 Git 커밋·push·브랜치 변경은 수행하지 않는다.

## 완료 기준

원본과 복사본의 바이트·SHA-256 일치, V1.6 DOCX·메타 제거, 현행 V1.6 우선 문구와 삭제 파일 로컬 링크 해소, 5개 구조 차이의 현재 소스 근거 기록, 문서 외 기존 파일의 작업 시작 대비 불변을 확인한다. 실행하지 않은 Play·빌드·컴파일·Editor import를 통과로 적지 않는다.
