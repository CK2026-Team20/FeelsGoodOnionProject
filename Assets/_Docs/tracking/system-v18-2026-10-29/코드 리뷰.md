# V1.8 문서 교체 리뷰

2026-10-29 / 코드 수정 없는 정적 문서 리뷰

## 검토 결과

- 원본 내용은 편집하지 않고 전체 파일을 복사했다. V1.6 제거는 DOCX와 대응 메타에 한정한다.
- 현행 권위는 V1.8 활성 본문으로 정정했다. 과거 HMS 12파일 수정 허가와 날짜별 검증은 과거 버전을 유지한다.
- 컷신 복귀 금지·경계 제거·최신 전환 우선·접촉/직선/몸체 포획은 목표 요구에서 제외했다. architecture·contracts의 실제 코드 설명은 미반영 표시를 붙여 보존했다.
- OptionsService의 버튼 허용 조건뿐 아니라 GameFlowService의 busy 및 상태 거절을 함께 확인했다. 타이틀의 별도 씬 존재와 3D 배경 존재를 구별했다.
- CinematicView의 분리된 이미지·텍스트는 이미 일치한다. V1.7의 폐기된 변경 이력을 새 작업으로 적용하지 않았다.

## 변경 경계

게임 코드/API·씬·프리팹을 수정하지 않았다. UI·레벨·Desktop 원본과 기존 미커밋 변경은 작업 시작 시 해시와 비교한다. 루트 AGENTS와 CLAUDE는 동일한 내용이다. 역사적 기록은 삭제된 문서의 링크 대상만 Git 이력으로 수정하고 결과·버전은 유지한다.

## 남은 구현 검토

[구조 차이 목록](구조%20차이%20목록.md)의 5건은 미구현이다. 향후 구현에서는 컷신 취소 후 낡은 완료 콜백, 옵션의 시간 정지 해제, 전환 중 새 트리거 수락, 전신 통과의 방향·재진입, 경로 거리 포획과 동시 사망 우선순위를 검증해야 한다. 이번 문서 리뷰를 실행 테스트 통과로 취급하지 않는다.
