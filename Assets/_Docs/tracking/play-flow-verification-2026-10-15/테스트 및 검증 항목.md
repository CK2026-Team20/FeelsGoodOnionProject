# 실제 Editor Play 검증

2026-10-15. 공식 Unity 플러그인의 editor_play/editor_stop/eval로 Unity 6000.6.0f1 Editor의 실제 프레임·물리·코루틴·UI 바인딩을 실행했다.

트리거·발판에는 런타임 Rigidbody 이동으로 시작 조건을 만들고 실제 OnTrigger/OnCollision 및 FixedUpdate를 관찰했다. UI는 연결된 실제 Button.onClick, 메모·사망·점프는 공개 유스케이스/API를 실행했다. GameView 포커스가 확보되지 않아 합성 Keyboard 이벤트가 Reader에 전달되지 않았으며 자연 키보드/마우스 조작 검증으로 집계하지 않는다. 테스트 배치는 저장하지 않았고 Application.runInBackground=true도 런타임에만 설정했다.

초기 조사 중 Play 종료 후 Unity GameObjectInspector/TransformInspector의 파괴된 선택 대상 예외가 2쌍 발생했다. 제품 런타임 예외와 구분하고 선택을 정리했다. 최종 구간에는 재발하지 않았다. 과거 Console 오류는 삭제하지 않았다.

직접 PlayerFacade.ForceDeath는 Bridge의 사망 관찰 시작을 우회하므로 정상 경로 사망 검사로 채택하지 않았다. 메모 닫기 명령 직후에는 애니메이션 중이어서 정지 상태이며 완료 후 해제를 확인했다. 정지 중 사망 요청 거절도 기존 계약이다.
