# 기능 명세서

2026-10-15 최신 직접 지시로 기존 Play/Player 금지를 철회한다. 목표는 실제 Editor Play에서 씬 흐름을 검증하고 재현되는 원인을 해결하는 것이다.

참고: 최신 기획과 사용자 수동 변경, 네 통합 씬, 실제 실행 로그 및 Flow/Core/Stage/Actor/UI 소스.
후속 범위: 체크포인트에 지정된 Quarter/Side 시점을 실제 저장 접촉 시 적용하고 재시도와 일치시킨다. 선형 이동 발판의 상승·하강·반전 탑승 유지와 점프 이탈을 실제 물리 스텝으로 검증한다. 카메라가 트리거를 감지하는 구조가 아니라 현재 플레이어의 StageTrigger 접촉이 요청을 전달한다.
제약: 공식 Unity 플러그인, 미저장 작업 보호, 소유권/보호 원본 권한 유지. Git 작업은 실행하지 않는다. 관련 없는 씬 배치/밸런스 변경은 제외한다.
완료 기준: 실제 Play 진입, Title/NewGame, 오프닝, Playing, 체크포인트/사망 재시도, 메모/옵션, 최종 대화/Ending/Title 복귀를 가능한 범위에서 검증한다. 자연 입력·물리와 테스트를 위해 직접 호출/이동한 경로를 구분한다. 실패·미검증을 명시하고 종료 후 원래 편집 상태로 복귀한다.
