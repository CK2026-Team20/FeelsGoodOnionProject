# 프레임 루프 정리 기능 명세서

## 목표와 근거
사용자 직접 지시: Update/FixedUpdate 및 관련 프레임 호출에서 불필요한 계층 탐색과 반복 무결성 검사를 확인하고 제거한다. 선행 적 수정(눈물 조각/레벨 계층 탐색 금지)을 유지한다.

## 참고 범위
Assets/_Code의 Update/FixedUpdate/LateUpdate 39개(SYM 25, HMS 14), 호출되는 서비스·속성·붕괴 코루틴, 렌더 콜백 OcclusionFadeController를 확인했다. Assets/RealToon/RealToon Tools의 콜백 7개도 읽기 전용으로 분류했다. Packages/Library/Plugins의 엔진·외부 패키지 내부 전체는 이번 자체 게임 코드 전수 점검에 포함하지 않는다.
공통/모듈 AGENTS, planning-index, standards, engineering-notes와 실제 소스를 기준으로 판단했다. 기능 확대나 V1.8 미구현 추격 시스템의 재작성은 범위가 아니다.

## 제약
- 수정은 Tech_SYM 코드 11파일과 작업 기록. 씬/프리팹/HMS/RealToon/아트 원본은 수정하지 않는다.
- 초기 배치 검사는 준비 시점에 유지하되 매 프레임 반복하지 않는다.
- 실제 접촉·방향·거리·시야·피해·정지·세대·애니메이션 완료 판정은 보존한다.
- 계층 재검색 서비스, 전역 캐시, 무효화 프레임워크를 추가하지 않는다.
- 앵커의 현재 월드 위치는 계속 읽는다. 런타임의 고정 연결 재배치/컴포넌트 교체를 계속 검증하기 위한 검색은 하지 않는다.
- Git commit/push 없음. 기존 사용자 변경을 되돌리지 않는다.

## 변경
1. LinearShuttlePlatform/PressureLinkedPlatform: 매 물리 스텝의 IsFixedPoint 경로 제거. 준비·복구 검사는 유지.
2. KinematicPlatformMotion: 같은 효과 소유자 재등록 시 HasTravelDriver의 반복 GetComponent 검사 생략.
3. PlatformPresentation: Controller 레이어/상태/파라미터 검사는 재생 요청 시 1회. 관찰에서는 생존·Controller 교체·실제 상태 진행을 확인하고 클립 List를 재사용.
4. ChaseRuntimeDriver: 준비 시 검사한 Box 구성 검사를 Advance에서 제거. 물리 포획 로직은 그대로.
5. InteractionPromptAnchor: 고정 앵커 계층/씬 검사와 IInteractable 연결은 Awake에서 수행. 활성/파괴 상태와 현재 위치는 실시간 반영.
6. PlayerInteractionService: 방문 대상 HashSet, 완료 장치 List 재사용. 진행 장치가 없으면 정리 즉시 반환. 사용 후 참조 해제.
7. EnemyContactSensor: 비어 있는 접촉 조기 반환, 접촉 제거 Predicate 재사용. 실제 교차 검사와 피해 횟수 계약 유지.
8. DebugPanelSession/ViewModel/DebugLogBuffer: 숨김 중 주기 갱신 중단, F1 열기 1회 갱신, 로그 revision이 같으면 ToArray/문자열 조합 생략.

## 완료 기준
컴파일 오류 없음, 격리된 실제 Unity 컴포넌트 검증, 변경 diff 검토, 콜백 분류 및 보호 원본 발견 사항 기록. 실제 Play 프로파일 전후 측정은 별도이며 자동 검증을 FPS 개선량으로 환산하지 않는다.
