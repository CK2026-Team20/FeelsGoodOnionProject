# 코드 리뷰

제품 C# 로직 변경은 없다. Unity 공식 도구의 LoadPrefabContents/SerializedObject/SaveAsPrefabAsset로 지정한 프리팹만 갱신했다. Pot/Burner/DamagePot은 m_Script 교체로 기존 컴포넌트 local fileID를 보존했고 실제 native 타입과 직렬화 타입명을 확인했다. 루트의 공통 DamageFloorPlatform은 하위 플랫폼을 관리하지 않으며 비어 있는 감지영역 때문에 불필요한 후보였다.

사용자 답변에 따라 묶음 참조의 NULL은 작성 의도로 취급한다. PeriodicPlatforms의 supportCollider/motion을 채우지 않았고 씬에서 고른 Rigidbody·Collider를 원본에 올리지 않았다. Gratan에는 이미 자기 자식으로 존재하던 Trigger 두 개만 연결했으며 물리 형상은 수정하지 않았다.

프로토타입의 개별 피해 추가/제거 override를 원본 상속으로 정리하려던 보조 검사는 Gratan override 복원 실패로 중단하고 저장 없이 폐기했다. 사용자 요구는 원본 공통 설정 반영이므로 불필요한 씬 재작성으로 확대하지 않았다. 최종 프로토타입 파일은 바이트 동일하고 기존 override25개는 유지한다. 최종 preview 재열기에서 Missing Script·동일 오브젝트 피해 중복·공통 legacy 타입·잘못된 감지영역0을 확인했다.

다른 작업의 DirectSceneTestSettings.cs, GlobalUiRoot.prefab, Tech_SYM/Prefabs/PeriodicPlatform.prefab과 Recovery는 건드리지 않는다. 프리팹을 저장하면서 현재 클래스에 없는 폐기 필드가 제거되거나 기본 필드가 직렬화된 차이는 기록하며 임의 YAML 편집은 하지 않는다.

독립 읽기 전용 검토에서도 대상6프리팹 변경·component fileID/GUID·작성 슬롯·보호 파일·프로토타입 원본 보존을 재대조했고 차단 항목은 발견하지 못했다.
