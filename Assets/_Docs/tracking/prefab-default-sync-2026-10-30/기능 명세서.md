# 프리팹 공통 설정 반영

2026-10-30 최신 직접 지시. 목표는 프로토타입에서 확정한 재사용 설정을 원본에 반영하되 씬 참조·아트·기존 배치를 보존하는 것이다.

## 확정된 작성 의도

- 묶음 프리팹의 빈 Collider/Rigidbody 참조는 사용할 메시를 고른 뒤 사용자가 드래그해 연결하는 슬롯이다. 첫 번째 자식을 임의 선택하거나 프로토타입 선택값으로 채우지 않는다.
- StageTriggerPoint 기본 종류는 체크포인트다. 소속 Stage·독립 Host·추격 무리/퇴로와 같은 씬 참조는 비워 둔다.
- Gratan은 기존 DamageablePlatforms 묶음 안에 유지한다. 별도 단일 프리팹은 생성하지 않는다.

## 적용 범위

|자산|변경|
|---|---|
|DamageablePlatforms|루트의 감지 영역0개 공통 피해 컴포넌트 제거. Gratan 자식에 GratangDamagePlatform과 기존 자기 Trigger2개 연결. Pot/Burner는 중첩 단일 원본에서 상속|
|Stationary/Pot, Stationary/Burner|각 PotDamagePlatform/BurnerDamagePlatform으로 타입 전환. 기존 컴포넌트 local fileID·감지영역·설정 보존|
|Tech_SYM/Prefabs/DamagePot|기존 Pot용 자산도 PotDamagePlatform으로 전환. 빈 감지영역·접촉면은 자동 연결하지 않음|
|StageTriggerPoint|기본 요청 종류를 Checkpoint(1)로 변경|
|LinearPlatforms|프로토타입6개에 동일 적용된 이동속도0.6m/s를 기본값으로 반영|

PeriodicPlatforms의 지지 Collider/이동 담당, Memo의 씬 UI, 고정 적의 순찰 앵커 등 의도된 빈 참조는 유지한다. 메시/몸체 선택, 배치별 EnemyDefinition, 대화 코드/테이블 등 특정 인스턴스 선택은 일괄 Apply하지 않는다. 기존에 연결된 정상 내부 참조도 임의로 비우지 않는다.

## 완료 기준

새 인스턴스에 구체 타입·내부 감지영역이 존재하고 Missing Script/중복 피해 컴포넌트가 없어야 한다. 기존 Transform/Renderer/Collider/Rigidbody와 메타는 동일해야 한다. 아트·Packages·ProjectSettings 및 미저장 Bootstrap 씬을 보존하고 실제 실행 범위를 구분한다.
