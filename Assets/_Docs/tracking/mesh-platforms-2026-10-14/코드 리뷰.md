# 코드 리뷰 — 메시 플랫폼

## 반영 구조

- PlatformContacts: Box RequireComponent 제거, 명시 Collider 배열, 실제 Surface/Passenger/Point/Normal/물리 단계 기록. 한 면의 이탈이 다른 면을 지우지 않도록 접촉 쌍별 갱신과 만료를 사용한다. 비활성·Trigger·충돌 무시·다른 Rigidbody를 거절한다. 잠든 물체의 Stay 중단은 접촉 만료와 구별한다.
- CharacterMovement: 표면의 ICharacterGroundContactFilter 한 계약을 조회한다. 최종 접지·상대 상승 속도·점프는 기존 HMS가 소유한다. 플랫폼 경사각 필드는 없다.
- KinematicPlatformMotion: 실제 Collider별 속도 전달과 Rigidbody별 한 번 운반을 분리했다. 회전으로 탑승 위치에 생기는 속도 및 직전 속도를 몸체별로 보존한다. 모든 지지면의 임시 마찰 재질을 자신의 수명 종료 시 복원한다.
- FloatingPlatform: 높은 테두리 Bounds 대신 실제 착지 접점의 현재 위치로 재착지 간격을 판단한다. 접점은 표면 로컬 좌표로 저장해 이동·회전에 따라간다.
- PeriodicPlatform/MeshCapsuleGeometry: Box 경로를 보존하면서 비 Convex 삼각형 메시 경로를 추가했다. 삼각형 교차 Y 구간, 내부 winding 검사, 첫 분리 출구를 계산한다. Bounds는 후보와 안쪽 방향에만 사용한다. 순수 기하 검증에서 회전 Box와 메시 표현을 비교했다.
- 주기 메시 캐시: 원본 import 수정 없이 Editor에서 읽기 불가 메시의 CPU 사본을 준비한다. 실제 Inspector 편집 대상만 갱신하며 빌드 시에는 빌드 씬 사본만 준비한다. 전체 열린 씬을 주기적으로 검색·수정하거나 자동 저장하는 구조는 채택하지 않았다.
- DamageFloorPlatform: 명시 Trigger 목록, 자기 relay 구독, 현재 Actor 세대, 물리 단계 중복 방지, 기존 Bridge.Damage 경로. 임시 비활성화와 세션 Unbind를 구분해 재활성화 후 현재 Actor를 다시 연결한다.
- OilSurface: Box RequireComponent 제거, 같은 객체의 명시 Convex Trigger. 기존 3초 효과 갱신을 유지하고 Pan 지지면과 VFX 장식 Collider를 피해/기름 판정에 섞지 않는다.
- ShatteredPlatform의 Box 전용 검사와 이동/장치의 끝점 cube 기즈모도 실제 Collider 계약으로 이관했다.

## 독립 검토와 보완

독립 검토에서 피해 재활성화 시 바인딩 손실, 여러 탑승자 Collider의 속도 전달 누락, 용기 내부의 부유 재착지 잠금, 충돌 무시 후 남은 접촉 운반 가능성을 지적했다. 재바인딩 수명, 같은 Rigidbody의 전체 접촉 쌍 전달, 실제 접점 기준 이탈, 소비 전 IgnoreCollision/IgnoreLayer 검사로 보완했다. 직전 회전 운반 속도도 함께 보완했다.

## 자산 검토

플랫폼 프리팹 19개를 이관 대상으로 처리했다. 중첩 원본의 변경을 그대로 상속한 3개는 추가 바이트 변경이 필요 없었다. 16개 프리팹 파일이 직접 바뀌었고, 실제 시각 메시를 기존 물리 좌표계로 합친 충돌용 Mesh 26개를 종류별 CollisionMeshes 폴더에 만들었다. 원본 아트를 복제 제작하거나 import를 변경하지 않았다.

서랍3개·트레이2개의 독립 이동은 유지한다. 같은 서랍 벽의 중복 물리 몸체와 Oil 벽면의 별도 Rigidbody는 정리했다. Pot/Gratan 기존 충돌 메시를 Convex Trigger로, Burner 기존 Box를 Trigger로 사용했다. 내용물 Trigger의 최종 넉백 방향·피해 체감 범위는 사람 검증 대상이다. 메모·눈물 수집 Box, 단순 프랍, 기존 빈 작성 참조와 비활성 모델 선택은 유지했다. Props 배경 프리팹에는 교체할 기존 BoxCollider가 없었고, 배경 물리 Box는 FloorPlatforms/Shelf에 있었다.

현재 기존 프리팹의 물리 루트 계층을 재사용한다. 일반적인 빈 Root/Physics 예시를 이유로 기존 프리팹의 전체 계층을 재작성하지 않았다.

## 한계와 보존

Play/Player·실제 빌드는 실행하지 않았다. 입력·점프·회전 중 자연 접촉, 전체 주기 시간 진행, 사망 연출 완료, VFX·조작감은 사람 확인이 필요하다. Convex 기즈모의 자홍색 입력 메시와 PhysX 최종 hull은 동일한 표시가 아니다. Physics Debugger로 최종 Trigger 부피를 확인한다.

기존 미저장 01_Stage_Prototype 씬을 저장하지 않았다. _Art 660파일, 기존 프리팹 meta 65개, 기존 Transform/활성 필드, 씬 파일은 기준 해시/직렬화 대조에서 보존됐다. Editor 작업 중 ProBuilder Settings.json의 바이트 변화가 관측됐다. 해당 설정을 수동 편집하지 않았으며 정확한 발생 원인은 미확정이다. 기존 사용자/Editor 변경일 수 있으므로 되돌리지 않고 보존했다. Git 커밋·push는 수행하지 않았다.
