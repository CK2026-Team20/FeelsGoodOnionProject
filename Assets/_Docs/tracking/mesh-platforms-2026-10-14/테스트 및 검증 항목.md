## 실패와 재검증

- 최초 접촉 수집 코드의 Collision.otherCollider API 사용이 컴파일에서 거절됐다. 실제 ContactPoint 쌍 갱신과 Exit 후 미갱신 쌍 만료로 수정했고 최종 컴파일은 성공했다.
- 최초 Oil 검사는 Prefab Contents의 비물리 Preview에서 겹침이 false였다. 실제 임시 인스턴스와 Physics.SyncTransforms를 사용한 비 Play 질의로 교체해 통과했다. 제품 코드를 검사 성공에 맞춰 완화하지 않았다.
- 부유 재착지 검사에서 Transform 이동 후 Bounds 동기화가 빠져 실패했다. 검사 준비 단계에서 동기화한 후 통과했다.
- IgnoreCollision은 위 환경에서 설정을 유지하지 않아 미평가로 남겼다. 제품은 접촉 소비 전에 현재 IgnoreCollision/IgnoreLayerCollision을 확인한다.

## 사람 플레이 완료 기준

1. Side/Quarter에서 Dish·용기 바닥·테두리·경사면을 밟고, 머리/벽 접촉이 접지가 되지 않는지 확인한다.
2. 이동·회전 중 면 전환, 점프·이탈 관성, 껍질·일반 물체 운반, 부유 발판 내부 재착지 및 비활성화/재시도를 확인한다.
3. 주기 생성/이동 중 1/4 경계 사망과 실제 몸체 분리·사망 완료, 얕은 급경사 안쪽 분리 후 낙하, 빈 내부 비침투, 껍질 독립 분리를 확인한다.
4. Oil은 Pan 위에서만 지지되고 기름 영역에서 미끄러지는지, Pot·Gratan·Burner는 공통 피해·무적·넉백을 유지하는지 확인한다.
5. 충돌 무시 전환과 수면 상태 물체의 이동 재개, 실제 최종 Convex hull 범위를 Physics Debugger와 플레이로 확인한다.
6. 기즈모의 현재·시작·도착 메시와 자식 회전·배율을 시각 확인한다. 경로 전체 충돌 검증은 별도다.
