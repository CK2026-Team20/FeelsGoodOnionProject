# 메시 기반 플랫폼 접촉·피해 영역 통합

## 목표와 기준

2026-10-14 사용자가 승인한 계획을 구현한다. 최신 직접 지시가 이전 Box 전용·사이드뷰 전용 규칙보다 우선한다. 참고 코드는 PlatformContacts, KinematicPlatformMotion, CharacterMovement.RefreshGround, PeriodicPlatform, DamageFloorPlatform, OilSurface이며 실제 `_Prefabs/Platforms`, `_Prefabs/Props`와 V1.6을 대조한다.

## 책임과 작성 계약

- 플레이어는 최대 접지각·캡슐 크기·점프·최종 접지 상태를 소유한다. 플랫폼은 명시된 Collider 목록과 아래 반구의 실제 접점·월드 법선 판정을 소유한다. HMS는 ICharacterGroundContactFilter 계약만 소비한다.
- 하나의 이동 Rigidbody에 여러 지지 Collider를 연결할 수 있다. 피해 Trigger는 목록에서 제외한다. 실제 Collider별 접촉과 운반 속도를 전달한다.
- 주기 발판은 실제 삼각형/캡슐 교차의 월드 Y 높이를 전체 캡슐 월드 Y 높이로 나눈다. 1/4 미만은 지지면에 착지 보정하거나, 급경사·벽이면 메시 Bounds 중심으로 수평 분리한다. 정확히 1/4 이상은 기존 공통 사망·수직 분리 경로다. 빈 내부는 재료 부피로 채우지 않는다.
- 충분한 통과 공간은 레벨 작성 전제다. 공간 부족의 활성화 보류·안전점 복귀는 추가하지 않는다.
- Pot/Gratan은 기존 충돌 메시의 Convex Trigger, Burner는 기존 Box Trigger를 피해 영역으로 사용한다. 피해·무적·넉백은 Bridge의 공통 규칙을 사용한다. Oil은 별도 Convex Trigger이며 Pan만 지지한다.
- 종류별 기존 프리팹과 중첩 계층·활성 모델 선택·의도된 빈 참조를 보존한다. 이동 서랍/트레이는 각각 독립 Rigidbody이며 같은 서랍 벽의 중복 Rigidbody는 제거한다.
- 메시를 기존 물리 좌표계에 합친 충돌 전용 Mesh 자산을 종류별 CollisionMeshes 하위에 둔다. Visual 및 `_Art` 원본·import 설정은 수정하지 않는다.

## Inspector와 표시

탑승 충돌면 목록, 기존 이동 Rigidbody·이동 설정, 피해 Trigger 목록, Oil Trigger·미끄러짐 시간, 선택적 접촉 디버그만 제공한다. 경사각·캡슐 치수는 중복 입력하지 않는다. 청록색은 지지 메시, 노란색은 아래 반구, 녹색은 접점·법선, 주황색은 Box Trigger, 자홍색은 Convex 입력 메시 참고선이다. Convex 입력선은 PhysX가 만든 최종 hull과 같다고 보장하지 않는다. 최종 hull은 Physics Debugger에서 확인한다. 시작·도착 형상은 경로 전체의 충돌 검사 결과가 아니다.

## 제약과 완료 기준

Play/Player·Git 작업·기존 씬 재조립/저장·원본 아트 수정은 하지 않는다. Unity 컴파일, 65프리팹과 연결 씬의 Missing Script/직렬 참조, 접지·다중면 운반·주기 임계값·피해 Trigger 분리를 검사한다. 비 Play 기하/API 검증과 실제 자연 물리 콜백·조작감은 구분한다. 후자는 사람 플레이 검증으로 인계한다.
