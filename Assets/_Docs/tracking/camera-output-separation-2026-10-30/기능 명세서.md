# 기능 명세서

## 목표와 범위

2026-10-30 사용자 확정: 원본 방향 변경은 본편 StageService의 세 구도에 적용한다. 현재 작업 씬 Main Camera Transform은 제외한다. 카메라는 대상의 +Z 쪽에서 -Z 방향으로 대상을 바라본다. 타이틀 전용 출력과 게임 전용 출력을 분리한다.

- StageService 신규 기본값과 등록된 01_Stage_Prototype의 측면·통로·쿼터뷰 Y 회전을 180도로 지정한다. 기존 수직각·반경·감쇠·화면 위치·오프셋은 유지한다.
- 기존 Bootstrap Camera/Brain/AudioListener는 Core의 게임 화면용으로 유지한다. 출력의 소유 수명은 App, 추적·구도 처리는 Core LevelCameraService다.
- 02_Title의 TitleScenePresentation 아래에 전용 Camera/AudioListener를 추가한다. 별도 Brain 없이 기존 타이틀 기준점·시야각을 사용한다.
- Title 진입 시 게임 Camera/Brain/Listener를 비활성화한 뒤 타이틀 Camera/Listener를 활성화한다. Title 해제 시 반대 순서로 원래 게임 활성 상태를 복원한다.
- 타이틀 구도를 게임 카메라 Transform·시야각에 적용하지 않는다. 오프닝·엔딩은 기존 Core 화면으로 게임용 출력을 사용한다.

## 제약과 완료 기준

현재 Stage_quarter 미저장 씬은 저장·재로드·변경하지 않는다. Unity 버전·렌더 설정·아트·공용 프리팹·보존용 과거 씬은 변경하지 않는다. 작업 대상 두 씬만 공식 Unity API로 열어 설정하고 개별 저장한다. 전환/실패/반복 해제 검증과 실제 Play 미실행 범위를 분리해 기록한다. Git 커밋·push·PR 작업은 이번 변경에 수행하지 않는다.

## 작성 방법

- 본편 구도: 01_Stage_Prototype의 StageService에서 세 View 설정을 편집한다.
- 타이틀 구도: 02_Title의 기존 cameraAnchor를 배치하고 TitleScenePresentation의 시야각을 조절한다. Title Camera는 해당 기준점에만 연결된다.
- 전용 Camera/AudioListener의 기본 활성 상태는 꺼 둔다. App의 Title 연결이 런타임 출력 전환을 담당한다.
