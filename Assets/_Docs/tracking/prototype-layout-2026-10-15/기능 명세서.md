# 프로토타입 레벨 배치 명세 — 2026-10-15

## 목표
기존 사용자 프리팹을 실제 `Architecture/01_Stage_Prototype.unity`에 배치하여 제공 목업의 진행 순서와 기능 구간을 구성한다. 첫 체크포인트의 플레이어 CapsuleCollider 중심은 **(0,0,0)**이다. 통합 흐름은 Bootstrapper → Title → Core + 새 Stage → 옵션의 Title 복귀 또는 포포/Ending → Title이다.

## 참고 자료와 실제 확인
- Desktop `Cooked!_프로토타입 레벨디자인.fbx`: Unity 임시 자산·Preview Scene에서 실제 변환, 메시 bounds, Spawn Point 순서와 평면/측면 렌더를 확인했다. 첫 시작은 원본의 오른쪽 Spawn Point이며 진행을 Unity +X로 정렬했다.
- 같은 이름의 `.blend`: 원본 파일과 해시를 보존했다. 이번 형상 조회의 직접 근거는 제공 FBX이며 Blender 내부 편집/재저장은 하지 않았다.
- `Assets/_Prefabs/`: 기존 65개 프리팹의 실제 형상·계층·공개 기능·직렬화 필드를 읽었다. 기존 Floor/Stationary/Moving/Interactable/Props/StageControl/Environment를 사용한다.
- 현재 시스템은 V1.6과 최신 직접 지시, planning-index/standards/engineering-notes 및 해당 지역 AGENTS다. 구 1_Stage를 새 레벨의 배치 원본으로 복제하지 않는다.

## 배치 기준
원본 진행축의 시작을 0으로 옮기고 +X 순서로 구성했다. 초안 변환은 X=(919.5371-sourceX)×0.07, Y=(sourceTop-8.1010475)×0.1-1.02, 깊이 Z=(91.7-sourceZ)×0.1이다. 이는 최종 좌표를 강제하는 비율이 아니다. 프리팹 메시와 Collider를 확인하여 식탁·식기·도마의 폭, 빈 공간, 지지 높이와 착지 여유를 개별 조정했다.

PlayerRoot 원본의 Capsule은 높이2m/반경0.5m, jumpHeight3m/moveSpeed5m/s다. 처음 바닥 상면은 -1.02m로 두어 원점 Capsule 아래에 약0.02m 여유를 확보했다. 식기 계단의 위/아래 식기가 Capsule을 가리는 두 지점은 X 간격을 벌려 수정했다. 목업 기능 순서는 유지한다. 원본 수치는 변경하지 않았다.

측면 구간은 Z=0, 통로·쿼터 분기는 깊이 방향, 마지막 측면 추격은 Z=15에서 +X로 진행한다. 선택형 프리팹은 형상 하나만 활성화했다. 적은 물리 기능 Root/Body의 단위 배율을 유지하고 인스턴스 외형과 BoxCollider 크기를 함께 조정했다. 고정 순찰점은 실제 선택한 EnemyActor 안, 움직이는 Body 밖에 둔다. 지지 Rigidbody는 배치 인스턴스에서 Kinematic/중력 해제를 설정했다. 오븐 트레이 두 곳의 닫힘 앵커가 배치 몸체보다0.5m 위에 있던 차이는 인스턴스의 시작/끝 앵커를 함께 이동해 보정했다. 원래 이동 벡터는 유지한다.

## 기능 구성
- 실제 프리팹 인스턴스136개, 씬 루트144개.
- 체크포인트7개, 카메라 전환5개(측면/통로/쿼터), Form/Tear 해금 각1개.
- 적4개, 수집 조각7개, 메모1개와 기존 화면 View 원본.
- 흔들림·주기·왕복·압력 연동·붕괴 발판, 기름 및 독립 피해 Trigger, 오븐 트레이2개/서랍3개.
- 스테이지 소유 추격 무리1개, 퇴로 차단1개, 실제 POPO 선택을 연결한 최종 Escape1개.
- 실제 음악 Clip과 기존 대화 JSON/메모 Sprite를 연결했다. 원경 식탁/소품/주방 외벽은 기존 프리팹으로 구성했다.

세 카메라 전환은 빈 Root/Sensor/Alignment 형제 구조다. 이번 목업의 통로 전환은 선택형 이동 차단체를 새로 추가하지 않았으며, 별도 추격 퇴로를 시작 트리거에 연결했다. cameraBounds는 선택 참조로 비웠다. Stage 관리 루트 아래에 월드 전체를 묶지 않고 각 기능의 독립 루트로 배치했다. Actor와 출력 Camera/Brain/AudioListener는 기존 Core/Bootstrap 소유를 유지한다.

## 참조 전환과 폐기
ArchitectureInstallation.stageScenes와 IntegrationEntrySettings.entries의 SceneAsset·파생 경로를 새 씬 하나로 갱신했다. BootstrapEntryRoute.PrototypePath 문자열만 새 경로로 바꿨다. Bootstrap/Title/Core 씬은 기존 공유 설치/Entry 참조를 통해 새 Stage를 사용한다. 빌드 메뉴의 명시적 목록도 같은 Catalog에서 네 씬을 얻는다.

구 `Prototype/1_Stage.unity`와 meta는 output의 legacy-backup으로 보존 후 AssetDatabase로 삭제했다. 빈 Prototype 폴더와 이번 형상 조회용 임시 FBX 폴더도 제거했다. 날짜별 과거 문서는 이력으로 보존하고 현재 문서의 실행 경로를 갱신한다.
