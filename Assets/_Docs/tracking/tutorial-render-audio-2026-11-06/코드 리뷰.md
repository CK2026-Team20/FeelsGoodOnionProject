# 코드 리뷰와 치명도 최종 판정

2026-11-06. 범위: 이번 구현과 수행된 실제 검사. 최신 사용자 지시에 따라 치명 여부만 최종 확인하고 확장 검증은 종료했다.

## 판정

실행 중 크래시·튜토리얼 초기 진입 차단 등 치명적 장애는 관찰되지 않았다. 전체 경로의 무결함을 증명한 결과는 아니다.

- **미해결 시각 결함:** Player에서 볼류메트릭 추가광의 차폐 그림자가 Editor와 다르다. 투명화 시스템 전체의 실패나 게임 진행 차단으로 확인된 현상은 아니다. 시각 완료 기준에는 미달이다.
- 최초 RealToon DOTS+lightmap 컴파일 오류4건은 소유 Editor stripping으로 사용하지 않는 DOTS 변형만 제외하여 후속 빌드 오류0을 확인했다. 실제 GRD 비활성·Entities Graphics/BRG 미사용을 검사하며 일반 instancing/APV/lightmap은 유지한다.
- 포그 키워드 _FORWARD_PLUS→_CLUSTER_LIGHT_LOOP 호환 처리는 컴파일/빌드 성공했지만 차폐 그림자를 복구하지 못했다. 키워드가 유일한 원인이라는 초기 추정은 철회한다. 패키지 원본은 수정하지 않았다.
- 독립 리뷰 P2: adapter의 잘못된 셰이더 참조는 필수 Pass5개 검사·오류 보고·자원 해제로 보완했다. 보완 후 Editor 컴파일0, 정상 adapter pass 생성 확인. 이 최종 방어 검사만 새 Player에 재빌드하지 않았다.
- 오디오 정책·출력·Binding 소유권 분리 및 풀 정리는 단계별 검토/검사를 수행했다. 물리 장치 청취·전체 세션 반복 검증 완료로 확대하지 않는다.

## 보호·정리

검증용 ProjectSettings/Packages/com.unity.pipeline/RuntimePipelineConfig.json은 사용자 임시 승인으로 생성했고 최종 제거했다. 생성된 빈 Pipeline/Resources와 meta도 정리했다. Player 정상 종료, Editor Tutorial 단일 씬/Edit/dirty=false, startScene Bootstrapper/runInBackground=false 복원 확인. 기존 미커밋 변경은 보존하고 commit/push/PR/병합하지 않았다.

## 후속: 발판 밝기 보강 리뷰

코드 변경 없이 씬의 발판61개 renderingLayerMask1→3 override 및 보조광4개를 추가했다. URP Light Layers 기존 활성 상태를 재사용했으며 공유 렌더 설정 변경 없음. Light.renderingLayerMask만으로 추가광 조명 마스크가 설정되지 않아 UniversalAdditionalLightData.renderingLayers도2로 명시했다. 충돌체·이동·가림 로직 변경 없음. 초기 미저장 씬을 보존하다가 저장 상태로 전환된 것을 확인한 뒤 기준본을 복사했고, 저장 직전 원본 디스크 바이트 일치를 확인하여 조절분을 저장했다. Play 종료 후 다시 dirty 상태이므로 추가 저장하지 않았다.
