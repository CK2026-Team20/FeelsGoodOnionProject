# 튜토리얼 투명화·오디오·라이팅 구현 현황

2026-11-06. 최종 사용자 지시: “치명적인 버그인지 아닌지만 확인하고 최종 확인해라.” 이에 추가 구현·장시간 성능 검증을 확장하지 않고 치명도 확인과 정리로 종료한다. 최초 승인 계획 전체 완료를 뜻하지 않는다.

## 반영한 기능

- Bootstrapper 게임 카메라에 HMS OcclusionFadeController 및 전용 셰이더 연결, 튜토리얼 10개 가림 Group. ZWrite=1 유지. D1 통계 시스템 도입 없음.
- SfxPlaybackPolicy: AlwaysPlay 17개, LimitedOneShot 3개, VirtualLoop 2개. BGM 5개 분리 유지. Limited는 동일 ID 동시2/0.08초, Virtual은20m 및 gain0에서 Stop/풀 반환, 논리 위상 유지 후 재진입.
- 튜토리얼 정적 베이크92개, UV2 소유 복제19개. 원본 아트는 보존. 기존 Core KitchenLight 인스턴스·지정 원본 제거.
- APV L1, 12개 셀·151040 probes. 동적 캐릭터용 소유 머테리얼과 세션 수명 lease, Reflection Probe 4개128 HDR.
- Area/Spot/Point의 따뜻한 주방 조명, 볼류메트릭 포그·라이팅. ACES, Bloom .06/threshold0, Color Adjustments exposure+.25, Vignette .18.
- URP17.6 호환 포그 셰이더/Renderer adapter는 소유 코드이며 설치 패키지의 공개 RenderGraph Pass를 재사용한다. 현 Player 그림자 결함 해결은 확인되지 않았다.

## 범위와 제한

조명은 튜토리얼 한정. 보호 HMS/RealToon/Packages/_Art 원본은 수동 변경하지 않았다. 공유 렌더 설정은 승인된 PC_RPAsset·PC_Renderer·UniversalRenderPipelineGlobalSettings 대상이다. 기존 자동 저장 변경과 사용자 diff는 보존했다. Git 작업 없음.

미등록 원본 음원 Sfx_Pc_Hit_Monster/Sfx_Pc_Knockback/Sfx_Platform_Spawn은 제작·대체하지 않았다. 1080p60 방어·144 달성 및 전체 튜토리얼 완주를 보증하지 않는다.

## 후속: 실제 밟는 발판 밝기 보강

사용자 요청에 따라 튜토리얼의 활성 발판 Renderer61개만 추가 Rendering Layer 비트2를 수신하게 하고, 위에서 비추는 Realtime Spot4개를 intensity0.8로 추가했다. 기존 layer1은 유지한다. 조명 그룹은 Tutorial Lighting/Walkable Platform Fill Lighting. 배경·캐릭터는 추가 레이어 대상에서 제외한다. 그림자·간접 기여0이며 별도 포그 기여 컴포넌트는 없다. 기존 ACES/Volume 및 아트 원본 머테리얼은 유지한다.
