## 확인한 씬 구조 문제

Prototype 씬의 직접 직렬화 Transform에서 다음 16개가 월드 루트에 따로 존재하고 실제 기능 필드가 참조한다.

| 기능 | 루트에 남은 기준점 | 근거 |
|---|---|---|
| 이동 발판 | `LinearPlatform_startPoint`, `LinearPlatform_endPoint` | LinearPlatform 인스턴스 startPoint/endPoint override |
| 서랍 3개 | `DrawerStep_1/2/3_closedPose`, `DrawerStep_1/2/3_openPose` | OvenTray 인스턴스 closedPose/openPose override |
| 적 3개 | `PatrolEnemy`, `OilPatrolEnemy`, `StationaryEnemy` 각각 patrolStart/patrolEnd | Enemy 인스턴스 순찰 참조 override |
| 압력 연동 발판 | `Body_startPoint`, `Body_targetPoint` | `ShellGate/Body`의 PressureLinkedPlatform |

따라서 이전 문서의 지역 앵커 정리 설명만으로 전체 정리를 완료했다고 판단할 수 없다. 카메라 트리거 자식 정렬점은 실제로 이관되어 있지만 발판·장치·적은 남아 있다. StationaryEnemy의 순찰 필드는 정지형 분기에서 소비되는지 확인하여 불필요하면 필드/연결/오브젝트를 함께 제거한다.

`PlayerCharacter.prefab`은 CameraTarget이 PlayerCharacter 아래, BackCameraTarget이 VisualRoot 아래에 있다. 통합 PlayerRoot는 ActorBody 아래 VisualRoot와 별도 CameraAnchor를 사용한다. 둘은 동일한 구조가 아니므로 실제 물리 몸체와 추적점이 함께 움직인다는 관계를 참고하고 보호 Player의 물리 계약을 강제 재배치하지 않는다.

## 권장 재구성

아래는 승인 전 설계안이다. 기존 프리팹 삭제·재생성·Apply·Unpack이나 리소스 제작을 허용한다는 뜻이 아니다. 소유 씬 배치와 허용된 override로 구성하고 실제 중첩 제약을 확인한다.

```text
씬 루트
├─ 게임 흐름 담당                  # 순수 관리 컴포넌트
├─ 출력 카메라                    # 관리자의 자식으로 월드를 묶지 않음
├─ 화면 Canvas
├─ 이동 발판                      # 완성된 기능 객체의 고정 루트
│  ├─ 시작점
│  ├─ 끝점
│  └─ 움직이는 몸체               # Rigidbody의 실제 이동
│     ├─ Render
│     └─ Collider
├─ 서랍                           # 완성된 기능 객체의 고정 루트
│  ├─ 닫힘 자세
│  ├─ 열림 자세
│  └─ 움직이는 몸체
│     ├─ Render / Collider
│     └─ 조작 지점 / 안내 지점
└─ 순찰 적                        # 완성된 기능 객체의 고정 루트
   ├─ 순찰 시작점 / 순찰 끝점
   └─ 이동 몸체
      ├─ Render
      └─ 접촉 Collider
```

핵심은 **고정된 목표점과 실제 이동 몸체를 같은 완성 객체 안의 형제로 두는 것**이다. 목표점을 움직이는 몸체 아래로 옮기면 목표도 따라 움직여 경로가 달라진다. 세계 위치를 읽는 `Transform.position` 자체는 오류가 아니다. 작성 시의 소유·부모 관계를 바꾸고 계산 경계에서 월드 위치로 변환한다.

현재 EnemyMotor는 EnemyActor의 transform을 움직이고 EnemyActor는 몸체를 직계 자식으로 요구한다. 적은 단순 reparent만으로 끝나지 않으며, 이동 대상·초기 위치 복원·센서 소유자 탐색·Gizmo를 함께 이관해야 한다. X/Y 순찰의 현재 월드축 규칙을 루트 임의 회전 지원으로 확대할지는 새 동작 요구 없이 변경하지 않는다. 장치·발판도 기존 월드 pose와 Rigidbody/Collider 관계를 보존한다.
