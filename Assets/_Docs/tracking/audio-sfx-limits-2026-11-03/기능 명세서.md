# 동일 효과음 재생 제한

목표: 다수 적의 동시 피격 등 동일 효과음의 집중 요청으로 생기는 과도한 중첩을 줄인다.

참고: AudioCueCatalog/AudioCue, AudioService, WorldAudioOutput, PlayerAudioBinding/WorldAudioBinding. 기존 이벤트 의미와 월드 정지 정책 유지.

규칙:
- 동일 Cue ID별 기본 최대 동시 재생 2개, 최소 재생 간격 0.08초.
- 마지막 수락 시각 이후 간격 미충족 또는 이미 최대 개수이면 즉시 무시. 무시된 요청은 대기열에 넣지 않으며 마지막 수락 시각도 바꾸지 않는다.
- 2D/위치 기반 출력을 합산한다. 정지된(Pause) 음성은 아직 종료되지 않았으므로 개수에 포함한다. 완료/명시적 Stop/Clear는 개수를 반환한다.
- 시간은 unscaled realtime을 사용한다. StopAll은 재생 간격 기록도 초기화한다. ClearWorldSfx는 실행 음성만 정리한다.
- 음악에는 적용하지 않는다. 기존 UI/전환 전용 단일 채널 및 전체 월드 채널 포화 정책은 유지한다. 카탈로그의 최대 개수는 상한이며 채널을 추가 확보한다는 뜻이 아니다.
- 지속 환경 Loop에도 동일 ID 제한 적용. 환경 바인딩은 활성 장치의 출력 확보를 기존 Tick 정책으로 재요청할 수 있으나 중앙 관리자는 억제 요청을 예약하지 않는다.

설정: Assets/_Data/Tech_SYM/Audio/AudioCueCatalog.asset → 소리 목록 → 해당 용도 → 최대 동시 재생 수(1 이상), 최소 재생 간격(초, 0은 간격 제한 없음). 음악 항목에는 적용되지 않는다. 설정은 AudioService 구성 시 복사되므로 편집 후 다음 실행부터 적용한다.

제약: 원본 음원·씬·프리팹 변경 없음. 기존 사망/Retry BGM 진행과 월드 정지 차단 유지.

완료 기준: 동일 프레임/간격 경계/최대 개수/서로 다른 ID/2D와3D 합산/일시정지/종료 반환/예약 없음/카탈로그 설정 전달 검사 및 기존 사운드 회귀 검사.
