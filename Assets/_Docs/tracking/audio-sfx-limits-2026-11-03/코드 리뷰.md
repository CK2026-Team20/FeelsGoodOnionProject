# 코드 리뷰

- AudioCue는 검증된 불변 설정을 소유하며 카탈로그 Entry는 한국어 InspectorLabel/Tooltip과 초기값을 제공한다. 비정상 개수·NaN/음수 간격은 거절한다.
- AudioService 한곳에서 제한 여부를 판정하고 재생 성공 후에만 수락 시각을 기록한다. 거절 요청은 기존 음성을 Stop하지 않는다.
- WorldAudioOutput은 네이티브 음성 수명을 계속 소유하며 CueId별 활성 개수만 노출한다. 관리자가 별도 가변 개수 장부를 중복 소유하지 않는다.
- 일반 출력은 드라이버 IsPlaying/Paused, 위치 출력은 AudioSource.isPlaying/Paused로 완료·일시정지를 구분한다.
- BGM 경로, 피해 판정, 적 이벤트 소유권은 변경하지 않았다.
- 기존 GameplayAudioChecks가 무시간 연속 이벤트를 모두 재생한다고 가정하던 부분을 명시적 테스트 시계와 새 억제 기대값으로 갱신했다.
