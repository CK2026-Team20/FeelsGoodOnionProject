# 런타임 장애물 검색·회피 최적화 결과 — 2026-11-13

## 목표와 범위
사전 등록을 없애고 실제 주변 Collider를 자동 검색하면서 기존 경로·볼륨 회피 동작을 유지한다. 이전 Profiler 진단에서 확인한 반복 물리 질의·경로 투영·장애물 상태 조회 비용을 줄인다.
현재 BoidsTest, BoidGroup/ObstacleQuery/Steering/BezierPath, 직전 Profiler/no-binary 결과가 기준이다. 원본 아트, 머테리얼, 프로젝트 물리 설정, dt, 후보48개, 예측1.2초, 개체12, 시드137을 변경하지 않았다. QA 제공 문서가 아닌 개발 검증 기록이다.

## 최종 구현
- BoidGroup의 obstacles/moving 등록 배열과 Configure의 해당 인수를 제거했다. 외부 호출 참조가 없음을 검색했다. 현재 씬의 그룹 직렬화를 저장하여 이전 등록 필드도 제거했다.
- 장애물 레이어(mask 기본 Everything)와 최대 접근 속력 예산(기본10m/s)만 설정한다. 군집 위치 AABB를 개체 이동 거리+장애물 접근 거리+몸 반경으로 확장해 물리 tick당 한 번 OverlapBoxNonAlloc 검색한다. ceil 적분을 포함하도록 horizon에 dt를 더한다.
- Trigger, 비활성 Collider와 자신의 풀 계층을 제외한다. 검색 버퍼64가 부족하면 확장해 다시 질의하며 4096 한도 초과는 명시적 오류다. 생성·삭제·활성·레이어 변경은 다음 검색에 반영한다.
- 같은 tick의 위치·world bounds·행렬·몸 크기·속도·정지 시각 snapshot을 모든 후보가 재사용한다. 속도 우선순위는 자동 발견한 BoidMovingObstacle의 명시 정보 → 연속 Collider 변위/dt → 최초 관측의 Rigidbody 속도다. kinematic 및 Rigidbody 하위 Collider 이동도 관측한다.
- BoidMovingObstacle은 자동 발견되는 시험 이동/정지 예측 정보이며 등록 필수 컴포넌트가 아니다. provider·Rigidbody 없는 이동체는 최초 관측만으로 속도를 알 수 없으므로 다음 관측부터 추정한다.
- 정적 도형은 빠른 구간 bounds 제외 후 필요한 경우에만 실제 SphereCast한다. 비볼록 메시 구멍을 임의 박스로 채우지 않는다. 평행 이동 Box는 snapshot 기반 상대 이동 OBB 검사와 정지 시각 분할을 사용한다. 이동하는 비-Box는 bounds로 보수적 예측한다.
- 경로 선분 delta·길이·역제곱 길이를 미리 계산하고, 투영에서 얻은 최근접 점을 Contains에서 재사용한다. 주변33선분 검색 범위와 이동 규칙은 유지한다.
- 회전이 끝나고 경로 경계 예측 구간도 지난 직선 꼬리만 하나의 선분으로 검사한다. Box 영역은 볼록하므로 직선 구간의 끝 포함으로 검사할 수 있다. 장애물은 전체 예측 구간을 계속 검사한다.
- 실제 접촉/관통 검증은 예측 cache만 믿지 않고 실제 Physics query와 상대 이동 검사를 사용한다. 재스폰/빈 군집 때 위치 이력을 초기화한다.

## 중간 결과와 잔여 한계
첫 시도는 정적 Box도 후보별 OBB로 검사해 아치에서 비용이 증가했다. 중간 실행은 Optimization/intermediate-results.json에 완료된 앞7개 결과만 보존했으며 전체 완료로 취급하지 않는다. 정적 도형의 실제 질의와 빠른 bounds 제외로 바꾼 뒤 위 최종 비교를 수행했다.
검색 속력 예산은 주변 발견 범위이며 실제 관측 속도를 제한하지 않는다. 예산보다 빠른 접근, 순간이동, 미관측 급가속, 회전·변형 장애물, 이동하는 비볼록 도형의 정확한 구멍 예측은 보장하지 않는다. 일반 이동 비-Box는 bounds 때문에 통과 가능한 공간을 보수적으로 막을 수 있다.
개체 간 강체 비관통은 여전히 제공하지 않는다. 큰 군집/여러 군집 동시 성능, Player 빌드, GPU 및 전체 게임 플레이는 미검증이다. 남은 경로 투영 비용과 전체 frame 여유는 별도 최적화 대상이다. 최종 Editor Play와 Profiler는 종료하고 원래12개 시나리오 구성을 복원한다. 기존 사용자 변경은 보존하며 Git commit/push하지 않는다.
