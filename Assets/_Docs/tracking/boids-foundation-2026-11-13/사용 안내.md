# 보이드 사용 안내

## 현재 씬에서 실행
현재 열린 Assets/_Scenes/Tech_SYM/BoidsTest.unity의 BoidsFoundationTest 아래에 12개 시험 구역을 구성했다. 기존 Main Camera, Directional Light, SideView, QuaterView, Plane, BG는 보존했다. 시험 전용 카메라가 실행 중 현재 시나리오를 비춘다.

Play를 누르면 각 구역을 18초씩 순서대로 실행한다. Inspector의 BoidTestSession에서 자동 검증을 끄면 수동으로 원하는 BoidGroup 컴포넌트를 활성화해 볼 수 있다. 자동 검증 중에는 군집 활성화를 시험 세션이 소유한다. 플레이어용 직접 씬 테스트 진입 선택은 이 시험 동안만 해제되고 편집 모드 복귀시 복원된다.

시험 순서: Path/Volume 각각 Arch, Torus, SquareRing, Cone, ApproachingBox, BezierCurve. Volume_BezierCurve는 경로를 사용하지 않는 빈 볼륨 대조군이다. 각 12개체이며 동시에 12개만 활성화된다. 이 구성이 144개 동시 성능 검증을 뜻하지 않는다.

## 군집 설정
BoidGroup의 이동 방식에서 Volume 또는 Path를 선택한다. 공통으로 BoidSettings, BoidAgent_Ghost 프리팹, 스폰 BoxCollider Trigger를 연결한다. 장애물 레이어에 포함된 주변 Collider는 런타임에 자동 검색하며 개별 장애물 참조 배열은 없다. Trigger와 자신의 풀 계층은 제외한다. 기본 레이어는 Everything이므로 불필요한 충돌체가 많다면 실제 장애물 레이어로 좁힌다.
- Volume: BoidActivityVolume의 BoxCollider Trigger 연결. 몸 반경과 안전 간격을 포함해 검사한다.
- Path: BoidBezierPath 연결. 웨이포인트마다 Anchor, Incoming, Outgoing Transform 참조를 연결한다. 경로 폭은 전체 지름(m)이며 중심선 주변의 허용 통로다. 경유점에 도착해 모이는 단계는 없다.
- 경로 종료: 열린 경로 끝을 통과하면 풀 반환. 순환 옵션은 마지막 구간을 첫 경유점으로 연결한다.
- 실행 중 모드 변경과 경로 핸들 실시간 편집은 이번 기본 사용 계약에 포함하지 않는다. 비활성 상태에서 설정한 후 재활성화한다.
- 움직이는 장애물: BoidMovingObstacle은 회전하지 않는 BoxCollider를 두 고정 Transform 사이로 이동시킨다. 도착 후 정지 상태도 충돌 대상으로 유지한다. 이 컴포넌트는 시험 이동과 정확한 정지 예측을 제공하며 장애물 등록의 필수 요건은 아니다. 일반 Collider도 발견되며 관측 위치 변화나 Rigidbody 속도로 이동을 예측한다.
- 경로·박스·스폰 영역은 실제 개체 크기와 회전 공간을 확보해야 한다. 모든 방향이 막힌 배치는 안전한 연속 이동을 보장할 수 없으며 FailedPlans로 기록한다.

## 새 전용 프리팹과 원본 보호
Assets/_Prefabs/Boids/BoidAgent_Ghost.prefab은 기존 Ghost 프리팹을 재사용하지 않고 빈 Root + Visual + VFX로 새로 조립했다. Visual은 원본 ch_monster_Rig FBX를 중첩 참조하고, 본 계층 및 배율을 보존한다. 전체 루트 배율은 1이며 임의 boidScale 필드는 없다. Collider를 물리 충돌로 밀어내는 대신 원본 Renderer 기준 외접 구 반경을 회피 질의에 사용한다. 따라서 개체에는 동적 Rigidbody가 없으며 위치의 소유자는 BoidGroup/BoidAgent 이동 경로 하나다.

원본 Monster Idle Type1은 비반복 클립이므로 보이드가 PlayableGraph의 시간을 반복 평가한다. 원본 클립·import·Avatar는 수정하지 않는다. N개체의 주기를 N등분하고 각 구간에서 균등 난수를 하나씩 뽑은 뒤 섞어 배정한다. 유한 표본에서 단순 독립 균등난수보다 시작 위상 쏠림을 줄이는 층화 표본이며, 개체 사이 값들은 독립이 아니다.
기존 BoidTrail VFX를 중첩 참조한다. 반환 시 Graph 해제, Trail emitting 해제/Clear, 진행·속도 초기화를 수행한다.

## 검증 출력
실제 Play 결과는 프로젝트 루트 output/Tech_SYM/Boids/2026-11-13/play-results-시각.json에 기록한다. Completed는 실행 순회 종료이고 각 결과의 passed가 해당 실행 조건의 판정이다. 실패한 이전 실행도 삭제하지 않는다. 최종 실행과 제한은 개발 검증 기록.md를 참조한다.

## 가중치와 머테리얼 후속 반영
BoidSettings.asset의 분리 가중치2·정렬 가중치1·응집 가중치0.5를 조절한다. 각 규칙에 곱하는 값이며 0이면 해당 규칙을 끈다. 공유 설정을 변경하면 연결된 모든 군집에 적용된다. 이웃 거리는 각 개체 기준 탐색 반경이다. 전용 프리팹 monster_body에는 _Art의 monster_default.mat를 연결했다. 성능 비교와 런타임 장애물 검색 설명은 가중치 머테리얼 및 성능 진단.md를 참조한다.

## 런타임 검색과 예측 범위
개별 장애물 등록 없이 장애물 레이어의 주변 Collider를 검색한다. 접근 속력 예산(기본10m/s)은 앞으로 접근할 장애물을 미리 발견하도록 검색 범위를 넓히는 값이며 실제 속도를 강제로 제한하지 않는다. 예상 장애물 속력에 맞게 설정한다. 레이어와 예산 변경 후에는 군집을 재활성화한다.
속도는 자동 발견한 시험 이동 정보, 연속 Collider 위치 변화, 최초 Rigidbody 속도 순으로 얻는다. 별도 이동 정보가 없는 Transform 이동체는 두 번째 관측부터 예측한다. 회전·순간이동·임의 가속은 보장하지 않는다. 움직이는 비-Box는 보수적 bounds 예측이며 정적 도넛은 실제 메시 구멍을 검사한다. 구체적 결과는 런타임 검색 및 최적화 검증.md를 따른다.
