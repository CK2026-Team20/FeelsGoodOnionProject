# 보이드 기반 이동 재설계

## 목표
보스·피해·패턴 기능 없이 분리·정렬·응집·장애물 회피·풀링을 제공한다. 군집별 BoxCollider 영역 활동 또는 개체별 연속 베지어 경로 추종을 선택한다. 현재 열린 BoidsTest 씬 안에서 두 모드의 장애물 회피를 검증한다.

## 참고 자료
현재 대화 확정 설계, 첨부 BoidAgent/Spawner, SebLague BoidHelper 황금비 후보 방향, ch_monster_Rig·Monster Idle Type1·BoidTrail 원본. 현재 브랜치 feature/Enemy-Boids이며 이전 구현의 완료 상태를 승계하지 않는다.

## 제약
원본 _Art·Ghost 프리팹·import·GUID·ProjectSettings·Packages를 수정하지 않는다. 기존 씬 루트 보존. 사용자 최신 지시로 새 보이드 전용 프리팹·테스트 배치는 이번 범위에서 제작 허용. 코드 Assets/_Code/Core/Tech_SYM/Boids, 프리팹 Assets/_Prefabs/Boids. Git 작업 없음. QA 제공 문서 생성 없음.

## 설계
동일 시점 위치/속도 스냅샷으로 같은 군집 이웃을 검색. 정렬은 이웃 평균 속도에 맞춤. 응집은 중심 거리로 약화. 경로 웨이포인트는 집결 목표가 아니며 공유 거리표·개체별 진행 상태·통로 폭으로 이동. 장애물 회피는 황금비 후보와 실제 회전 구간 검사, 이동 박스는 상대 이동으로 예측. 양수 최소 속력 유지. 경계와 장애물로 모든 후보가 막힌 경우 실패 횟수를 기록하며 무충돌을 무조건 보장하지 않는다.

## 애니메이션과 수명
원본 모델 배율 유지, 독립 Root/Visual/VFX. 원본 비반복 Idle은 PlayableGraph로 반복 평가하여 import를 보호한다. N개 스폰에 N등분 구간별 균등 난수와 섞기를 적용. 대여마다 위상 초기화, 반환시 Graph 해제·Trail Clear·이웃/진행 캐시 초기화. 풀 재사용 확인.

## 완료 기준
컴파일·직렬화 참조, 원본 배율·보호 파일, 두 모드의 아치/도넛 구멍/사각 고리/원뿔/전방 이동 박스, 곡선 통과·박스 이탈·속력·Idle 분포·풀 재사용을 실제 Editor Play에서 검증. 도넛은 단순 외곽 우회와 구멍 통과를 구분. 실행 조건·접촉·실패·성능·미실행 범위를 개발 검증 기록에 남긴다.

## 2026-11-13 런타임 검색·회피 최적화
사용자 후속 요청으로 BoidGroup의 정적/이동 장애물 등록 배열을 제거하고, 장애물 LayerMask와 접근 속력 예산으로 주변 Collider를 자동 검색한다. 군집별 물리 tick마다 OverlapBoxNonAlloc으로 발견한 충돌체의 위치·크기·변환·속도를 snapshot하고 후보 검사가 재사용한다. Trigger와 자기 풀 계층은 제외한다. 생성·삭제·비활성·레이어 변경을 다음 검색에 반영하며 가득 찬 버퍼는 확장한다.
경로의 선분 벡터/길이 데이터를 캐시하고 최근접 위치를 재사용한다. 회전 완료 및 경로 경계 예측 종료 이후의 직선 구간만 묶어서 검사한다. 예측 시간·후보 수·물리 dt·속력 정책은 성능을 위해 줄이지 않는다. 정적 비볼록 메시의 실제 구멍 검사는 유지한다.
완료 기준: 기존12개 경로/볼륨 실제 회귀, 런타임 발견·삭제·속도·버퍼 계약 검사, 이전과 동일12개체 Profiler 비교, 독립 코드 검토 및 남는 범위 기록.
