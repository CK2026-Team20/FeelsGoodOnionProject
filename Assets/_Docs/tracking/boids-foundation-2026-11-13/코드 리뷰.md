# 코드 리뷰

## 검토 범위와 결론
Assets/_Code/Core/Tech_SYM/Boids의 신규 구현을 독립 읽기 전용 검토했다. 기존 본편 시스템 전체의 준수 여부를 주장하지 않는다. 최초 8건과 후속 3건의 결함을 수정했고, 마지막 수정 및 후보 점수 생략의 안전성을 재검토하여 추가 확정 결함 없이 종결했다. 실제 실행 판정은 개발 검증 기록과 JSON을 따른다.

## 수정한 결함
- 회피 예측 0.08초와 실제 FixedUpdate 간격 차이: 동일 dt 적분으로 변경.
- 경로 폭이 복귀 유도에만 사용됨: 스폰·후보의 가까운 미래·실제 이동 이탈 검사 추가.
- 예측 경로의 투영 cursor 고정: 후보별 독립 cursor를 단계마다 갱신.
- 비활성 이동 스크립트의 BoxCollider가 회피 대상에서 사라짐: 속도0 장애물로 유지.
- 도착점 이후에도 박스가 이동한다고 예측: 도착점 제한과 정지 시각에서 구간 분할.
- 초기화 실패한 빈 군집의 풀 재사용 허위 성공: 예상 개체 수/유효 tick/초기화 실패 검사.
- Idle 연결 없이 위상 값만 검사: 필수 자산 Validate, Graph 준비, 실제 재생시간 변화 검사.
- 프레임 사이 얇은 장애물 관통 계측 누락: 실제 이전/다음 위치의 swept 검사와 full body radius 적용.
- Respawn 실패 후 일부 대여 개체 잔류: 실패 시 대여분 전부 반환하고 예외 전달.
- 순환 경로에 열린 경로의 반환 조건 강제: Loop는 반환 조건에서 제외. 현재 자동 시나리오는 열린 경로만 실행.
- 비활성 시험 세션의 기존 플레이어 진입 선택 변경: 활성 시험 세션에서만 일시 해제/복원.

## 실제 실행에서 추가 수정
경로 폭을 엄격히 검사한 초기 버전에서 원뿔 앞 정체 및 전방 이동 박스에 밀리는 현상을 확인했다. 경로 경계의 예측 길이를 폭/속력에 맞춰 짧게 재계산하되 장애물은 전체 예측 시간 동안 확인한다. 황금비 방향들에 정확한 경로 접선을 추가하고, 검증된 후보 안에서 경로 전진을 우선 평가한다.

## 비용과 책임
현재 best보다 높아질 수 없는 후보는 물리 검사를 생략한다. 재검사 때 회전율은 증가만 하므로 감점 이후 점수가 상한을 초과하지 않아 더 좋은 후보를 버리지 않는다. 매 FixedUpdate의 Stopwatch 할당은 제거했다.
설정은 읽기 전용 getter, 풀은 대여/반환 소유권, Agent는 이동 상태와 자신이 만든 Graph/Trail 수명, Path는 공유 거리표, Group은 활성 목록과 같은 시점 스냅샷, Query는 장애물 질의, Planner는 후보 검증/선택을 소유한다. UnityUtils에 의존하지 않는다.

## 남는 범위 제한
경로 경계는 boundaryHorizon까지만 예측하고 장애물은 전체 PredictionTime을 예측한다. 실제 첫 이동도 경계 검사 대상이지만 전체 미래 궤적의 통로 포함 보장은 아니다. 회피 후보가 모두 실패하면 FailedPlans를 올리며 해당 시나리오를 통과로 기록하지 않는다. 불가능한 막힌 배치에 대한 무충돌·무정지 동시 보장은 없다. 분리는 군집 조향이며 개체끼리의 강체 비관통 보장이 아니다.

## 후속 런타임 검색·최적화 리뷰
사전 등록 제거, 군집별 discovery snapshot, 경로 선분 cache, 직선 꼬리 통합을 독립 읽기 전용 검토했다. kinematic 속도 관측 누락(P1)과 재스폰의 오래된 위치 이력(P2)을 수정했고 추가3개 회귀를 포함한16개 계약 검사 통과. 최신 소스 재검토에서 두 지적을 종결했다. 최종 프로파일러 비교 및 실행 범위는 런타임 검색 및 최적화 검증.md를 따른다.

## 대규모 최적화 후속 리뷰
후보 점수 상한 정렬, 같은 시각 오차를 포함한6tick 궤적 묶음, 첫 이동 보존, 직선 통로 축약 및 회피 재검증을 검토했다. 풀 소유 Batch의 해제를 부모 삭제에 의존하는 P2를 수정했다. Dispose의 직접 Shutdown/컴포넌트 삭제·멱등성·폐기 후 대여 방어를 독립 재검토하여 종결했다. 실제 풀/Idle12검사 통과. 계산 순서 최적화와 보수적 묶음 검사로 궤적은 비트 단위로 동일하지 않으며 미래 경로 경계 보장은 기존 boundaryHorizon 범위다. 실행 결과·성능 목표 미달·개체 겹침·볼륨 구멍 통과 제한은 대규모 FPS 및 전체 시나리오 검증.md를 따른다.
