총22개 assertion 통과. 본편 시점 검사는 현재 구간의 View를 Play 중에만 바꿔 실제 EnterSection을 호출하고, 취소 경로는 실제 CancelTransition을 호출했다. 물리 가림은 기존 그룹을 카메라와 실제 Actor 사이로 잠깐 이동해 검사했다. 각 검사 finally에서 원래 View/배치를 복원했다. 직접 씬은 즉시 전환 방식이므로 비동기 블렌드 취소 대신 Select 및 Unbind의 복원 계약을 검증했다.

처음 본편 새 게임 진입 때 Unity 네이티브 크래시가 발생했다. ObjectDispatcher.DispatchTypeChangesAndClear → WorldProcessor.Update → GPUResidentDrawer.PostPostLateUpdate 스택이다. 공식 도구로 에디터를 다시 열고 GRD 활성 상태로 위 검사를 통과했다. 원인 규명이나 크래시 해결 완료로 기록하지 않는다. 재검증 콘솔의 오류1건은 CLI 내부의 미지원 `editor status` 요청이며 게임 예외가 아니었다.

사용자 승인 후 현재 튜토리얼 편집을 저장했다. 직접 테스트용 임시 설정/시작점은 검사 후 제거했다. 종료 상태는 Tutorial Edit Mode, dirty=false, DirectSceneTestSettings0, 직접 진입 선택false, 시작 씬 Bootstrapper, runInBackground=false다. 오디오/렌더/빌드 프로필 수정 없음.
