# 쿼터뷰 오클루전 연동

목표: 본편과 직접 씬 테스트에서 실제로 확정된 쿼터뷰에만 투명화를 허용한다. 라이팅 롤백 환경과 오디오·빌드 프로필·GRD를 유지한다.

참고: LevelCameraService의 수락/완료/취소 및 Brain 평가, CoreWorldBinding의 Actor 연결 수명, DirectSceneTestCamera의 Select/Tick/Unbind, HMS OcclusionFadeController.OnDisable의 원본 머테리얼 복원 계약.

정책: 측면/통로 비활성. 쿼터뷰 진입 전환 완료 후 활성. 쿼터뷰 이탈 시작 시 비활성 및 복원. 쿼터→쿼터 보정에는 활성 유지. 취소 후 실제 확정 카메라로 돌아온 뒤 상태 복구. 사망/Actor 해제/타이틀 복귀 비활성. 쿼터 재시작 초기 선택 완료 시 재활성. 옵션 정지는 상태를 임의 초기화하지 않는다. 이동 모드(통로와 쿼터가 동일)를 조건으로 사용하지 않는다.

제약: HMS 원본·렌더 설정·오디오·프로필 변경 없음. 카메라 서비스는 화면 시점을 소유하고 오클루전 타입을 참조하지 않는다. 작은 연결 객체 하나가 컨트롤러 enabled와 자신이 등록한 구독을 소유한다. 기존 미커밋 변경 보존, Git 작업 없음. 공식 Unity 스킬/도구로 검사한다.

완료 기준: C# 컴파일, 본편/직접 테스트 Play에서 측면·통로 차단, 쿼터 Fade/Restore, 시점 이탈 즉시 원상복원, 전환 취소 및 쿼터 재시작, 해제 후 잔존 투명도/구독 없음. 통제 배치와 자연 입력 전체 완주를 구분한다.
