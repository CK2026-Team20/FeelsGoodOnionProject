# 코드 리뷰

2026-11-08 쿼터뷰 전용 오클루전 연동.

- LevelCameraService가 실제 Brain 출력과 블렌드 완료를 확인해 PresentedView를 알린다. Corridor와 Quarter의 공통 이동 모드를 화면 판정에 사용하지 않는다.
- CameraOcclusionBinding이 자신의 구독과 출력 컨트롤러 활성 상태를 관리한다. 해제 시 컨트롤러의 기존 OnDisable 복원 경로를 사용한다.
- CoreWorldBinding은 Actor 해제 전에 연결 객체를 Dispose한다. 직접 씬 테스트는 Select/Tick/Unbind에서 같은 연결 객체를 사용한다.
- 읽기 전용 독립 리뷰에서 구체적인 결함은 발견되지 않았다. 정적 리뷰는 실제 전환·취소·재시작 검증을 대체하지 않는다.
- HMS 원본, 오디오, 렌더 설정, 빌드 프로필은 이번 연동 구현에서 수정하지 않았다. 기존 누적 diff는 이번 변경과 구분한다.
