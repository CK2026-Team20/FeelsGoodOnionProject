# 코드 리뷰

## 최종 변경
- AssetDatabase.MoveAsset로 본편 관리 씬3개, ScriptableObject5개, 대화 JSON1개를 분리했다. GUID9개를 전후 비교했다.
- ArchitectureInstallation/IntegrationEntrySettings/AudioCueCatalog의 경로 상수를 갱신했다.
- BootstrapEntryRoute의 관리 씬 경로를 갱신하고 실제 삭제된 Prototype 및 오래된 Stage2/3 호환 경로를 제거했다. SceneService는 현재 카탈로그의 씬만 정리한다.
- IntegrationBuildPipeline은 Installation에 명시적으로 등록된 Assets/_Scenes/ 아래 실제 SceneAsset을 검사한다. 이전 Architecture 폴더 제한은 루트 Tutorial 씬도 차단하고 있었으므로 새 구조에 맞게 해제했다. 자동 씬 검색/등록은 추가하지 않았다.
- 설치 자산의 실행 경로 캐시를 새 SceneAsset 경로로 저장했다. Tutorial 구간/트리거와 시작 상태는 변경하지 않았다.
- 남길 자산에 직접 참조가 없고, 코드/설정에서 경로/GUID 로드도 없는 SYM 전용 자산97개와 빈 폴더25개를 삭제했다. 테스트 씬에 포함된 오브젝트는 씬 삭제와 함께 제거된다.
- 타 작업자 씬이 참조하는 SYM 자산49개는 원위치/원내용으로 보존했다. 공용 _Prefabs 및 루트 Tutorial/Stage 씬은 이번 수정 대상이 아니다.
- 테스트 기능 코드 자체는 제거하지 않았다. 사용 중인 직접 씬 테스트의 프롬프트/메모 프리팹과 디버그 폰트는 보존했다.

## 예외와 검증 경계
- 사용자 정정에 따라 스킬3개·적2개·메모2개 모델은 기존 경로에 남는다. _Data의 안내는 정본 위치를 명시하며 복제 모델을 만들지 않았다.
- 삭제 전 원본 및 meta 백업: output/Tech_SYM/asset-organization-2026-11-02/backup/
- Build Profile 파일은 SYM 범위 밖이므로 수동 수정하지 않았다. 저장된 m_path는 구 경로이나 GUID는 유지되고 EditorBuildSettings API는 새 경로4개를 정상 반환한다. 프로필을 다음에 저장할 때 캐시가 갱신될 수 있다.
- ProjectSettings/EditorBuildSettings.asset에는 기존 01_Samples 경로가 남지만 현재 활성 프로필은 별도 씬 목록을 사용한다. 이번 작업에서 설정을 변경하지 않았다.
- 실제 Play/Player/빌드는 미실행이며 폴더 이관 검증을 전체 게임 QA로 해석하지 않는다.
