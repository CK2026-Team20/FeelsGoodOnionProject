# 현행 씬 문제와 개선안

2026-10-15. 직전 작업 이후 사용자가 추가한 Zone과 플레이어 수치를 현재 Editor에서 다시 읽었다. 과거 Zone0/Small 크기 역전 기록을 현재 결함으로 승계하지 않는다.

## 오해와 실제 제약 구분

- Z 회전은 미지원이 아니다. LevelCameraService 각도는 Vector3이며 실제 Play에서 Z=20도 설정이 출력 Z=20도로 반영됐다. Quarter의 Z 이동도 허용되고 실제 입력 명령0.5초에서 z+1.99m 이동했다. 다만 타겟 중심 궤도 편집 UI, 별도 XYZ 상대 위치 작성, 미리보기는 없다. 서비스가 리그 회전/TargetOffset을 다시 작성하므로 리그 Transform 직접 편집은 권위 있는 설정 경로가 아니다.
- 안전 위치로 '절대 이동하지 않는다'는 일반 결론도 정확하지 않다. 실제 Side Zone 접촉은 z0.5→0 보정과 Completed까지 확인했다. 이 Zone에서 X/Y safeAnchor로 이동하지 않는 이유는 차단체 없는 Side 계약 때문이다. 테스트는 공중에 놓은 시작 조건이어서 이후 바닥 없는 위치로 낙하했다. 일반 유저 동선에서 같은 추락을 재현했다고 주장하지 않는다. 경로 안전 검사에는 침투/장애물 검사만 있고 목적지의 바닥 지지 보장은 없다.
- Small 역전은 현재 수정되어 정상적으로 절반 크기다. 현행 Quarter 속도도5m/s로 이미 조정되어 있다. 코드 기본값3m/s를 현재 prefab 적용값으로 오인하지 않는다.
- 화면 캡처에서는 작은 플레이어와 넓은 검은 배경/큰 빈 공간이 확인됐다. 아트 누락인지 의도된 블록아웃인지는 별도 리소스 검토가 필요하다.

모든 시스템이 배치·활용되고 있지는 않다. 단, 비활성 프리팹 선택지를 누락으로 판정하지 않았으며 기능의 존재와 전체 플레이 동선 검증은 구분했다. 수정 우선순위는 작성 기준 통합 → 카메라 경계/전환 정리 → 버튼 cap/body 분리 → 플레이어·레벨 크기 기준 정립 → 기능별 실제 구간 배치다.
