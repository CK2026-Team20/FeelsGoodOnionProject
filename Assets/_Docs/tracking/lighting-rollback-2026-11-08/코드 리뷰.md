# 변경 검토

기존 미커밋 오디오·체크포인트·아트 변경이 있어 전체 파일 롤백을 하지 않고 씬의 라이팅 관련 객체·속성만 복원했다. 수정 전 백업은 output 검증 폴더의 before에 보관했다.

제거 완료: StageLightingMaterialOverrides와 CoreWorldBinding/DirectSceneTestRuntime의 전용 lease 연결, TutorialVolumetricFogFeature, TutorialVolumetricFog 셰이더, 별도 IntegrationBuildPipeline 메뉴. 직접 테스트 카메라도 후처리 false로 변경했고 투명화 컴포넌트 추가는 유지했다. 설치된 외부 패키지의 일반 빌드 기능은 프로젝트 커스텀 설정 조작 코드로 간주하지 않는다.

독립 읽기 전용 검토 결과: 삭제 GUID47개 잔여 참조0, Core 원본 KitchenLight 배치 일치(새 인스턴스 ID 제외), 렌더 baseline 복원, 오디오 연결 유지, BuildProfile 파일 동일. 별도 오디오38파일 해시 전후 동일성도 메인이 확인했다.

RealToonCore의 기존 GRD 컴파일 호환 include 수정은 이번 라이팅 기능 코드가 아니므로 변경하지 않았다. GRD를 끄거나 셰이더 변형 제거 코드를 도입하지 않았다. 첫 Play의 네이티브 충돌과 재시작 후 실제 통과는 검증 문서에 구분 기록한다.
