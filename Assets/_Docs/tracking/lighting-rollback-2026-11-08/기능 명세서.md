# 라이팅·빌드 경로 롤백

2026-11-08 사용자 직접 지시를 적용한다. 이전 라이팅 도입 계획보다 이 명세가 우선한다.

## 목표와 대상
- 튜토리얼에 추가한 조명·Reflection Probe·APV·볼류메트릭 포그·후처리 및 베이크 데이터를 제거한다.
- 이전 분류 대상의 Static 체크를 해제하고 조명용 UV2 메시·머테리얼 참조를 원본으로 복원한다.
- Core의 기존 KitchenLight 프리팹 하나를 원래 GUID와 배치 기준으로 복구한다.
- PC_RPAsset 및 관련 렌더 설정은 라이팅 도입 전 자료와 Git 이력을 대조해 복원한다. GRD 원래 활성 상태를 유지한다.
- 프로젝트의 별도 빌드 실행·설정 조작 코드를 제거하여 기존 Windows Build Profile 하나를 빌드 설정의 기준으로 사용한다.
- 오디오 정책·카탈로그와 병합 기능, 사용자 후속 체크포인트·아트 편집은 보존한다.
- 사용자 표현 '투영 시스템'은 앞선 OcclusionFadeController/OcclusionGroup 투명화 통합으로 해석하여 롤백 환경에서 실제 검증한다.

## 참고와 제약
원본 근거는 2026-11-06 검증 baseline, lighting-setup.cs, static-classification.json, Git의 KitchenLight 프리팹 및 Core 배치이다. 씬 전체 복원은 금지하고 해당 객체·직렬화 속성만 변경한다. 공식 Unity 도구 사용, 미저장 씬 보호, 오디오 파일 해시 대조, 원본 아트 보존. Git commit/push 없음. 모니터·전체화면·사용자 로컬 실행 설정을 변경하지 않는다.

## 완료 기준
롤백 씬에서 추가 조명/Probe/Volume/베이크 참조 없음, Core 원본 라이트 인스턴스 1개, 분류 대상 Static 해제, 삭제 자산의 남은 참조 없음. C# 컴파일 오류 없음. 빌드 설정을 덮어쓰는 사용자 코드와 별도 빌드 진입점 없음. 실제 Play에서 투명화 발생·복원과 ZWrite=1, 프레임 진행, 콘솔 오류 확인. 실제 실행하지 않은 검증은 완료로 표시하지 않는다.
