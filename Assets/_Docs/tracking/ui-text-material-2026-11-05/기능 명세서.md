# UI 텍스트 통일

2026-11-05 직접 지시 및 후속 답변: 시네마틱과 본편 UI 전체의 TMP 머테리얼·색상·굵기를 DialogueRoot/Context와 통일한다. 크기·배치·문구·MVVM 흐름은 유지한다.

기준: Assets/_Prefabs/UI/Dialogue/DialogueRoot.prefab의 Context. 머테리얼은 이미 전체 UI 프리팹25개가 동일하며 색상·굵기를 추가 적용한다. 수정 대상은 TMP가 있는 UI 프리팹6개와 본편 씬의 관련 오버라이드다. _Art 원본과 HMS 테스트 씬은 보호한다.

완료 기준: 실제 Unity 객체의 폰트/머테리얼/색상/굵기 일치, 격리 Canvas에서 한글/영문/숫자 메시 생성, 씬 오버라이드 검사, diff 검토. 본편 Play는 Bootstrap dialogueTable 누락으로 현재 차단됨.
