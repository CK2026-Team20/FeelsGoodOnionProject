격리 검사에서 실제 프리팹 내용을 LoadPrefabContents로 로드하고 필요한 Canvas를 임시 추가, 비활성 자식을 활성화한 뒤 한글/영문/숫자31문자에 ForceMeshUpdate를 실행했다. 모든25개에서 실제 메시 정점 생성과 동일 머테리얼/폰트/색상/굵기를 확인한 후 저장 없이 검사 복제본을 해제했다. 초기 Canvas 없는 시네마틱/대화 검사8개는 메시0이어서 통과로 인정하지 않았으며 Canvas 준비 후 재검증했다. 화면 가독성이나 전체 게임 플레이를 증명하는 검사는 아니다.

Play 시도는 수정 전 수행했고 실패 후 종료했다. 프레임1931이 두 번 같아 프레임 진행도 확인하지 못했다. 수정 후에는 격리 메시 검사와 씬 직렬화 검사를 재실행했다.

HMS 테스트 씬7개와 Editor F1 동적 텍스트는 본편 UI 프리팹 통일 완료 수치에서 제외한다.
