# 적 Idle 시작 위치 분산

목표: 반복 Idle을 개체별 균등 난수 위치로 시작하고 Inspector Flag로 직접 지정한다. 참고: EnemyActor 준비/Retry 수명과 현재 Enemy.controller의 반복 Idle_1. 제약: 이동 속도/Body/앵커 불변, 원본 아트·Controller·프리팹 복제/Apply 없음, 미저장 씬 보존. 완료 기준: 실제 Animator 재생 위치, 수동값·Retry·자기 구독 해제 검증.

Enemy Root의 EnemyIdleAnimation이 외형 Animator를 참조한다. 시작 위치 직접 지정=false면 최초 사용에 Unity Random.value를0~1 주기로 정규화해 저장한다. 독립 균등확률 추출이며 유한한 개체들이 정확히 같은 간격에 놓이는 층화 배분은 아니다. 같은 개체는 재시도/비활성화 후 재활성화에도 값을 유지하고 새 게임의 새 인스턴스는 다시 추출한다. Flag=true면 Idle 시작 위치0~1을 사용한다(1은0과 동일). 수동 해제 시 이전 랜덤값을 사용한다. Play 중 Inspector 변경은 다음 LateUpdate에 적용하고 종료하면 작성값으로 돌아간다.

준비 성공 이벤트와 OnEnable에서 첫 화면 표시 전에 기본 레이어 반복 상태를 Rebind/Play/Update(0)한다. 단일 Idle Controller용이다. 순찰 속도와 Animator.speed는 변경하지 않는다. 잘못된 연결·비반복 기본 상태는 원인 로그를 남기고 적 이동 로직은 종료하지 않는다. 정상 적용 뒤 매 프레임 재추출/재생하지 않는다.

현재 Tutorial의30개(활성15/비활성15)에 컴포넌트와 기존 Animator를 연결했다. 기본 Flag=false. Undo 그룹: 적 Idle 시작 위치 분산 연결. 사용자 기존 편집과 함께 미저장 상태로 유지했으며 씬 저장은 수행하지 않았다. 다른 씬/프리팹에는 Enemy Root에 해당 컴포넌트를 추가하고 외형 Animator를 연결한다.
