# 적 개체별 속도

목표: 같은 EnemyDefinition을 사용하는 적도 별도 이동 속도 설정. 참고: EnemyActor.Tick/EnemyMotor.Move/EnemyDefinition. 기존 배치·기절·Retry·보호 자산은 유지한다. 완료 기준은 실제 몸체 이동량과 기본값 호환 검사다.

EnemyActor의 개체별 속도 사용을 켜고 개체 이동 속도(m/s)를 입력한다. 0은 이동 정지, 음수/비유한값은 오류다. 개별 설정이 꺼져 있으면 기존 모델의 기본 이동 속도를 사용하므로 기존 배치는 그대로다. 개별 값은 프레임마다 실제 이동에 반영되며 Retry에서 덮어쓰지 않는다. 종류·첫 대기는 기존 모델에 남는다. Play 중 변경은 종료 시 되돌아간다.
