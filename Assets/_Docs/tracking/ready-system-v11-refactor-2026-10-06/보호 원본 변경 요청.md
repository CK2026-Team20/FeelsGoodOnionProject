# 보호 원본의 변경 요청과 한계

2026-10-07 사용자의 직접 지시로 아래 HMS 9개 .cs의 필요한 공개 확장·참조 캐시·변수만 이번 명세 1회에 허용된다. 기존 기능·독립 소비·기본값·enum 번호를 보존한다. 공용 Interfaces/타인 자산/메타는 읽기 전용이다. 이전 세션의 허가를 영구 권한으로 승계하지 않는다. 실제 작성·컴파일·실행 상태는 검증 문서에 별도로 기록한다.

## 필수 기능을 위한 최소 9개 파일의 예외 요청

공통 경로는 `Assets/_Code/Core/Tech_HMS/Features/`다. 허가 요청은 **아래 9개 .cs의 명시한 기능 변경**에만 적용하며, `.meta`/보호 prefab/씬/아트/공용 Interfaces/Packages/ProjectSettings 권한을 포함하지 않는다. 보호 자산에 새 필드를 연결하는 작업은 소유 SYM 배치에서 수행한다. HMS 원본 프리팹에 Apply하지 않는다.

| 파일 | 현재의 제한 | 요청 변경 / 왜 필요하나 |
|---|---|---|
| TearSkill.cs | 범위 Collider 접촉만으로 IStunnable을 호출해 벽/사물을 관통함 | 범위 후보와 실제 Hurt Collider 피격을 분리하고 벽/사물 앞 가림 검사·자기/센서 제외·중복 대상 처리. 판정점/다른 적의 차단은 선택 후 적용; 도메인 효과 적용 전에 검사해야 하므로 SYM에서 이미 발생한 기절을 되돌리는 우회 불가 |

허가 근거는 현재 사용자의 직접 지시다. 새 조립은 선택적 확장을 명시적으로 사용하며 HMS의 독립 기본 동작을 바꾸지 않는다. 같은 기능을 SYM에 복제하여 원본 경계를 우회하지 않는다. 종료 알림 예외·콜백 재진입·낡은 요청은 확장 경계의 실제 회귀 검사와 독립 검토로 확인한다.

## 보호 코드 내부의 정리 후보

추가 후보는 아래13개 파일이다. 현재 새 SYM 게임은 준비·재사용 대기·별도 회수 조건을 쓰지 않지만 HMS 독립 자산/Temporary 소비자 및 공개 슬롯 API가 남아 있다. **필수 9개 기능 예외만으로 아래 정리 범위를 일괄 허가하지 않는다.** TearSkill.cs는 직접 피격 기능 변경과 준비/쿨다운 정리 범위가 겹치는 파일이며 총 파일 수에 이중으로 합산하지 않는다. 전체 프로젝트 정리 요청에 대한 진단 대상이며, 실제 보호 소비자 이관/허가가 없는 삭제는 범위 밖이다.

| 파일 | 검토할 불필요 경로와 보존 근거 |
|---|---|
| PlayerFormController.cs | 현재 Q 복귀와 다른 거리/접지 회수 메서드/설명. Q 원자 공간 검사·껍질 생성/반환은 필요 |
| PlayerSkill.cs | Preparing/Cooldown 기반 공통화가 세 즉발 스킬에 필요한지 검토. 성공 Activated 통지는 실제 소비자 존재 |
| PlayerSkillController.cs | 빈/동적 슬롯·남은 쿨다운 중계의 실제 외부 소비를 확인. 활성 스킬 수명/중복 발동 방지는 필요 |
| PlayerSkillPresentation.cs | 준비/쿨다운 표시 필드. HMS Temporary HUD 소비를 먼저 이관해야 함 |

| TearSkill.cs | 가림/직접 피격은 위의 필수 기능 변경 요청이며, 여기서는 별도 preparation 타이머/취소 재검사/쿨다운 로그 정리 범위를 다룬다. 즉시 소비/중복 대상 제외/스턴 적용은 필요 |
| TearSkillDefinition.cs | 준비/재사용 대기 설정. 조각5/반경3m/스턴2초 설정은 필요 |
| ShrinkSkill.cs | 준비 시간/조건 반복. 즉시 작은 폼/껍질1개 성공 계약은 필요 |
| ShrinkSkillDefinition.cs | 준비·대기 필드. 점프/폼 설정 실제 사용 유지 |

| RestoreFormSkillDefinition.cs | 준비·거리/접지·대기 설정 소비. 실패 공간에서 둘 다 유지하는 실제 규칙 보존 |

공용 Interfaces5개는 실제 플레이어/상호작용/기절 VFX 경계가 남아 있다. HMS MovingPlatform/PlatformRigidbodyMovement와 SYM 물리는 현재 좌표·운반·효과 계약이 전부 같지 않다. 보호 Back/BackFixed와 Temporary 코드는 새 SYM prefab에서 제외하지만 보호 독립 씬의 소비자를 무단 깨뜨리지 않는다. 이 제한을 ‘모든 코드 정리 완료’로 보고하지 않는다.

## 허가와 검증 기록

현재: **9개 .cs의 기존 기능 보존 최소 확장만 이번 명세 1회 허용 / 추가13파일 정리·삭제 금지**. 사용자·정확한 파일·실제 diff·원본 GUID·검증 결과를 security.md와 실행 인계에 기록한다. 원본 .meta/프리팹/아트/공용/Packages/ProjectSettings 수정 허가로 확대하지 않는다. 이 문서는 허용 범위이며 실제 Unity/Play/빌드 통과 결과가 아니다.
