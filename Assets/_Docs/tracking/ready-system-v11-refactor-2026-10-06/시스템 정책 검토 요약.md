2026년 10월 7일 · 시스템 기획서 V1.1 검토용

이 문서는 시스템의 주요 선택지와 권장 방향을 읽기 쉽게 정리한 요약이다. **‘확정’은 사용자가 결정한 사항이며, ‘권장’은 선택을 위한 제안이다.** 권장안을 채택한 것으로 해석하지 않는다.

각 범주를 **선택할 내용 → 권장 처리 → 함께 정할 사항** 순서로 읽으면 된다. 구체적인 예외 처리·코드 근거·프리팹 연결 영향은 [상세 선택지 검토](<모호성 선택지 검토.md>)에서 확인할 수 있다.

## 먼저 확인할 네 가지

1. **기본 형태 복귀 시점 — 권장**  
   기본 형태가 들어갈 공간을 확인한 뒤 즉시 복귀한다. 껍질이 돌아오는 모습은 별도 연출로 처리한다.
   // 확정안
   // 기본 형태로 복귀할 공간에서 Q입력 이후 콜라이더로 먼저 검사한다 만약 충분한 공간 확보가 되지 않으면 Q 입력은 무시하고 불가 경고 효과음 재생 
   // 기존 상태로 복귀 가능하다면 원래 워크플로우 대로 콜라이더 상태 전환 이후 정상적으로 애니메이션 실행

2. **형태 전환 재사용 제한 — 권장**  
   전환 표현의 완료·중단·누락을 모두 종료 처리한다. 애니메이션이 없다는 이유로 Q 입력이 계속 막히지 않게 한다.
   // 확정안
   // 전환 상태(껍질 회수->커질 때, 기본 형태[껍질있는 형태]->작아질 때)에서 전환 처리 이후 콜라이더는 Q입력시 바로 해당 크기 상태를 가지고 이후 다른 크기 상태 전환에 대해서만 Q입력에 대하여 1초 쿨타임을 가지도록 한다

3. **체크포인트 저장 범위 — 확정**  
   현재 플레이어의 위치와 보유 눈물조각 수만 저장한다. 스테이지를 초기 상태로 다시 준비할지는 별도의 복구 정책이며, 초기 재준비를 권장한다.
   // 확정안
   // 스테이지 서비스가 체크포인트 저장 시점에 현재 플레이어의 위치(체크포인트 위치)와 보유 눈물 갯수를 저장 (기존 기능 그대로 유지)

4. **최종 도착 이후 순서 — 권장**  
   포포 도착을 수락하면 추격과 포획 판정을 종료한다. 이어서 최종 대화를 진행하고, 대화가 끝나면 게임 완료와 엔딩으로 넘어간다.
   // 별도의 다이얼로그 트리거를 두지 않으며 포포 그자체의 별도 트리거를 두어 포포 트리거 지점 접촉 이후 다이얼로그 실행 이후에 엔딩 컷신 진입 이후 타이틀 화면으로 복귀.

## 1. 크기 전환과 껍질 회수

### 선택할 내용

- **복귀 시점:** 입력이 성공한 즉시 / 껍질이 도착했을 때 / 애니메이션의 지정 시점.
- **회수 방식:** 실제 껍질을 이동 / 표현용 껍질만 비행 / 캐릭터 주변에서 효과만 재생.

### 권장 처리

**기본 형태가 들어갈 공간을 확인하고, 성공하면 즉시 복귀한다.** 같은 시점에 남겨 둔 껍질의 무게와 충돌 판정을 해제한다. 껍질이 돌아오는 모습은 게임 판정과 분리한 연출로 처리한다.

이 방식은 형태 전환이 언제 완료됐는지 명확하고, 연출 도중의 이동이나 피격 때문에 복귀가 다시 보류되는 상황을 줄인다.

- **기본 형태:** Collider 높이 **2m**, 폭 **1m**.

- **축소 비율:** 높이와 폭을 각각 **0.5배**로 설정.

- **점프 높이:** 기본 **2m**, 작은 형태 **3m**는 정지한 발판에서 이륙한 발 위치부터 최고점의 발 위치까지 측정한다.

// 상호작용 거리 - 거리 기반 시야각 기준 이 모든 것은 플레이어 root 오브젝트의 중심 위치. 
// 눈물 범위 - 플레이어 root 오브젝트의 중심 위치에서 3차원 구 생성하도록 한다.

이동 발판에서 뛰면 발판의 속도를 상속하므로 실제 월드 최고점은 달라질 수 있다.

## 3. 눈물 스킬의 범위와 피격 판정

### 확정된 규칙

**벽이나 사물에 가린 적은 눈물 범위와 겹쳐도 피격되지 않는다.** 범위 접촉은 후보 탐색이며, 실제 적 몸체에 직접 닿았는지 별도로 판정한다.

### 선택할 내용

- **범위 모양:** 3차원 구 / 높이가 제한된 원통 / 수평 거리.
- **거리 조건:** 적 몸체 일부가 범위에 닿음 / 지정 중심점이 범위 안에 있음.
- **직접 피격 검사:** 가까운 몸체 지점 / 중심점 / 여러 몸체 지점.
- **재기절:** 남은 시간에 2초 추가 / 2초로 갱신 / 최소 2초를 보장.

// 확정안
// 3차원 구 지름 충돌 처리는 기존 기능 그대로 가나 플레이어 오브젝트 root 중심에서 raycast를 실행한 
// 이후 가장 단순한 방법으로 적 콜라이더에 충돌하는지 검사한다 이때 해당 레이가 충돌 되었다면 눈물 피격 판정 아니라면 피격 불가 판정이다.

### 권장 처리

**반경 3m의 3차원 구**를 사용하고, 유효한 적 몸체 일부가 범위에 닿으면 후보로 잡는다. 발동점에서 가까운 몸체 지점까지 검사하여 앞에 벽·사물이 없고 해당 몸체에 직접 닿았을 때만 기절을 적용한다. 같은 적은 한 발동당 한 번만 처리한다.

현재 적 몸체는 Trigger Collider이므로 Trigger 전체를 제외하지 않는다. 실제 피격 몸체와 시야·상호작용 등의 탐지 영역을 구분한다.

재기절은 **남은 시간에 2초 추가**를 권장한다. 예를 들어 0.7초가 남았다면 재피격 후 2.7초가 된다. 쿨다운 삭제는 본문과 수정 이력에 함께 반영한다.

### 함께 정할 사항

누적 기절의 상한, 다른 적의 몸체도 눈물을 막는지, 일부만 노출된 적을 얼마나 넓게 인정할지는 별도 선택 사항이다.

## 4. 피격과 사망

### 선택할 내용

- **피해 처리:** 피해원별 처리 / 한곳에서 공통 처리.
- **조작 제한 종료:** 클립 종료 / 고정 시간 / 클립 누락 시 대체 종료.
- **사망 후 운동:** 기존 속도·중력 유지 / 속도와 몸체 운동 정지.
- 
// 확정안
조작 제한 종료: PC가 피해를 받을 시 항상 넉백도 같이 제공되어야 하고, 기획서에 서술된 바에 따르면 넉백 모션이 유지되는 동안에만 조작이 금지됨.
현재 구현은 넉백 제공 시 조작 제한 시간을 함께 제공하는 형태로 구현되어 있음.
넉백 애니메이션은 1개만 존재하므로, 넉백 애니메이션의 총 시간을 측정해, PC에게 넉백을 가하는 측에서 해당 시간을 공통으로 맞추도록 하여 기존 기능에 수정을 가하지 않는 방향을 제안하고 싶음. (또는, IKnockbackable 인터페이스에서 넉백 제공 시간을 -1로 제공할 경우 Player측에서 특정 고정값을 사용하도록 변경하는 방향도 괜찮다고 생각됨.)
사망 후 운동: 사망 여부에 관계 없이 외력(플랫폼에 실려감 등)은 받는 것으로 하되, 즉시 속도를 없애는 여부는 크게 중요하다고 생각되지 않아 현재 구현 형태를 그대로 사용하는 방향을 제안하고 싶음.
### 권장 처리

피해를 한곳에서 수락하고, 같은 시점의 여러 피해는 한 건으로 처리한다. 넉백 방향과 무적 규칙도 공통 기준으로 관리한다.

넉백의 초기 시험값은 **수평 3m/s, 상향 3m/s**로 제안한다. 실제 플레이 감각에 따라 조정할 값이며, 최종 밸런스 수치로 확정한 것은 아니다.

피격 클립이 없으면 해당 조작 제한을 정리하고, 사망 클립이 없으면 화면 전환과 자동 복구로 진행한다. 다른 메모·옵션 등의 제한까지 함께 해제하지 않는다. 사망 후에는 캐릭터의 속도와 몸체 운동을 정지하는 방향을 권장한다.

### 함께 정할 사항

진행 중 행동을 중단하더라도 이미 적용한 눈물의 기절 효과까지 취소하지 않는다. 사망한 몸체가 남아 있는 동안 발판과 압력판에 어떤 영향을 줄지는 플랫폼 정책과 함께 정한다.

### 권장 처리

**작동 중인 장치에 대한 추가 F 입력만 차단한다.** 다른 장치와 메모는 각자의 조건에 따라 사용할 수 있게 한다.

메모는 다음 기준으로 처리한다.

- 열리는 중이거나 열린 상태에서는 **F로 닫기**, **Esc로 옵션 열기**를 허용한다.
- 닫히는 중에는 캐릭터 조작과 F를 막고, 옵션 열기는 허용한다.
- 메모를 읽는 동안 낙하·발판 운반·피격 등 물리는 계속 진행한다.
- 비치명 피격이면 메모를 유지하고, 사망하면 즉시 취소한다.
- 옵션이 위에 열려 있으면 F 입력을 아래 메모로 전달하지 않는다.

## 6. 애니메이션의 중단과 재실행

### 선택할 내용

- **중단된 일회성 표현:** 폐기 / 남은 부분부터 재생 / 처음부터 재생.
- **같은 행동 재실행:** 기존 표현 유지 / 새 표현으로 재시작.
- **착지 직후 점프:** 착지 표현 중단 / 착지 종료까지 점프 대기.


// 확정안
// 중단된 일회성 표현: 폐기
// 같은 행동 재실행: 새 표현으로 재시작
// 착지 직후 점프: 착지 표현 중단

### 권장 처리

중단된 일회성 표현은 폐기하고 현재 이동·공중 상태에 맞는 표현으로 돌아간다. 새 행동이 실제로 수락됐을 때는 애니메이션을 처음부터 재생한다. 거절된 입력으로 표현을 다시 시작하지 않는다.

점프가 수락되면 착지 애니메이션을 즉시 중단한다.

### 공동 확인 기준

형태 전환·피격·사망 클립은 아트와 프로그래머가 실제 길이, 반복 여부, 종료·중단·누락 처리, 옵션 정지를 함께 확인한다. 조작 복구나 화면 전환이 누락된 클립 때문에 계속 대기하지 않아야 한다.

## 7. 체크포인트와 다시 등장

### 확정된 저장 범위

체크포인트에는 다음 두 값만 저장한다.

1. **현재 플레이어의 월드 위치**
2. **현재 보유한 눈물조각 수**

적·장치의 위치나 진행 단계, 남은 시간, 체력, 형태, 능력, 대화 기록은 체크포인트에 저장하지 않는다.

// 확정안
// 체크포인트 저장 범위 - 현재 플레이어의 위치와 보유 눈물조각 갯수
// 저장시점 - 현상태 유지 체크포인트 닿았을 때를 즉시 기준점으로 삼음
// 복원시점 - 체크포인트에서 저장된 위치와 눈물조각 갯수만 복원하고, 스테이지는 초기 상태로 다시 준비
### 선택할 복구 방식

- 스테이지를 초기 구성으로 다시 준비한다.
- 현재 스테이지의 각 기능에 초기화 명령을 보낸다.
- 사망 당시의 월드 상태를 유지한다.

### 권장 처리

**스테이지를 초기 상태로 다시 준비한 뒤 위치와 눈물조각만 복원한다.** 반쯤 열린 장치나 적의 중간 행동은 저장·복구하지 않는다. 압력판은 새로 등장한 캐릭터의 실제 접촉으로 다시 판정한다.

능력 해금과 완료한 대화의 유지 여부는 한 판의 실행 상태로 별도 검토한다. 이를 체크포인트 저장 항목으로 추가하지 않는다.

### 배치 시 확인할 사항

현재 위치에 기본 형태로 다시 등장할 수 있어야 한다. 작은 형태 전용 통로나 초기화되는 이동 장치 위에 체크포인트를 두면 복원 위치가 막힐 수 있으므로, 초기 월드에서도 안전한 영역을 사용한다.

## 8. 플랫폼과 장치의 예외 처리

### 선택할 내용

- **캐릭터·껍질 끼임:** 장치 정지 / 밀어내기 / 압사 처리.
- **발판 생성 위치 점유:** 비충돌 상태로 대기 / 밀어내기 / 해당 몸체와 충돌 예외.
- **붕괴 시점:** 1초 경고 종료 때 지지 해제 / 1.25초 낙하 때 지지 해제.

// 확정안
// 캐릭터, 껍질 끼임 - 만약 생성, 소멸 발판에서 해당 플레이어가 정확히 윗면에 착지 하지 않고 오브젝트 콜라이더 바운더리 영역 안에 실제 조작 가능한 플레이어 콜라이더 바운더리와 껍질 콜라이더가 해당(플레이어) 콜라이더 높이 기준 1/4 이상 들어가 있는 상태에서는 발판 별도 사망 도트윈의 DOMove메서드의 큐빅 이징트윈과 기존 사망 애니메이션을 실행 시킨다 만약 바운더리가 해당 콜라이더 내에 충돌 판정이 1/4미만이라면 착지 판정처리 한다.
// 1초 경고 종료와 동시에 콜라이더 비활성화, 붕괴 애니메이션 실행, 이후 붕괴한 플랫폼에 한에서 별도의 재생성을 하지 않는다.

### 권장 처리

캐릭터나 껍질이 끼면 이동을 멈추고, 장애물이 해제되면 원래 목표를 향해 다시 움직인다. 발판의 생성 위치를 누군가 점유하고 있으면 비충돌 상태로 기다렸다가 공간이 비었을 때 충돌을 켠다. 이 경우 실제 생성 주기가 늘어날 수 있음을 명시한다.

작은 형태로 붕괴 발판 위에 있다가 기본 형태가 되면 현재 무게와 접촉으로 붕괴를 시작한다. **붕괴 시작 후 1.25초까지 지지를 유지**하고, 그 시점에 충돌을 해제한다. 경고 1초가 끝난 뒤의 0.25초도 밟을 수 있게 한다.

## 9. 일반 적의 행동과 기절

### 확정된 제외 기능

**일반 적 처치와 처치 후 기름 생성은 제거 대상이다.** 머리 밟기 처치 기능을 본편 선택 기능으로 남겨 두지 않는다. 배치된 기름 바닥은 유지한다.

### 선택할 내용

- **눈물의 기절 대상:** 일반 적만 / 추격 무리까지 포함.
- **추적·복귀 경로:** 작성한 X/Y 축 유지 / 바닥 XZ 이동 / 경로 탐색.

// 확정안 
// 기절 대상 - 스테이셔너리 추적 개체의 일반 적만 눈물 효과 부여
// 추적 상태 - 기존 구두 명세에서 기본 추적 상태 오브젝트를 뚫는 문제를 처리하기 위해 투명화를 넣어도 Z축이 겹치는 카메라 뎁스에 따른 Z 버퍼 문제 때문에 적 객체의 추적 상태는 기능 제거 대상 즉, x,y평면 순찰과 Idle, 기절 상태만 가짐
// 적은 더이상 체력을 가지지 않으므로 플레이어가 죽일수 없음.
### 권장 처리

눈물은 일반 적만 기절시키고, 추격 무리는 기존 추격 규칙을 유지한다. 일반 적의 추적과 복귀는 작성된 X축 또는 Y축을 따른다. 활동 범위와 이동 가능한 지형을 벗어나지 않는다.

장애물을 우회하는 추적이 본편에 필요해지면 XZ 이동이나 경로 탐색을 별도로 선택한다.

## 10. 추격 종료와 게임 완료

### 선택할 내용

- **완료 시점:** 포포 도착 즉시 / 도착 후 최종 대화 완료.
- **동시 도착·포획:** 도착 우선 / 포획 우선 / 통과 시각 비교.

### 권장 진행 순서

**포포 도착 수락 → 추격 이동·포획 판정 종료 → 최종 대화 → 게임 완료 → 엔딩**

같은 물리 갱신에서 도착과 포획이 함께 발생하면 도착을 우선하는 방향을 권장한다. 이미 앞선 갱신에서 사망한 캐릭터의 도착은 인정하지 않는다.

다시 등장하는 위치는 추격 시작선 이전에 확보하여 시작선을 다시 통과할 수 있게 한다. 실제 저장 위치를 시작선 이전의 안전한 영역에서 확보하고, 저장할 때 과거의 고정 위치로 바꾸지 않는다.

// 확정안
// 완료 시점 - 도착 이후 최종 다이얼로그 트리거 작동(이 시점에 적 추적 즉시 종료) 이후 엔딩 컷신 트리거 작동 이후 타이틀 화면으로 복귀 
// 동시 도착, 포획 시점- 포획 우선이 선행 -> 체크포인트 재시작 
// 다이얼로그 시스템은 월드시간 정지가 아님 다이얼로그 시퀸스 이벤트 트리거는 대화창 영역에만 별도 콜라이더를 두어 L클릭 혹은 키보드 Enter키로 이벤트 처리.

## 11. 기획 문서 정리

### 편집 오류 정리

- 1.2의 껍질 회수 문장 중복을 제거한다.
- 목차와 본문의 2.3 제목을 통일한다.
- 기름 규칙의 잘못된 **2.3 참조를 2.2로 수정**한다. 현재 제외된 적 기름 생성 규칙은 활성 명세에서 정리한다.
- 삭제 이력과 본문에 남은 적 관련 예외를 대조한다.
- 능력 조작 안내의 구성·본문·수정 이력을 일치시킨다.

### 선택할 안내 방식

능력 획득 대화에서만 안내 / 해금된 능력을 HUD에 상시 표시 / 획득 시 일시 안내.

// 확정안
// 안내 방식 - 능력 획득은 기존 트리거 접촉 이전에는 비활성화(오파시티 음영처리) 상태로 표시 이후 트리거 접촉시 UI 활성화 상태 유지
### 권장 처리

능력 조작 안내는 **획득 시 연결된 대화에서 제공**하는 방향을 권장한다. 체력·눈물조각과 가까운 상호작용 대상 안내는 기존 화면 표시 범위로 구분한다.
