## 목표·근거·경계

목표는 최신 시스템 자료와 직접 선택을 프로젝트 기획에 반영하고, 중복/폐기 코드를 삭제할 실행 순서·이관·새 prefab 연결·완료 기준을 마련하는 것이다. 본편 레벨/아트/보호 파일을 임의 재작성하지 않는다. 체크포인트는 최신 추가 지시에 따라 Position/Fragments 두 값뿐이며 원본의 월드 저장 요구는 적용하지 않는다.

근거는 새/이전 DOCX 실제 본문·색상·취소선·수정 이력·원본 PDF40쪽, `Assets/_Code`206파일, Unity native prefab 계층/설치 데이터, 전체161자산의 재귀 스크립트 의존526건이다. 코드 토큰/텍스트 GUID 참조와 native 재귀 의존의 의미를 구분한다. 반사/동적 로드/메뉴의 미사용은 이 숫자만으로 단정하지 않는다.
