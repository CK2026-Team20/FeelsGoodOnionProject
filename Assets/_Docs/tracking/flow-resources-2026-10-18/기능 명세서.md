# 리소스 참조와 실제 씬 왕복 검증

## 목표와 근거

2026-10-18 사용자 직접 요청: 제공 음악·컷신 원화를 연결하고 새 게임부터 UI, 타이틀 복귀, 재진입 흐름을 실제 실행하여 재현된 흐름 오류를 해결한다. 현재 지정 시스템 V1.6, UI Ver2.1, StageService/CinematicCatalog 및 실제 자산을 근거로 한다.

## 범위와 제약

공식 Unity 플러그인으로 native 자산 연결과 Editor Play를 수행한다. 보호 아트/import/공유 설정을 수동 변경하지 않으며 기존 미커밋 변경을 보존한다. Git 작업은 하지 않는다. 기존 6구간은 동일 Stage1 음악을 참조했으므로 현재 music.stage1 자산으로 복구하며 새 음악 배분 규칙을 만들지 않는다. 컷 순서·문구·4초 표시 시간은 유지한다.

## 완료 기준

- 음악6참조와 컷신8참조의 실제 자산 로딩·저장 확인.
- 실제 Bootstrap→Title→Opening→Playing, 옵션 정지/해제 및 Title→새 게임 왕복 확인.
- Ending과 재시도 관련 실제 전환, 출력 중복 및 세션 잔존 검사.
- 재현 오류의 원인·수정과 수행한 입력 경로를 코드 리뷰/검증 문서에 기록. 합성 입력·버튼 이벤트·API 준비와 사람 직접 플레이를 구분한다.
