# 체크포인트 배치 검사 시점 변경

## 2026-11-03 직접 지시: 체크포인트 배치 검사는 에디터 전용

플레이어 Collider 접촉 때문에 체크포인트 저장이 거절되지 않도록 런타임 초기 등록·접촉 저장·실제 스폰의 지면/겹침 검사를 제거한다. 배치 검사는 Edit Mode Inspector와 파랑/빨강 Gizmo에서만 수행하며 Play 중에는 실행하지 않는다. 발바닥 좌표 계산, 필수 참조/스냅샷 유효성, 초기 무음 등록·중복 활성화 억제는 유지한다. 대체 위치 없음. 이전 문서의 런타임 공간 검사 요구를 대체한다. 상세: Assets/_Docs/tracking/checkpoint-editor-validation-2026-11-03/.

목표: 런타임에 접촉 중인 플레이어/동적 Collider가 스폰 배치 검사에 잡혀 체크포인트 저장을 막는 경로 제거.

참고: StageService.RegisterInitialCheckpoint/AcceptCheckpoint, StageTrigger.CheckpointPose, SessionActorHost.Spawn, CheckpointSpawnPoint, SpawnPlacement, StageTriggerEditor, planning-index.md.

제약: 사용자 미저장 씬과 아트/프리팹 불변. 발바닥 좌표와 대체 위치 없음 정책 유지. 지면/공간 검사만 제거하며 참조·형상 계산·유한 수치 등 내부 계약 검증은 유지.

완료 기준: 런타임 공간 검사 호출 0, 물리 검사 API는 UNITY_EDITOR 전용, 에디터 배치 검사 유지, 장애물/지면 없음 상태에서도 초기 저장 및 복귀 위치 보존, 컴파일 통과.
