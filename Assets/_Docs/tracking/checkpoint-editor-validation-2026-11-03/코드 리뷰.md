- SessionActorHost의 최초 정렬/Normal 준비 후 두 번 수행하던 SpawnPlacement.Require 제거.
- 미사용 RequireSpawnPlacement/RequirePlacement/Require API 삭제. 단순 무조건 성공 반환으로 오류를 숨기지 않음.
