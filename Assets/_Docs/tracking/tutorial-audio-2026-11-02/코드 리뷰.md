## 독립 리뷰와 반영

읽기 전용 독립 리뷰에서 발견한 2건을 수정했다.

- 추격 저장 이전 다른 체크포인트를 통과하지 않으면 초기 회전이 재적용될 수 있었음 → 추격 저장 성공도 실제 저장 상태로 표시하여 기존 복귀 회전 보존.
- 엔딩만 즉시 음악 전환하는 예외 → 다른 BGM처럼 이전 곡의 페이드아웃 완료 후 시작하여 중첩·갑작스러운 끊김 방지.

최초 컴파일에서 Unity 6000.6의 GetInstanceID 사용 금지 발견 → 세션 내 객체 identity token으로 대체. 최종 컴파일 오류 없음.

## 수명과 데이터

튜토리얼 장부의 유일한 소유자는 GameSessionRuntime. ViewModel은 View 참조 없음. CoreWorldBinding이 획득한 프롬프트 목록으로만 해제하며 View는 자기 구독/tween만 회수한다. Animator는 비활성화 상태 유지 설정을 사용한다.

음악은 기존 앱 AudioService 단일 소유. StageService는 음악 클립/콜백을 소유하지 않는다. 새로운 초기 등록은 CheckpointCaptured를 발행하지 않는다. 정규 도달과 추격 저장은 초기 등록과 구분한다.

## 남은 범위

전체 SFX의 재생 조건 정합화는 이번 승인 범위 밖이다. 특히 FormChange가 현재 Sfx_Ability를 참조하고, 해금/조각 수집이 새 시트의 4→5 규칙과 별도로 동작하는 점은 후속 정합화 대상이다. 발소리/기름/공간음/환경 Loop 및 미정 3개 행은 별도 검수한다.

실제 물리 접촉 전체 경로·사용자 입력 전체 플레이·독립 씬 직접 테스트·Player 빌드·팀 청취 검증 완료로 확대하지 않는다.
