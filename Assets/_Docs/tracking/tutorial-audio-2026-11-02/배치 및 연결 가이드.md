# 튜토리얼 UI 배치 및 사운드 연결

## 튜토리얼

프리팹 폴더: Assets/_Prefabs/UI/Tutorial/

애니메이션: Assets/_Animations/Tech_SYM/Tutorial/. 스프라이트는 Assets/_Art/UI/Tutorials/의 원본 시트에 포함된 Sprite를 직접 참조한다. 별도 PNG 사본을 만들지 않는다. Image의 초기 크기는 참조하는 원본 Sprite의 잘린 영역 크기다.

| 프리팹 | 안내 | 주기 |
|---|---|---|
| Tutorial_Move | A/D 이동 | 2.6667초 |
| Tutorial_Jump | Space 점프 | 1.3333초 |
| Tutorial_Tear | E 눈물 | 5.3333초 |
| Tutorial_Form | Q 크기 전환 | 10.6667초 |

1. 원하는 프리팹을 Tutorial 씬 월드 아래 배치한다. 관리자 오브젝트 아래 월드를 묶지 않는다.
2. Root는 로직 담당, Trigger 자식은 BoxCollider 접촉 영역, Visual은 World Space Canvas다. Visual/Body/Image의 Image 스프라이트를 Animator가 교체한다.
3. Root 위치와 Trigger의 중심·크기로 발동 범위를 정한다. 기본 Box는 3×3×3m이며 실제 레벨 통과 경로에 맞춰 조절한다. 현재 플레이어 Collider와 물리 충돌 매트릭스가 접촉을 허용해야 한다.
4. Visual의 위치(기본 Root 위 2m)·배율(기본 0.0025)을 조절한다. Image는 원본 픽셀 크기와 종횡비를 유지한다. 표시 크기가 다른 프레임을 임의로 동일 크기 이미지로 재제작하지 않았다.
5. Root View의 등장 시간은 기본 0.3초, 0이면 즉시 표시다. 표시 후 상하 이동은 없고 카메라를 향한다.
6. 정상 Bootstrapper→Core+Stage 진입 시 CoreWorldBinding이 자동으로 현재 Actor·세션·Control·게임 출력 Camera를 주입한다. Scene에 UI 담당을 별도로 등록할 필요는 없다. 단, Play 진입 전에 프리팹을 배치해야 한다.
7. 현재 씬 직접 테스트 전용 경로는 이번 튜토리얼 조립 대상으로 검증하지 않았다. 정상 통합 진입으로 확인한다.

프리팹은 제작했지만 씬 배치는 수행하지 않았다. 실제 Play 검증에 사용한 __TutorialValidation_* 객체는 런타임에만 추가했으며 Play 종료로 제거했다. 사용자 최종 레벨 위치·크기 검수는 남아 있다.

## BGM

Bootstrapper AudioRoot → AudioRuntimeHost → 소리 목록(AudioCueCatalog)의 **스테이지 음악**에서 SceneAsset, 일반 음악, 기본 음량, 전환 시간을 연결한다. Tutorial·Stage_2·Stage_4·Stage_quarter에는 현재 Bgm_Normal_Stage.wav를 기본 연결했다. 새로운 스테이지는 여기에 추가한다. 이름 문자열을 직접 입력하지 않는다.

카탈로그의 기존 Title/Opening/Chase/Ending 용도 연결과 Respawn 용도는 유지·추가되어 있다. 구간의 시작·끝 체크포인트에는 음악을 연결하지 않는다. 기존 소리 용도 ID/enum 번호는 호환을 위해 보존했다.

## 체크포인트

최초 시작 위치는 StageService의 첫 구간 시작 체크포인트다. 게임 시작 시 무음으로 저장/활성 등록되므로 그 지점에 다시 접촉해도 효과음이 나지 않는다. 별도 시작 Transform은 필요 없다.

각 StageTrigger의 **체크포인트 소리**에서 구간 기준/재생/무음을 선택한다. 기본 구간 기준은 시작만 재생하고 끝은 무음이다. 숨겨진 종료 지점은 무음을 명시해도 된다. 재생을 선택해도 초기 등록·재접촉은 소리가 나지 않는다.

새 게임은 장부를 초기화하고 사망 재시도는 장부를 유지한다. 리스폰 소리는 사망 재시도가 성공하여 Playing으로 복귀했을 때 한 번 재생한다.
