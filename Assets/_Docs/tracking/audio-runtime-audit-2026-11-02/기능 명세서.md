# 전체 사운드 재생 경로 조사와 눈물 차폐 수정

## 목표·참고·제약·완료 기준

명세30종 전체의 음원 연결, 발생 메서드/이벤트, 실제 재생 호출, 반복/종료/해제 경로를 확인한다. 적끼리 겹쳐 눈물 피격이 차단되는 문제는 수정한다. 참고는 Audio/사운드_원본_2026-11-02.csv, AudioCueCatalog, AudioService/AudioFlowBinding/CoreWorldBinding, HMS TearSkill 공개 targetValidator, PlayerBridgeService 및 EnemyActor다.

사용자가 해결한 Sprite와 미저장 Tutorial 씬, 보호 HMS·아트·공용 프리팹은 변경하지 않는다. 공식 Unity 도구로 Play 없이 검사하며 Git 작업은 하지 않는다. 전체 오디오 신규 구현은 이번 조사 결과와 구별한다. 완료 기준은 30종 대조표, 실제 차폐 검사 회귀, 카탈로그 및 기존 통합 자동 검사다.

## 변경 규칙

OverlapSphere의 일반 적 HurtCollider 후보와 동일 개체 중복 제거는 유지한다. 차폐 검사에서는 모든 EnemyActor 소속 Collider를 무시하며 일반 지형/벽은 유지한다. 플레이어와 적 몸체가 겹치는 경우도 허용한다. 대상 몸체의 가장 가까운 표면까지만 검사하여 대상 뒤의 벽이 차폐로 오인되지 않게 한다. 적 접촉 피해와 Physics 레이어 충돌 설정은 바꾸지 않는다.
