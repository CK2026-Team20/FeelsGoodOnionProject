## 실패 후 수정·재실행

- 최초 합성 이동 검사는 프로젝트의 방향키 대신 A를 사용해 실패했다. 실제 키 바인딩에 맞춰 수정 후 통과했다.
- ESC는 공통 루트 비활성화 문제를 수정 후 통과했다.
- 사망 재생성 검사는 Actor generation 변경 순간의 Despawn을 완료로 오인했다. 새 Actor 준비까지 기다리도록 검사 조건을 수정 후 통과했다.
- 초기 카메라 도구 캡처는 Overlay UI를 포함하지 않아 화면 검증 자료로 쓰지 않았다. native ScreenCapture로 `final-debug-panel.png`를 확보했다. 이 캡처에서 긴 피해원 글자 겹침을 발견해 보완했으며 최신 화면 재촬영은 대기다.
- 전체 `git diff --check`는 Unity 기본 직렬화의 빈 `m_Name: ` 뒤 공백을 보고했다. 승인되지 않은 YAML 텍스트 보정은 하지 않는다. 코드·Markdown 범위는 별도로 검사한다.

## 차단·미완료

- 실제 본편 타이틀→오프닝→ESC 복귀 검사 도중 Unity 네이티브 GPUResidentDrawer/ObjectDispatcher 충돌. `title-play-checks.json`의 연결 끊김은 통과가 아니다. `editor-native-crash.txt`에 해당 스택만 보관했다.
- 공식 `unity open . --until-ready`가 Scene Backup Detected 창으로 중단됐다. 사용자에게 Keep Backups를 눌러 보존·재개하도록 요청했다. 공식 Unity 도구만 허용된 작업 경계로 다른 UI 자동화를 사용하지 않았다.
- 직접 테스트→타이틀 복귀의 명시 해제 마지막 수정은 컴파일/실행 재확인 필요.
- Opening/Ending 취소 서비스8시나리오 검사 스크립트 `CinematicFlowChecks.cs`는 준비됐으나 아직 실행하지 않았다. 실제 엔딩 화면/입력 검증과 별개다.
- 일반 비개발 Windows 빌드와 Player 어셈블리의 DebugTesting 타입 제외 검증 미실행. `ReleaseBuildCheck.cs`는 준비됐다. #if UNITY_EDITOR 정적 확인만으로 빌드 통과를 주장하지 않는다.
- 새 사용 문서의 Unity .meta 자동 생성·최신 UI 재촬영·실제 포인터 클릭/휠, 회전·배율 적의 자연 물리 접촉, 전체 본편 회귀/레벨 자연 동선 QA는 미완료다.
