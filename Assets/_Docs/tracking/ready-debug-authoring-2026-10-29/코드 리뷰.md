# 구현 코드 리뷰

2026-10-29. 승인된 구현과 기존 미커밋 자료를 분리해 검토했다. 기능 구현과 실행 검증 완료는 구별한다.

## 설계·범위

- 직접 씬 테스트는 실제 SessionActorHost·PlayerBridgeService·GameSessionService·GameplayControlService를 조립한다. 타이틀/컷신/전체 Stage 등록이 필요 없는 Editor 전용 진입 어댑터다.
- 화면은 DebugPanelViewModel 명령·상태에 바인딩한다. View는 피해·회복·해금 판정을 소유하지 않는다. 로그 수집은 별도 제한 버퍼이며 Unity 스레드 로그를 잠금으로 보호한다.
- F1은 커서 표시 이유만 전달한다. 옵션/디버그 Pause는 독립 토큰으로 해제하며 숨김은 게임 상태를 바꾸지 않는다.
- 적 방향·지형·축/단위 배율 제약 소비자를 함께 제거했다. 실제 Body/앵커 참조와 유한 수치 검사는 남긴다. 보호 prefab·기존 변환은 유지한다.
- 피해 플랫폼은 구체 타입과 정수 피해만 전달한다. PlayerBridgeService에서 무적을 먼저 판정하고 기존 사망 연출 경로를 재사용한다. 타입 판정에 리플렉션/이름 문자열을 사용하지 않는다.
- TitleScenePresentation은 기존 앱 Camera/Brain을 빌려 고정 구도를 적용·반환한다. 타이틀 전용 출력 Camera를 중복 생성하지 않는다.
- Inspector 편집은 HMS 설정 원본과 실제 적용값을 함께 변경한다. 보호 HMS 소스/프리팹을 변경하거나 실행 때 기준값을 강제하지 않는다.

## 후속 씬 전환 순서 검토

기존 Title 선행 언로드에서 네이티브 GPUResidentDrawer/ObjectDispatcher 충돌을 재현했다. 렌더 설정 변경은 채택하지 않았다. GameFlowService는 페이드 뒤 Core·Stage를 먼저 로드하고 Title을 해제한 뒤 InitializeSession을 실행한다. 프레임 대기 실험 코드는 제거했다.

독립 검토에서 차단 결함은 발견하지 못했다. 부분 로드는 실제 로드 씬을 Recover에서 정리하며, 기존 Title 재사용은 sceneLoaded를 다시 발생시키지 않아 중복 바인딩하지 않는다. Title 언로드 시 빌려 쓴 Brain 상태를 반환한 후 세션 카메라를 바인딩한다. 이 예외 경로의 검토를 실패 주입 실행으로 표현하지 않는다.

원본 렌더 설정에서 실제 오프닝 복귀9항목을 두 번 통과했고, 오프닝 Skip→Playing→ESC 복귀7항목 및 서비스 취소8시나리오도 통과했다. Unity6000.6.0f1과 렌더 설정을 유지한다. 빌드 중 자동 생성된 렌더 자산 직렬화는 output에 백업하고 복원했다.

## 보존

기준선 대비 _Art·_Prefabs·Tech_HMS·Packages·ProjectSettings 보호 파일1,218개 변경0. Prototype의 기존 Transform 블록과 위치·회전·스케일 override 동일. 본편 씬 변경은 피해 컴포넌트 연결/중복 비활성화/폐기 필드 override 제거에 한정한다. 소유 Title 씬에는 빈 월드·구도 기준점을 추가했다. 원본 prefab Apply/Unpack·재생성은 하지 않았다.
