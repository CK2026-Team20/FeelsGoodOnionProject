# 구현 준비 문서 검토

2026-10-29. 소스 수정 리뷰가 아니라 명세·계획의 구현 경계 검토다.

- 현재 BootstrapEntryRoute/BootstrapPlayModeHook와 IntegrationEntrySettings는 등록 Stage·세션 경로에 의존한다. 독립 테스트 시작 경계를 분리하는 T1을 지정했다.
- CursorPresentationBinding이 기존 커서 출력 소유자다. 디버그 View가 매 프레임 Cursor를 직접 덮어쓰지 않도록 T5에 통합 책임을 뒀다.
- EnemyMotor의 XYZ 이동 계산 자체보다 축/방향/지형/회전/scale 검사가 배치를 제한한다. 검사만 삭제하고 지형 보정 코드를 남기지 않도록 T2에 제거 소비자를 포함했다.
- PlayerBridgeService는 피해1과 HP==1 사망 준비를 가정한다. T3은 설정 피해량과 무적 우선, 기존 사망 완료·데드존 예외를 함께 다룬다. 애니메이션은 플랫폼으로 옮기지 않는다.
- 현재 빌드 메뉴는 Development 빌드다. 이것만으로 일반 빌드의 테스트 기능 제외를 증명하지 않도록 T7에 별도 비개발 빌드 검증을 명시했다.

독립 의도 검토에서는 문서 갱신을 막는 미결정0건을 보고했다. 최종 문서 독립 검토 결과는 테스트 및 검증 항목에 기록한다. 코드·씬 실행 성공을 이 문서로 주장하지 않는다.
