# 타이틀·직접 씬 테스트·적/피해 작성 개선

2026-10-29. 질의응답과 승인 계획에 따른 구현 명세다. 구현 결과와 실제 검증 범위는 같은 폴더의 테스트 및 검증 항목으로 구분한다.

현재 정본은 프로젝트 루트의 `.dryforge/spec.md`, 구현 순서는 `.dryforge/plan.md`, 권한·인계는 `.dryforge/handoff.md`다. 세 문서는 같은 작업을 정의하며 이 요약이 별도 기능 정본은 아니다.

확정 요구는 다음과 같다.

1. 현재 작업 씬의 시작점과 테스트 객체만으로 실행한다. 타이틀·컷신·전체 Stage/체크포인트 구성이 필요하지 않다. 실제 게임 로직을 재사용한다.
2. F1은 로그/버튼 패널 표시만 바꾼다. 게임 진행과 플레이어 입력은 유지하며 커서를 표시한다. ESC 옵션의 기존 정지와 명시적 디버그 Pause는 별개다.
3. 로그는 Unity 로그를 별도 인게임 UI에 표시한다. 검은 좌상단 읽기·스크롤 View만 제공하며 검색·입력·명령 콘솔은 없다. 단순 조작 패널은 실제 상태 표시, 회복/조각/해금/무적, 지정 지점 이동, 플레이어 재생성, 실제 플랫폼 피해 적용, Pause/재개를 제공한다.
4. 적 Root/Start/End는 고정하고 Body만 이동한다. 첫 방향·축 제한·지형 검사·회전/단위 스케일 거절을 제거한다. 피해 플랫폼은 구체 타입과 Inspector 피해량만 전달하고 플레이어가 연출을 소유한다. 무적이면9999도 적용하지 않는다.
5. 빈 타이틀 배경 준비와 불투명 Canvas 가림 제거, 컷신 중 ESC 옵션을 통한 타이틀 복귀를 반영한다. 이동1.8·점프1/작은0.5는 초기 기준이며 Inspector 수정값이 실제 실행값이다. 기존 아트/프리팹/씬 변환은 정규화하지 않는다.

이전 계획은 `output/Tech_SYM/Documents/ready-debug-authoring-2026-10-29/previous-plan/`에 보존했다. 이전 생성 이미지의 검색창·큰 로그 도구 구성은 최종안이 아니다. 최근 두 첨부 레퍼런스의 단순 UI를 기준으로 한다.

## 책임과 실제 연결

- DirectSceneTestEntry/Runtime: Editor 시작 선택, 실제 SessionActorHost와 PlayerBridge 조립, 현재 씬의 선택적 객체 연결, 플레이어만 재생성, 임시 출력 해제.
- DirectSceneTestPresentation: 기존 옵션 View/서비스, 별도 테스트 음량 저장소, 단일 CursorPresentationBinding과 디버그 화면 조립. 사용자 PlayerPrefs를 쓰지 않는다.
- DebugLogBuffer: Unity 로그 수집과 제한된 메모리 보관. DebugPanelViewModel: 실제 상태 표시·공개 서비스 명령. DebugPanelView: 상태 바인딩·포인터 입력만 담당.
- EnemyActor/Motor: Root와 Start/End는 고정, Body는 편집한 위치에서 End로 먼저 이동. 재준비는 편집한 Body 로컬 위치로 복귀. Root 회전·배율은 앵커 위치와 외형에 반영하고 Body 이동 거리는 월드 m/s로 계산한다.
- Pot/Gratang/Burner: 기존 배치의 실제 활성 피해 Trigger에 구체 타입을 연결했다. PlayerBridgeService가 수락된 피해원과 피해량을 보유하며 리플렉션을 사용하지 않는다.
- TitleScenePresentation: 별도 Title World/Camera Anchor 구도와 앱 출력 카메라를 연결한다. Background/KitchenBand Image만 표시 해제했고 배경 아트는 제작하지 않았다.
- PlayerTuningSynchronization: 소유 Editor Inspector에서 기존 HMS 속도/폼 설정 원본을 함께 갱신한다. HMS 원본 코드와 프리팹은 변경하지 않는다.

## 구현된 명령

회복, 조각 최대 충전, 능력 해금, 디버그 무적, 시작점 이동, 이동 지점 선택/이동, 플레이어 재생성, 실제 피해원 선택/피해 적용, 일시정지/재개다. F1 숨김은 설정·상태·정지 소유권을 초기화하지 않는다. 사망·교체 중 낡은 플레이어 명령은 거절한다. 검색·명령 입력·복사·필터·로그 지우기 기능은 없다.

## 자산 범위

Prototype 씬에 Pot12개·Burner12개·Gratang1개 구체 피해 컴포넌트를 연결하고 중복된 빈 부모의 기존 DamageFloor11개를 비활성화했다. 보호 원본 prefab에 Apply하지 않았다. DirectSceneSmoke는 시작점·바닥·Pot 테스트 객체만 둔 소유 예제 씬이며 본편 빌드 목록에 추가하지 않는다.
