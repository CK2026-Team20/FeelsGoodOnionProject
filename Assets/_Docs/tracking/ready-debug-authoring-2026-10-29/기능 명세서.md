# 타이틀·직접 씬 테스트·적/피해 작성 개선

2026-10-29. 질의응답과 승인 계획에 따른 구현 명세다. 구현 결과와 실제 검증 범위는 같은 폴더의 테스트 및 검증 항목으로 구분한다.

현재 정본은 프로젝트 루트의 `.dryforge/spec.md`, 구현 순서는 `.dryforge/plan.md`, 권한·인계는 `.dryforge/handoff.md`다. 세 문서는 같은 작업을 정의하며 이 요약이 별도 기능 정본은 아니다.

확정 요구는 다음과 같다.

1. 현재 작업 씬의 시작점과 테스트 객체만으로 실행한다. 타이틀·컷신·전체 Stage/체크포인트 구성이 필요하지 않다. 실제 게임 로직을 재사용한다.
2. F1은 로그/버튼 패널 표시만 바꾼다. 게임 진행과 플레이어 입력은 유지하며 커서를 표시한다. ESC 옵션의 기존 정지와 명시적 디버그 Pause는 별개다.
3. 로그는 Unity 로그를 별도 인게임 UI에 표시한다. 검은 좌상단 읽기·스크롤 View만 제공하며 검색·입력·명령 콘솔은 없다. 단순 조작 패널은 실제 상태 표시, 회복/조각/해금/무적, 지정 지점 이동, 플레이어 재생성, 실제 플랫폼 피해 적용, Pause/재개를 제공한다.
4. 적 Root/Start/End는 고정하고 Body만 이동한다. 첫 방향·축 제한·지형 검사·회전/단위 스케일 거절을 제거한다. 피해 플랫폼은 구체 타입과 Inspector 피해량만 전달하고 플레이어가 연출을 소유한다. 무적이면9999도 적용하지 않는다.
5. 빈 타이틀 배경 준비와 불투명 Canvas 가림 제거, 컷신 중 ESC 옵션을 통한 타이틀 복귀를 반영한다. 이동1.8·점프1/작은0.5는 초기 기준이며 Inspector 수정값이 실제 실행값이다. 기존 아트/프리팹/씬 변환은 정규화하지 않는다.

이전 계획은 `output/Tech_SYM/Documents/ready-debug-authoring-2026-10-29/previous-plan/`에 보존했다. 이전 생성 이미지의 검색창·큰 로그 도구 구성은 최종안이 아니다. 최근 두 첨부 레퍼런스의 단순 UI를 기준으로 한다.

## 책임과 실제 연결

- DirectSceneTestEntry/Runtime: Editor 시작 선택, 실제 SessionActorHost와 PlayerBridge 조립, 현재 씬의 선택적 객체 연결, 플레이어만 재생성, 임시 출력 해제.
- DirectSceneTestPresentation: 기존 옵션 View/서비스, 별도 테스트 음량 저장소, 단일 CursorPresentationBinding과 디버그 화면 조립. 사용자 PlayerPrefs를 쓰지 않는다.
- DebugLogBuffer: Unity 로그 수집과 제한된 메모리 보관. DebugPanelViewModel: 실제 상태 표시·공개 서비스 명령. DebugPanelView: 상태 바인딩·포인터 입력만 담당.
- EnemyActor/Motor: Root와 Start/End는 고정, Body는 편집한 위치에서 End로 먼저 이동. 재준비는 편집한 Body 로컬 위치로 복귀. Root 회전·배율은 앵커 위치와 외형에 반영하고 Body 이동 거리는 월드 m/s로 계산한다.
- Pot/Gratang/Burner: 기존 배치의 실제 활성 피해 Trigger에 구체 타입을 연결했다. PlayerBridgeService가 수락된 피해원과 피해량을 보유하며 리플렉션을 사용하지 않는다.
- TitleScenePresentation: 별도 Title World/Camera Anchor 구도와 앱 출력 카메라를 연결한다. Background/KitchenBand Image만 표시 해제했고 배경 아트는 제작하지 않았다.
- PlayerTuningSynchronization: 소유 Editor Inspector에서 기존 HMS 속도/폼 설정 원본을 함께 갱신한다. HMS 원본 코드와 프리팹은 변경하지 않는다.

## 구현된 명령

회복, 조각 최대 충전, 능력 해금, 디버그 무적, 시작점 이동, 이동 지점 선택/이동, 플레이어 재생성, 실제 피해원 선택/피해 적용, 일시정지/재개다. F1 숨김은 설정·상태·정지 소유권을 초기화하지 않는다. 사망·교체 중 낡은 플레이어 명령은 거절한다. 검색·명령 입력·복사·필터·로그 지우기 기능은 없다.

## 자산 범위

Prototype 씬에 Pot12개·Burner12개·Gratang1개 구체 피해 컴포넌트를 연결하고 중복된 빈 부모의 기존 DamageFloor11개를 비활성화했다. 보호 원본 prefab에 Apply하지 않았다. DirectSceneSmoke는 시작점·바닥·Pot 테스트 객체만 둔 소유 예제 씬이며 본편 빌드 목록에 추가하지 않는다.

## 2026-10-29 후속 확정: 버전·렌더 설정 보존

Unity6000.6.0f1을 변경하지 않는다. GPU Resident Drawer 비활성화 등 렌더 설정 변경을 해결책으로 채택하지 않는다. 새 게임은 페이드 → Core·Stage 준비 → Title 해제 → 세션 초기화 순서로 전환하며 기존 상태·입력·취소 계약은 유지한다. 실제 결과와 미실행 경계는 테스트 및 검증 항목을 따른다.

## 2026-10-30 로그 폰트 보완

로그 본문은 기존 NotoSansCJKkr-Regular.otf에서 생성한 세션 전용 동적 TMP 폰트를 사용한다. 원본 아트·폰트 자산은 수정하지 않는다. 로그 수집 원문은 유지하고 표시 단계에서만 지원하지 않는 문자·잘린 서로게이트를 [U+코드]로 표시한다. 경로의 역슬래시 n/t는 줄바꿈/탭으로 해석하지 않는다. 실제 개행·탭은 유지한다. 패널 무적 표시는 정적 폰트에 없는 체크 기호 대신 [ON]/[OFF]를 쓴다. 세션이 임시 폰트·재질·아틀라스를 해제한다.

## 2026-10-30 직접 테스트 리스폰의 붕괴 발판 복원

사용자 요청: 직접 테스트 사망·재생성 버튼에서 같은 씬의 붕괴 발판 전체를 일반 플레이와 동일하게 복원한다. DirectSceneTestRuntime은 Actor 제거 완료 후 SceneComponentLookup.FindAll<ShatteredPlatform>으로 비활성 객체까지 조회하고 기존 ResetForRetry를 호출한 뒤 Actor를 생성한다. 완성된 StageService 구성을 요구하지 않는다. 다른 장치 초기화, 씬 저장·재로드, 아트 변경은 범위 밖이다.

## 2026-10-30 직접 테스트 본편 카메라 구성

목표는 미완성 작업 씬에서 본편 CinemachineCamera·PositionComposer·Brain 및 LevelCameraService.ViewSettings/ResolveMode를 재사용해 측면·통로·쿼터뷰를 선택하는 것이다. StageService 바인딩·체크포인트·구간 전환 전체는 요구하지 않는다. DirectSceneTestCamera가 실행 전용 출력과 세 리그·임시 비활성 상태를 소유한다. 설정의 임시 cam/Update 추적 코드는 제거한다. 기존 활성 화면 출력과 연결 Brain·AudioListener는 같은 테스트 씬에서만 일시 비활성화하고 해제·실패 시 복원한다. 아트·렌더 설정·씬 저장·재로드는 변경하지 않는다. 패널 View → ViewModel 명령 → 카메라 구성 객체 순서로 호출하며 선택 시점을 리스폰에도 유지한다. 명시한 Stage 또는 유일한 Stage의 구도 값을 사용하고 없으면 설정의 본편 형식 구도를 사용한다. 사용 순서는 디버깅 모드 사용 방법을 따른다.

## 2026-10-30 카메라 월드 +Z·실제 상호작용 보완

최종 직접 지시는 입력 변환 추가가 아니라 카메라 수평 방향을 월드 +Z로 유지하는 것이다. HMS 소스와 입력 처리에는 변경이 없다. DirectSceneTestCamera는 구도 데이터를 복사해 Y/롤0, 수직각 -89~89로 적용하고 최초 출력 위치도 동일한 구도로 초기화한다. 원본 구도와 부모 회전을 수정하지 않는다.

DirectSceneTestInteraction이 기존 F 안내·MemoScreenCanvas·MemoSystem·MemoView를 재사용한다. 실제 판정/명령은 기존 PlayerInteractionService와 SessionActorHost 하나를 사용한다. MemoObject의 빈 화면 담당, MemoUIController의 빈 화면 부모/프리팹만 임시로 제공하고 기존 연결을 보존한다. 임시 연결은 종료 시 해제하며, 메모 이미지·앵커·물리 설정은 사용자가 작성한 원본을 사용한다. 미저장 작업 씬 저장·재로드·Play를 하지 않는다.

## 2026-10-30 최종 방향 정정: 대상의 +Z 쪽 배치

사용자가 위치와 시선을 명확히 구분해 카메라를 대상의 +Z 쪽에 두고 대상을 향해 -Z 방향으로 바라보도록 확정했다. 앞선 +Z 시선 설명은 폐기한다. 실행용 구도의 Y 회전을 180도로 수정했고 HMS 입력은 변경하지 않았다. 원본 설정 적용 대상은 별도 확인 중이다.

## 2026-10-31 원본 구도 재사용

최신 직접 지시로 디버그의 고정 Y180/롤0/수직각 제한을 제거한다. CopySourceProfile은 source.angles를 그대로 복사한다. 입력 코드·씬 저장본·현재 미저장 편집은 변경하지 않는다. StageService가 없는 씬의 기존 Inspector 테스트 값은 유지하고 신규 쿼터뷰 기본값은 프로토타입의 (20,-30,0)을 따른다.
