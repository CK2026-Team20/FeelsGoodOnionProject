# 기능 명세서

## 목표
현재 01_Stage_Prototype에서 누락된 흐름 구성 객체를 추가하고 새 객체의 참조를 연결한다. 기존 배치 오브젝트는 필드·위치·활성 상태·계층 모두 보존한다.

## 참고
planning-index.md, V1.6 원본의 체크포인트·UI·흐름 조항과 최신 직접 지시, 실제 열린 Stage, Bootstrap/Title/Core Preview Scene, StageService/StageTrigger/CoreComposition/LoadedStageRegistry/BootstrapEntryRoute.

## 제약
공식 Unity MCP만으로 Scene 편집. Play/Player/빌드/Git 실행 금지. 기존 prefab Apply 및 기존 객체 변경 금지. 과거 136개 배치 기록은 현재 89루트 씬의 검증 근거로 사용하지 않는다.

## 변경
누락된 StageService를 독립 StageManager 루트에 추가한다. initialCheckpoint는 현재 시작 위치에 배치된 StageTriggerPoint를 참조한다. cameraBounds는 선택 참조이므로 비워 둔다. 기존 트리거 소속·Collider·음악은 변경하지 않는다. Core/Bootstrap에 존재하는 UI·세션·연출·카메라를 Stage에 중복 추가하지 않는다.

## 완료 기준
StageService 1개 및 initialCheckpoint 연결, 기존 객체 전체 직렬화 전후 비교, 저장 결과 비교, Missing Script/깨진 참조 검사, 기존 오류와 미검증 실행 경로 명세. 기존 객체 수정이 필요한 통합 실행 장애는 해결 완료로 판정하지 않는다.
