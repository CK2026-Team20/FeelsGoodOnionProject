## 실행 실패 원문과 범위

이번 새 게임 진입 시 Console seq143~145에 다음 오류가 다시 발생했다. seq146에서 GameFlowService가 InvalidOperationException을 기록하고 seq147~149에서 Recovering→Title로 복귀했다.

- Stationary 2건: `물리 루트와 몸체는 무회전·단위 배율이어야 합니다. 외형 자식만 회전/확대하세요.`
- Patrol 1건: `적의 초기 위치와 실제 순찰 끝점이 지형의 안전 높이 구간 안에 있어야 합니다.`

앞선 Console에도 같은 오류가 있었다. 적·씬·물리 코드는 이번에 변경하지 않았다. 문제를 우회하여 전체 게임 검증 통과로 표시하지 않았다.

## 시각 확인 사항

최댓값의 양파 손잡이와 100 글자가 일부 겹친다. 새 Frame의 비율은 기존 630×620 Panel 영역에 맞춰 표시된다. 기존 크기·배치·preserveAspect를 유지하라는 승인 조건에 따라 조정하지 않았다. 자연 입력 전체 플레이, 실제 음원 청취, 플레이 HUD 캡처, 빌드/Player는 미검증이다.

## 증거

프로젝트 루트 output/Tech_SYM/UI/Icons/:
- GlobalUiRoot.before.prefab: 적용 전 사본.
- art-hashes-before.json, preservation-check.json: 원본 해시 및 전체 저장 필드 보존 검사(exit 0).
- title-options.png, title-options-mid.png: 실제 Play 화면의 최댓값·중간값.
- title-tests.json, runtime-log.json: 공식 도구의 테스트 반환값과 새 게임 실패 로그.

스크린샷 도구가 경로를 Assets/output으로 정규화하여 생성한 PNG는 지정된 루트 output으로 이동했고, 이번에 생긴 빈 Assets/output 폴더와 메타는 정리했다. 사용자 기존 파일은 없었다.
