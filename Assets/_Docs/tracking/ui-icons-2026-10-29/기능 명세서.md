# Icons UI 적용 명세

2026-10-29 사용자 승인 계획에 따라 새 Icons 리소스를 기존 UI 표시 크기로 적용한다. 원본 픽셀 크기로 RectTransform을 재설정하지 않는다.

## 참고와 범위

- 기준: 최신 직접 지시, planning-index, Cooked!_UI기획서Ver2.1.pdf, UI 지역 AGENTS, 현재 UI 프리팹과 HudView/OptionsView.
- GlobalUiRoot 옵션 Panel에 Options/Frame.png를 연결한다.
- Master/Music/Sfx 각각 Track=Bar_bg.png, Fill=Bar.png, Handle=Button.png를 연결한다.
- 이 10개 Image의 RGB를 흰색으로 하고 기존 알파를 유지한다.
- GameUiRoot의 HP 2종·Q 2종·E 2종은 이미 같은 Icons 자산을 참조하므로 유지한다. 기존 ViewModel 상태 전환을 재사용한다.

## 보존 조건

Transform Scale, RectTransform 크기·앵커·피벗·위치, CanvasScaler, Image 유형과 preserveAspect, 슬라이더와 버튼의 입력 계약을 변경하지 않는다. 손잡이 Scale (2,2,2)를 유지한다. SetNativeSize를 호출하지 않는다.

원본 PNG/meta/Import 설정, 게임 코드·씬·보호 자산은 수정하지 않는다. 프리팹 재생성·Unpack·Apply, Git commit/push/PR은 범위 밖이다.

## 완료 판정

적용 자체와 저장본 보존 검사는 완료했다. 실제 타이틀 옵션은 검증했으나 플레이 중 HUD/옵션은 기존 적 배치 오류로 진입이 실패하여 미검증이다. 세부 결과는 테스트 및 검증 항목.md를 따른다.
