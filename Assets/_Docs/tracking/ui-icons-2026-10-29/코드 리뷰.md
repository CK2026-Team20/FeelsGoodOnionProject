# Icons UI 적용 리뷰

## 최종 변경

제품 변경은 Assets/_Prefabs/UI/GlobalUiRoot.prefab 한 파일이다. 공식 Unity 플러그인 eval의 LoadPrefabContents/SaveAsPrefabAsset/UnloadPrefabContents로 기존 프리팹을 수정했다.

- Sprite 참조 10개 변경: Panel 1, Track 3, Fill 3, Handle 3.
- RGB 7개 변경: Panel 1, Track 3, Fill 3. 기존 손잡이는 이미 흰색이었다. 알파 변경 없음.
- Sprite/Color 행을 제외한 전체 저장본 비교가 동일하다. RectTransform 39개, Transform 1개 및 CanvasScaler/입력/직렬화 설정을 보존했다.
- HP/Q/E의 기존 Sprite 참조 6종과 하트 3개 연결은 실제 AssetDatabase 조회로 확인했다.
- Architecture 씬의 m_Sprite/m_Color propertyPath override 검색 결과 없음. 타이틀 실행 인스턴스의 옵션 10개 Image가 새 자산을 참조함을 확인했다.
- 원본 Icons 파일 24개(PNG와 하위 메타 포함)의 SHA-256 변경 0건.

## 책임과 수명

공개 API/타입/소스 변경 없음. HudView의 Model 기반 폼·준비 상태 표시, OptionsView의 ViewModel 명령, SetValueWithoutNotify 및 자기 리스너 해제 계약을 그대로 사용한다. 실제 옵션 값 전달과 재열기·같은 Model 재바인딩을 확인했다. Dispose 이후 호출 및 입력 1회 명령 호출 횟수 계측은 수행하지 않았다.

## 남은 확인

기존 손잡이 크기와 배치 때문에 최댓값에서 양파 그림과 100 글자가 일부 겹친다. 사용자 크기·배치 보존 조건에 따라 수정하지 않았다. 플레이 진입 실패와 HUD 동적 검증 제한은 검증 문서에 기록했다.
