# 설정 변경 검토

PC_RPAsset의 기본 Volume Profile을 해제해 SampleSceneProfile의 Bloom0.25/Neutral/Vignette0.2가 자동 적용되지 않도록 했다. 전역 기본 프로필의 후처리 컴포넌트19개를 비활성화해 전역 Bloom1이 대체 적용되는 경로도 차단했다. 기존 파라미터 값과 GUID는 보존한다.

VolumeManager는 비활성 기본 프로필 컴포넌트를 기본값 계산에서 건너뛴다. 씬 Volume 자체의 컴포넌트를 끈 것이 아니므로 씬 오버라이드는 정상 적용된다. 출력 카메라 renderPostProcessing=True 유지. Volume Layer Mask와 일치하는 레이어의 씬 Volume 및 overrideState가 켜진 파라미터로 효과를 설정한다.

이 정책은 현재 사용 중인 PC_RPAsset에 적용된다. Mobile_RPAsset의 별도 기본 프로필 연결은 이번 명시적 수정 대상이 아니므로 변경하지 않았다. 공유 SampleSceneProfile 원본 또한 그대로 유지했다.
