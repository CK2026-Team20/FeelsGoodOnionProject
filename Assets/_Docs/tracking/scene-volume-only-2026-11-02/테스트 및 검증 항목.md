# 검증 결과

공식 Unity 플러그인의 실제 VolumeManager와 별도 VolumeStack에서 검증했다.

1. 씬 Volume 없는 상태: Bloom intensity0, Tonemapping None, Vignette0.
2. 임시 씬 Global Volume 적용: Bloom0.75, Tonemapping Neutral, Vignette0.3 확인.
3. 해당 Volume 비활성화: 세 효과 모두 OFF 확인.
4. 임시 GameObject/Profile/컴포넌트/Stack 해제 후 실제 BootstrapCamera 스택 갱신: renderPostProcessing=True, Bloom0 확인.
5. 대상 자산만 SaveAssetIfDirty로 저장. 씬 저장/재로드나 Play 전환 없음. 검사 시작과 종료 모두 Play 일시정지.
6. SampleSceneProfile 파일은 이전 사본과 SHA256 일치. 자산 diff 공백 검사 통과.

원문: output/Tech_SYM/scene-volume-only-2026-11-02/verification.txt. 이전 자산 사본도 같은 폴더에 보존했다. 테스트는 엔진 Volume 합성 동작 검증이며 화면의 주관적 외관 비교나 standalone Player 시각 검증은 수행하지 않았다.
