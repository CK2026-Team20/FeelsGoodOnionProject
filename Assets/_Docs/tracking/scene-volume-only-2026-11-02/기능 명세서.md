# 씬 Volume 전용 후처리

사용자 승인: 전역 기본 프로필과 PC_RPAsset의 기본 후처리를 끄고 씬 Volume으로만 적용한다. 타 작업자 씬과 아트 원본은 수정하지 않는다.

변경 대상은 Assets/Settings/DefaultVolumeProfile.asset 및 Assets/Settings/PC_RPAsset.asset 두 파일이다. 전역 프로필의 IPostProcessComponent 19개를 active=false로 전환하고 PC의 volumeProfile 연결을 null로 변경한다. 카메라 후처리 기능은 씬 Volume 적용을 위해 유지한다. ProbeVolumesOptions는 조명 설정이므로 유지한다. SampleSceneProfile, Mobile_RPAsset, 전역 설정 연결, 씬·프리팹·아트는 수정하지 않는다.

완료 기준: 기본 상태의 효과 OFF, 씬 Volume 효과 ON, Volume 비활성화 시 효과 OFF, 현재 카메라 스택 갱신, 두 자산의 변경 범위 확인.
