# 현재 작업 실행 인계

정본은 Assets/_Docs/tracking/2026-10-05-guidance-refresh-{spec,plan,handoff}.md 세 파일이며 .dryforge의 동명 실행 문서는 같은 내용의 사본이다. 한 벌만 읽고 동기화는 해시로 확인한다. 이전 ready-2026-10-05는 이력이며 메모 E전용·최신 운영 지시가 우선한다.

사용자가 앞선 개선안 적용과 경계 내 구현 정비를 직접 승인했다. 기획 기준은 planning-index, 현재 규칙은 business-rules, 수정 허가는 security를 따른다. 기본 Git 준비·커밋/병합 절차는 이번 권한에 포함되지 않는다. 기존 공유 체크아웃 변경과 미저장 씬은 보호한다.

문서 체계는 기존 Assets/_Docs와 지역 지침을 유지하는 갱신이다. 문서 검토 완료 뒤 .dryforge/status.json에 initialized=true를 기록하며 이는 문서 초기화만 의미한다. 게임 검증·최종 사용자 수락은 tracking/status에서 별도 관리한다. 현재 검증 결과는 새 근거가 있을 때만 갱신한다.

## 프로젝트 기반
Unity6000.6.0f1 로컬 게임, 앱/세션/스테이지 수명 분리, HMS 플레이어 원본·SYM 소비자 연결, MVVM과 소유권 경계, Assets/_Docs 문서 위치를 유지한다. 서버/네트워크·본편 세부배치·실제 애니메이션 연결은 이번 목표에 추가하지 않는다.

검증: 문서는 링크·정본/사본·이력·해시·diff, 코드는 Unity 컴파일·영향 경계, 자산은 GUID/직렬화·실제 해당 동작을 확인한다. 원본 기획/보호 파일/ProjectSettings의 기준점 해시를 비교한다. 최종 독립 리뷰는 실제 수행한 결과만 사용한다.

## 승인된 기본 형식 예외
사용자는 앞선 감사의 선택 읽기·문서 간 근거 연결·권한 예외 표·현재/이력 분리안을 적용하도록 승인했다. 따라서 Assets/_Docs 경로와 필요한 문서 간 링크, 운영 지침의 DryForge 명시는 이 프로젝트의 직접 지시로 유지한다. 스킬의 일반 문서 형식보다 이 승인된 목적과 기존 소유권 경계를 우선하며, 이를 이유로 전체 문서를 다시 생성하지 않는다.
