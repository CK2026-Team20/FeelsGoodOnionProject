# 코드 리뷰

## 결과

2026-10-13 로컬 소스와 실제 Unity 자산을 확인했다. 변경 소스는 LevelCameraService, StageTrigger, 기존 StageTriggerEditor, CoreComposition, CoreWorldBinding 다섯 파일이다. 실제 게임 프레임·물리·렌더링 완료 판정은 포함하지 않는다.

## 카메라

구도 값의 소유자는 LevelCameraService로 유지했다. 화면 위치·허용 폭/높이·감쇠·거리·각도·시야각의 마지막 적용값을 비교하고 변경된 구도만 적용한다. 연결/구간 진입의 Apply는 초기 검증을 유지하며 LateUpdate의 Refresh는 잘못된 런타임 값에서 기존 유효 출력을 보존한다.

전환 중 임시 Follow는 finally에서 반환한다. 구도 갱신은 EnterZone, 입력 lease 생성/해제, 이동 Tween 진행, 요청 세대 증가를 호출하지 않는다. 일시정지 중에는 변경 시에만 Brain delta 0으로 출력한다. 변경 없는 프레임의 추적 상태는 유지한다. 유효값 복귀까지 경고를 한 번으로 제한해 NaN 입력의 반복 경고도 방지했다.

## 추격과 수명

StageTrigger의 작성 참조 chaseDriver와 실행 중 빌린 chase를 구별했다. BindChase는 같은 씬 Stage/퇴로/무리, 작성 참조 일치, 센서·퇴로가 움직이는 무리 밖에 있는 것을 확인한 후 저장 명령과 함께 연결한다. UnbindChase는 작성 참조를 지우지 않는다.

CoreWorldBinding은 추격 트리거와 무리를 연결 당시 목록에 먼저 기록한다. 무리는 중복 없이 초기화하며 부분 실패에서도 같은 목록으로 Unbind/Shutdown한다. Actor 제거 시 씬을 다시 검색하지 않는다. Stage의 추격 종료는 연결된 목록만 Stop하고 오디오 상태를 종료한다. Driver의 이동·실제 포획·사망 우선순위와 Presentation의 자기 tween 수명은 변경하지 않았다.

## 자산과 보존

03_InGameCore의 기존 ChaseSwarm 프리팹 인스턴스를 Prototype/1_Stage의 Chase 아래로 이관했다. Stages/03_3_Stage의 StartChaseTrigger 아래에는 기존 원본의 인스턴스를 배치했다. 고정 센서와 움직이는 무리는 별도 Transform이다. 3스테이지 센서 회전 180도와 무리 월드 회전 0도를 구별해 기존 전면 방향을 유지했다.

원본 프리팹 크기 Y=2와 기존 Core override Y=100의 차이를 확인하고 두 스테이지에서 기존 Core의 크기를 유지했다. 프리팹 원본·meta SHA-256은 변경 전후 일치한다. 저장 diff는 Core 무리/참조 제거, 스테이지의 무리/참조/계층 추가, 새 비추격 필드의 null 직렬화만 포함한다. Canvas의 계산 좌표를 안정화한 뒤 저장 전 원래 Transform 480개와 다른 컴포넌트 설정 585개를 확인했다.

저장 후 재검사는 기존 객체 ID 480개, 3D 월드 배치 428개, UI 객체 ID 52개를 확인했다. 화면용 UI의 world 좌표는 PreviewScene에서 달라지므로 저장 diff로 원본 직렬화 보존을 확인했다. 관련 네 씬에 Missing Script와 깨진 직렬화 참조는 없다.

## 남은 확인

실제 플레이에서 구도 조정 중 화면, 옵션/메모 정지 중 화면 갱신, 통로 전환과 입력 복귀, Actor 재생성·스테이지 교체 시 무리 수명, 포포 접촉과 실제 포획은 사람 확인 항목이다. 비 Play 직접 호출과 직렬화 검사를 전체 게임 기능 통과로 해석하지 않는다. Git commit/push/PR은 수행하지 않았다.
