# 체크포인트·씬 종료·음악 작성 통합

2026-10-13 사용자 검토와 답변을 반영한 실행 명세다. 목표는 체크포인트 작성 컴포넌트를 StageTrigger 하나로 통합하고, 타이틀 복귀에서 게임 씬을 완전히 해제하며 Prototype/1_Stage만 실행하는 것이다. 구현·검증 결과는 별도 기록하며 이 명세만으로 완료를 선언하지 않는다.

## 확정 동작

- CheckpointMarker와 P_START/P_END 전용 등장 앵커·카메라 설정을 제거한다. 체크포인트 모드 StageTrigger의 Transform이 등장·저장 위치다. 플레이어 CapsuleCollider의 월드 중심을 그 위치에 맞춘다. 감지 범위는 같은 기능 객체의 Collider로 조절한다.
- 최초 체크포인트와 접촉 체크포인트는 같은 컴포넌트다. 스테이지는 체크포인트 참조를 사용하고, 기존 세션이 위치·조각 0..5·해금 마스크 0..3을 원자 저장한다. 같은 저장 트리거 재접촉 억제를 Actor 교체로 비우지 않는다. 추격 직전에는 당시 플레이어 Collider 중심과 조각·마스크를 저장한다.
- Side/Corridor/Quarter 모두 같은 CameraZoneTrigger와 빈 기능 Root/감지 범위/정렬 지점 구성을 사용한다. 차단 사용 구간에만 안전 앵커·차단 몸체·차단 목표를 둔다. 기존 두 DOMove와 물리 배치·접촉 계약을 보존한다.
- 옵션 및 엔딩의 타이틀 복귀에서 세션·작업·구독을 해제한 뒤 로드된 Stage 전체와 Core를 실제 언로드한다. Bootstrap과 Title만 남는 것이 정상 완료다. 재시도는 같은 Core/Stage 인스턴스를 유지한다. 부분 로드·실패 복구에도 같은 종료 계약을 적용한다.
- 설치·진입·빌드 목록의 Stage는 Prototype/1_Stage 하나다. 03_2_Stage와 03_3_Stage는 실행 대상에서 제외한다. 보존 씬에 남은 Marker 참조도 이관해 소스 삭제 후 Missing Script를 남기지 않는다. 기존 씬 파일 자체의 삭제는 하지 않는다.
- 시작 체크포인트 StageTrigger의 음악을 첫 플레이 진입에 자동 적용한다. 이후 StageTrigger로 음악을 변경한다. 같은 AudioClip 요청은 재생 시간과 진행 중인 fade를 유지하며 무시한다. 다른 음원은 현재 envelope에서 크로스페이드한다. 기존 추격·오프닝·엔딩·타이틀의 음악 우선순위를 유지한다.
- 카메라 경계는 선택 참조다. 미연결 시 월드 경계 제한 없이 세 구도의 추적·전환을 사용한다. 연결 시 같은 씬의 활성 Trigger BoxCollider 안으로 카메라 위치를 제한한다. Inspector에 필요 이유와 미연결 동작을 한국어로 명시한다.

## 참고와 제약

StageTrigger/StageService, GameSessionRuntime/SessionActorHost, GameFlowService/SceneService, AudioService/AudioFlowBinding/UnityAudioPlaybackDriver, LevelCameraService/CameraZoneTrigger, 설치 자산과 네 기존 Stage 씬을 확인했다. 최신 직접 지시가 기존 타이틀 이후 씬 유지·Actor 위치 저장·Stage3개 선로딩 정책을 변경한다.

Tech_SYM 소스·소유 씬·설정·승인 문서만 변경한다. HMS·공용·_Art·Packages·ProjectSettings·원본 프리팹과 meta/import는 수정하지 않는다. 기존 프리팹 삭제·재생성·Apply/Unpack, Play/Player, Git 변경은 수행하지 않는다. 연결된 정지 Editor로 씬을 이관하며 미저장 작업을 보호한다. 감지 스크립트와 Trigger Collider 동거는 기존 PhysX 콜백 계약 보존을 위한 계층 예외다.

## 완료 기준

Inspector 작성은 체크포인트 모드 StageTrigger에 소속 Stage·기본 시점·선택 구간 음악을 연결하고 해당 Transform을 복귀 중심 위치에 두는 방식이다. BoxCollider.center/size는 감지 범위이며 저장 위치를 바꾸지 않는다. 시작 체크포인트의 음악은 필수다. 별도 음악 변경 구간은 같은 StageTrigger의 음악 변경 모드8을 사용한다. 음악만 반복 접촉으로 변경하려면 한 시도에 한 번 설정을 끈다. 체크포인트·포포·데드존에는 적용하지 않는 once 설정을 Inspector에서 노출하지 않는다.

실제 Unity 컴파일, Marker 코드/GUID 참조0, 보존 자산 Missing Script/깨진 참조0, 기존 월드·충돌·렌더 배치 보존, 단일 Stage 등록, Collider 중심 일치, 체크포인트 값 보존·중복 억제, 옵션/엔딩/복구 종료 순서, 음악 중복·연속 전환, 경계 선택 및 기존 런타임 구도 변경을 비 Play에서 확인한다. 자연 접촉·출력 화면·실제 음원·언로드 이후 재진입·전체 한 판은 사람 Play 확인으로 명확히 구분한다.
