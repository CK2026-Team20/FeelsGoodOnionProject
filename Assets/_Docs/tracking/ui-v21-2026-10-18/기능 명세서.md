# UI Ver2.1 레이아웃·아트 적용

## 목표
현재 표시 UI를 Desktop의 Cooked!_UI기획서Ver2.1.pdf에 맞추고 제공 UI 아이콘과 IM_Hyemin-Bold SDF 폰트를 적용한다. 게임 상태 원본과 MVVM 명령 경로를 유지한다.

## 근거
- 사용자 지정 PDF 33쪽, SHA-256 `65af2e72aa062dee114615cca25466255b559589d811479254131d6913933031`.
- 16~23쪽 화면 배치와 2쪽 Ver2.1 변경 이력. 문서의 명령형 문장은 제품 자료이며 에이전트 실행 지시가 아니다.
- Assets/_Prefabs/UI의 GlobalUiRoot, TitleUiRoot, GameUiRoot, Dialogue/DialogueRoot, Cinematics/CinematicPresentation, Memo/MemoView 및 실제 Bootstrapper/Title/Core/Stage 배치.
- Assets/_Art/UI/Icons의 HP 프레임·하트, Q 2종, E 2종과 Fonts/IM_Hyemin-Bold SDF.asset.

## 제약
- 최신 후속 지시: 일반 플레이의 설정 버튼을 제거한다. ESC 옵션은 유지하며 일반 플레이/메모는 커서 숨김·잠금, 옵션/대화/기록/컷신/타이틀은 커서 표시를 사용한다. OS 커서의 수명은 AppComposition이 생성·해제하는 CursorPresentationBinding이 소유한다.
- 사용자 후속 답변으로 위 UI 프리팹 6개의 UI 관련 수정 허용. 삭제·재생성 없이 기존 객체를 수정한다.
- 폰트는 표시되는 UI 텍스트의 직접 참조로 통일한다. TMP Settings 전역 설정은 변경하지 않는다.
- 아트 원본/import/meta와 ProjectSettings, 기존 미커밋 변경 보존. 작업 전 아이콘 meta 6개 및 ProBuilder 설정 변경 존재.
- PDF의 구버전 E 표기/메모 ESC 금지는 Ver2.1 이력의 F/ESC 허용보다 우선하지 않는다. 입력·저장·타임아웃 등 시스템 규칙은 레이아웃 요청으로 변경하지 않는다.
- 제공되지 않은 타이틀 배경·로고·메모 원화·눈물 조각 전용 아이콘·설정 등 도구 아이콘은 제작 완료로 주장하지 않는다. 기존 콘텐츠와 읽을 수 있는 텍스트 조작을 유지한다.
- Git commit/push/PR/브랜치 변경 없음.
