# UI Ver2.1 변경 검토

## 변경과 책임
- UI 프리팹 6개와 Bootstrapper/Title/Core의 실제 배치 override를 native Editor API로 수정했다. 삭제·재생성·원본 prefab Apply를 사용하지 않았다.
- 타이틀 왼쪽 메뉴, 중앙 옵션 슬라이더, 좌상단 HP 프레임/하트·조각, 좌하단 Q/E, 상단 대화, 중앙 메모, 기록 두 열/스크롤을 구성했다. 컷신은 기존 원화 영역을 유지하고 건너뛰기·텍스트 폰트를 조정했다.
- TMP 텍스트 35개(프리팹 기준)와 통합 씬 35개 직접 참조는 모두 IM_Hyemin-Bold SDF다. TMP Settings는 변경하지 않았다.
- HudView는 상태를 판단하는 Model을 검색하지 않는다. HudViewModel이 기존 Bridge/Session 상태와 공개 PlayerFormController 이벤트를 소비한다. FormChanged는 자신이 구독한 실제 form에서만 해제하며 Actor 변경 시 연결을 교체한다.
- HP는 Image.fillAmount, Q는 현재 폼에 따라 작아지기/커지기 Sprite, E는 해금 및 5조각 준비 상태에 따라 활성/비활성 Sprite를 사용한다. 여섯 아트 Sprite가 모두 연결됐다.
- 눈물 조각 전용 UI Sprite가 없어 기존 HudIconGraphic의 눈물 표시는 유지했다. 따라서 소스와 보존 씬용 하트 호환 경로를 삭제하지 않았다. 나머지 소비 이관 및 GUID 참조0 확인이 제거 조건이다.
- DialogueView는 기록 화자/본문 열과 클리핑을 표시하고, 기록이 열리면 뒤의 본문/도구를 숨긴다. 기존 대화 서비스의 진행·자동·종료 규칙을 변경하지 않았다.
- 일반 플레이의 설정 열기 버튼은 최신 지시로 제거했다. 기존 OptionsView의 ESC 입력과 닫기/음량/메인복귀 경로를 유지한다.
- CursorPresentationBinding은 Flow/Options/Dialogue 상태를 구독하는 OS 출력 어댑터다. ViewModel→View 역참조가 없고 AppComposition이 세션별 대화 연결·종료 시 해제·포커스 복귀 갱신을 담당한다. 일반 플레이와 F로 닫는 메모에서는 숨김/Locked, 마우스 조작 화면에서는 표시/None이다. 종료 시 이전 커서 설정을 복구한다.

## 검토 및 한계
- 재바인딩, 한 번의 Slider 변경, Unbind 이후 명령 차단, HUD Dispose 이후 알림 없음, 대화 해제 시 취소를 실제 DLL/프리팹 격리 Play로 검증했다. 별도 하위 에이전트 검토는 수행하지 않았다.
- 원화에 이미 그려진 글자는 TMP 폰트 변경 대상이 아니다. 실제 메모는 PlaceholderMemo_1/2이며 최종 본문 원화가 없다. 타이틀 배경·로고, 조각 전용 Sprite, 도구 아이콘도 아트 미제공 상태다.
- 사용자/다른 작업의 오디오 카탈로그 변경은 직접 수정하지 않았고 원복하지 않는다. Stage music NULL 및 CinematicCatalog 첫 원화 누락은 이번 UI 범위 밖이다.
- TMP 자동 변화: IM_Hyemin 폰트의 머테리얼 _ScaleRatioA/B/C가 1→0.5/0.40625/0.40625로 재계산되고 LiberationSans fallback glyph/cache가 갱신됐다. 폰트 원본/아틀라스/import를 수동 편집한 것은 아니다. 기존 아트 아이콘 meta와 ProBuilder 설정 변경은 그대로 보존했다.
- C# 및 문서 diff 공백 검사는 통과했다. 전체 diff에는 Unity native YAML의 빈 m_Name 뒤 공백과 작업 전 아이콘 meta 공백이 남는다. raw YAML 정리를 위해 보호 자산을 수정하지 않았다.
