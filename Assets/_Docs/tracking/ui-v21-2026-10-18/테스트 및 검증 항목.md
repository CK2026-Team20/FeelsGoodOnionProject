# UI Ver2.1 검증 결과

## 실행 환경과 증거
- Unity 6000.6.0f1 / 공식 Unity 플러그인 / Editor Play. 기준 Canvas 1920×1080. 화면 캡처는 Screen Space Overlay를 포함한 source=screen이다.
- 증거: 프로젝트 루트 `output/Tech_SYM/ui-v21-2026-10-18/`. native-validation.json, isolated-checks-first.json(59개), isolated-checks.json(최종 수정 후 57개), screenshots/.
- UI 격리 검증은 실제 제품 View/ViewModel/Service와 실제 UI 프리팹을 사용한다. Flow/PlayerBridge는 테스트 대역, 폼 이벤트는 비활성 실제 PlayerFormController의 상태를 준비한 뒤 발생시켰다. HP/조각/해금은 테스트 데이터이며 자연 게임 플레이 성공을 뜻하지 않는다.
- 검증 시에만 Application.runInBackground=true로 프레임을 진행하고 false로 되돌렸다. 실제 설정 저장을 피하기 위해 음량 검증은 메모리 저장소를 사용했다. 가상 Keyboard는 검사 후 제거했다. Play를 종료했고 임시 Editor 검증 소스는 제품에서 제거하여 output 증거로 보존했다.

## 시각 보완·실패 기록
- 초기 타이틀 밝은 글자/배경 대비 부족을 실제 화면에서 찾아 어두운 글자로 수정했다.
- 초기 Slider 손잡이 세로 늘어남을 native RectTransform/비율 설정으로 수정했다.
- 초기 기록 화면 뒤의 본문 겹침을 표시 전환으로 수정하고 최종 캡처를 다시 확인했다.
- 초기 스크롤바 작성 eval의 Vector2 생성 문법 오류는 변경 전 컴파일 거절되었고 수정 후 성공했다.
- capture 도구는 절대 출력 경로도 Assets/output으로 정규화했다. 생성된 PNG만 루트 output의 screenshots로 옮긴 후 이번에 생성한 Assets/output을 native API로 제거했다.
- 첫 격리 캡처의 검정 화면은 테스트용 GlobalUiRoot의 미바인딩 FadeCanvas였다. 검증 환경에서만 비활성화 후 다시 캡처했다.
