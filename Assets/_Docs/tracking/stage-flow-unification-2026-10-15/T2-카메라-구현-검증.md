# T2 카메라 구현·코드 리뷰·검증

## 목표와 구현

R4/R5/R8의 코드 범위다. StageService 구간 선택과 세 구도 설정을 유일한 원본으로 유지한다. LevelCameraService는 구간 실행·추적·DOMove 보정·블렌드를 담당한다. 위치 bounds getter/검사/최종 ClosestPoint 보정과 CameraZoneData/Request 및 직접 Zone 선택 경로를 제거했다. 유한 값 검사 소비자 3곳은 CameraProfileValidation으로 연결했다.

StageService의 cameraBounds, CameraZoneTrigger의 필드, LevelCameraService의 이전 세 구도 필드는 T4 이관용 숨김 직렬화 형식이다. Legacy Zone에는 실행 메서드가 없다. T4 전 리그에 남은 Confiner는 Bind 동안 enabled만 끄고 Unbind에서 원래 상태를 복원한다. BoundingVolume·경계 위치를 읽거나 쓰지 않는다. 실제 prefab Confiner 삭제 및 전체 serialized 참조 0은 T4 담당이다.

반경은 추적점+월드 focusOffset에서 정착 카메라까지의 유클리드 거리다. 기존 PositionComposer를 사용하며 FOV·출력 aspect·화면 위치로 전방 깊이를 계산한다. 수직각(X), 수평각(Y), 롤(Z)을 한국어 도 단위로 편집한다. Composer 최소 깊이 .01m 미만 설정은 유효 구도를 보존하며 거절한다. Actor 회전 시 월드 오프셋만 변환하여 추적 감쇠를 초기화하지 않는다. 자유 회전 입력은 추가하지 않았다.

Inspector 편집은 Play의 SerializedObject 경로로 실제 출력에 반영했다. Play 종료 시 편집값이 되돌아감을 Inspector에 표시한다. 반경은 정착 기준이며 감쇠·dead zone·블렌드 중 편차가 허용된다. unrelated profile 값은 덮어쓰지 않는다.

## 작성 진단과 미리보기

StageTriggerEditor.cs 안에 StageServiceEditor·CameraViewSettingsDrawer·StageAuthoringDiagnostics를 함께 두어 새 script/meta 없이 구현했다. 시작/끝 연결, 이름, 선택한 보정 직선, 목표 Capsule, 시선 중심, 카메라 위치/광축/화면 테두리를 표시한다. 미리보기는 정착 구도이며 추적점 미선택 시 시작점 가정임을 표시한다.

검사할 실제 PlayerFacade/CharacterMovement의 Capsule(프리팹 드래그 가능), 보정 시작 중심 Transform, 지지 탐색 거리를 Editor 임시 선택으로 받는다. Scene/prefab에 저장하지 않는다. 현재 선택 형상의 scale/회전·radius/height와 MaximumGroundAngle을 사용한다. 검사 대상은 지정한 단일 시작 중심에서 각 구간 시작까지의 직선 및 목적지다. 모든 센서 진입 방향, 다른 폼, 움직이는 지형, 실제 접촉 전체를 검증하지 않는다.

센서 겹침은 두 대상과 원인을 표시한다. 목표/출발점 Capsule overlap과 직선 CapsuleCast에서 장애물을 표시한다. 독립 리뷰 수정 후 목표/출발점은 전체 Capsule overlap 후보를 보수적으로 표시하고, 경로는 런타임과 같은 .002m skin을 사용한다. 얕은 접촉도 작성 검토 대상으로 남길 수 있다. 지지면은 사용자가 지정한 거리와 실제 접지각으로 검사한다. Capsule·경로·지지 거리 미선택은 검사불가/대상필요다. 전체 구간 작성이 비어 있으면 SECTION_INVALID다. 검사 버튼 시점의 결과이며 배치 변경 후 재검사가 필요하다.
