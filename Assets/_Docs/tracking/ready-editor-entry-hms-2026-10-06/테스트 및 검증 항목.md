## 실행 조건과 복원

사용자가 미저장 Prototype/1_Stage를 초기 저장 상태로 되돌리도록 명시해 마지막 저장 씬을 다시 열었다. `saved-scene-restoration.json`의 dirty=true→false를 확인한 뒤 Play했다. 그 이전 미저장 메모리에 대한 과거 확인불가 항목을 복구했다고 주장하지 않는다.

## 발견 후 수정한 회귀와 남은 제한

독립 폼의 visualRoot가 non-null이어도 직계 NormalVisual/SmallVisual이 없으면 첫 Awake에서 실패했다. 소유 prefab/scene 계층과 authoring validation을 보완하고 실제 Q/Q/F 및 전수 native 검사를 다시 통과했다. 초기 HMS 스킬 cooldown은 공개 block reason이 None이 될 때까지 기다려 검사했으며 원본 설정을 변경하지 않았다.

진입 배치의 Stop 중복 콜백과 reload 뒤 Hook의 너무 이른 setup 조회를 수정했다. Hook은 요청/Editor/실제 runtime Play가 모두 끝난 안정 update에서 기록을 비교한다. 수정 후 실제 matrix에서 Hook 예외0이다. 전체 Domain Reload 때 Unity.Hierarchy.HierarchyViewModel의 manager!=NULL UI Assertion4가 남으며 제품 stack은 없다. `matrix-console-after-fix.json`을 환경 제한 증거로 유지한다.

과거 실패 실행은 `failed-attempts/`와 timestamp별 sequential JSON에 보존했다. Full 동선은 실제 P_CHASE 접촉과 작성된 안전 경로를 사용하며 탈출의 정상 ReturningToTitle→Ending→Title을 끝까지 관찰한다. 현재 캡처는 `captures/`의 실행별 폴더에 저장한다. 이전 검증 코드가 쓰던 ready 렌더 폴더의 일부 이미지에는 이번 이전 실행이 들어갔으므로 과거 이미지 근거로 재사용하지 않는다.

보호 HMS PlatformManager Missing Script1, 실제 모델/클립/착지·픽셀 품질, 강제 컴파일/설치 자산 fault 주입은 미완료·제외를 구분해 인계한다. UAC 및 기존 PluginImporter/animation 경고를 오류0이나 기능 완료의 의미에 포함시키지 않는다. Windows 빌드·실행 파일 플레이·팀 기능 결과·FunQA 평가는 미실행이다.
