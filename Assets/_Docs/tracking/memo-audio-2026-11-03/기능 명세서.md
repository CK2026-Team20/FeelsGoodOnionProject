# 메모 상호작용 효과음

목표: 메모 열기 수락 시 다른 장치와 같은 Interaction 효과음1회. 참고: MemoUIController.TryOpen, WorldAudioBinding, AudioService 및 기존 카탈로그. 제약: MVVM/도메인 성공 판정 유지, 기존 음원 참조, 사용자 씬·아트·프리팹 수정 없음. 완료 기준: 월드 정지 중 재생, 거절/닫기 무음, 자기 구독 해제와 재바인딩 중복 없음.

MemoUIController는 View 생성과 Bind 성공 후 Opened(MemoObject)를 발행한다. 관찰자 오류는 GameplayEvent가 분리해 메모 성공을 뒤집지 않는다. WorldAudioBinding은 같은 씬의 담당에 구독하고 Dispose 시 자기 콜백을 해제한다. 기존 AudioCueIds.Interaction을 중앙 AudioService.PlayUiSfx로 출력한다. 메모가 이미 PauseWorld를 소유하므로 월드 위치음으로 출력하지 않는다. UI 채널은 Master×SFX×Cue 게인을 적용하고 Loop를 허용하지 않는다. 옵션/죽음/Playing 외 상태에서는 바인딩이 새 피드백을 요청하지 않는다. 닫기와 강제 종료에는 별도 효과음을 추가하지 않았다.
