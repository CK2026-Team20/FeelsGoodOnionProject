# UI 원본 크기 적용

## 목표
최신 CutScenes 01~04 오프닝, 05~08 엔딩과 Icons를 적용하고 목업 기반 UI의 크기·배치를 수정한다.

## 참고
사용자 2026-11-01 직접 지시·첨부 목업·크기 정정, planning-index, UI Ver2.1 PDF, 시스템 V1.8, 기존 UI 프리팹과 View/ViewModel.

## 제약
각 이미지 RectTransform은 PNG 원본 가로×세로. 부모 프레임 안에서도 늘이거나 줄이지 않으며 localScale=1. 레이아웃 그룹은 정렬·간격만 담당한다. _Art 원본·메타·import, HMS·공용 코드·Packages·ProjectSettings는 변경하지 않는다. Stage_quarter 미저장 씬을 저장·닫기·재로드하지 않는다. 기존 UI 프리팹의 대상 요소를 수정하며 전체 재생성·Apply는 하지 않는다. Git push·PR·병합은 하지 않는다.

## 변경
- 상단 조각 아이콘 제거. E 카드 내부 하단에서 조각 수와 E 키를 TearReady 기준으로 상호 배타 표시.
- Q/E 텍스트 프레임 제거, 원본 아이콘 내부 하단 배치. 스프라이트 전환 시 새 원본 크기 적용.
- 설정 닫기 버튼 프레임 내부, 제목과 같은 중심 높이, 우상단 pivot. Min/Max·백분율 제거.
- 대화 기록/자동/건너뛰기 버튼을 하단에 정렬. 기존 명령·구독 수명 유지.
- 메모와 제공 아이콘의 실제 원본 크기 적용.
- HudIconGraphic의 모든 실제 자산·코드 참조를 이관/제거한 뒤 소스 삭제.
- 월드 프롬프트는 원인 조사 범위. 임의로 프롬프트 문구/형식을 변경하지 않는다.

## 완료 기준
원본 크기/참조/배치 검사, HUD 준비 전후·소비 후 표시 전환과 해제 검증, 기존 버튼 연결·옵션 설정 보존, 컴파일 및 Missing Script 검사, 가능한 범위의 화면 렌더 확인. 실제 게임 Play·Player 검증은 수행 여부를 별도로 기록한다.
