# EnemyActor 실제 프로파일 검증
목표: 실제 Profiler 기록으로 EnemyActor/FixedBehaviourUpdate 비용과 프레임 지연 원인을 확인하고, 확인된 병목만 수정한다.
참고: EnemyActor, EnemyMotor, EnemyContactSensor, Enemies/AGENTS, 사용자 기존 Profiler 버퍼 및 현재 Tutorial Play 상태.
제약: 적의 레벨/눈물 탐색 금지. 씬/프리팹/보호 원본과 물리·렌더 설정 유지. 미저장 작업을 저장/재로드하지 않는다.
완료 기준: 기존 캡처 보존, 현재 코드의 실제 PlayerLoop 기록, Enemy 포함 시간/GC/호출 수 비교, 원인과 측정 한계 기록.
이번 결과: 선행 코드 수정이 실행 중인 버전에서 적용되었음을 실제 프로파일로 확인했다. 현재 Enemy 병목은 재현되지 않았으므로 추가 런타임 코드 변경은 하지 않았다. 과거/현재가 섞인 버퍼를 보존한 후 비우고 새 캡처만 UI에 남겼다.
