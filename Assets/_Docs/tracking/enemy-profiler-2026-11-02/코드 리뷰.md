# 실제 프로파일 원인 분석
## 과거 기록
원본 Profiler 범위 98207..100206을 user-capture.data에 저장했다.
98285 프레임은 전체 41.3470ms, EnemyActor 27.7420ms(30호출/물리2스텝), FixedBehaviourUpdate 30.6619ms다. 이전 첨부 스크린샷 수치와 일치한다.
98441 프레임은 전체62.184ms, Enemy40.7698ms(60호출/물리4스텝), Fixed44.2115ms다.
Enemy 하위에 GetComponentNullErrorMessage/GetComponentNullErrorWrapper/GC.Alloc이 반복되며 한 번의 Enemy 호출 아래334개 이상의 하위 샘플이 있었다. 이는 선행 수정에서 제거한 고정점/계층 검색 패턴과 부합한다. Deep Profile이 꺼진 과거 자료만으로 managed 하위 함수 전체의 호출 스택까지 증명한 것은 아니다.
과거 버퍼 뒤쪽 Enemy 샘플에는 이 패턴이 없었다. 따라서 전체 버퍼를 현재 코드 한 버전의 측정값으로 취급할 수 없다.

## 현재 기록
현재 Play Tutorial: Patrol 활성15, Stationary 비활성15, fixedDeltaTime 약0.02, TimeScale1, Physics.autoSyncTransforms=false, Deep Profile=false. 설정 변경 없음.
현재 코드 새 측정들에서 Enemy 아래 GetComponent 계열 대량 샘플과 GC 할당은 재현되지 않았다.
마지막 current-clean 캡처는 버퍼를 비운 뒤 실제 game frame400개를 진행했다. RawFrameData 0..397 중 양끝 전환 영향을 제외한5..394의390프레임 분석:
- Enemy 평균0.01983ms, p95 0.05930ms, 최대0.13980ms.
- FixedBehaviourUpdate 평균0.09996ms, p95 0.29660ms, 최대0.51180ms.
- PlayerLoop 평균4.84536ms, p95 6.45550ms, 최대10.97050ms.
- Main Thread frame 평균8.17310ms, p95 13.35880ms, 최대27.73220ms.
- 물리 갱신 있는159프레임만 보면 Enemy 평균0.04865ms. 총2385호출=159*15. 프레임당 물리 스텝 최대1.
- Enemy 하위 GC.Alloc 메타데이터 합0B, GetComponent 이름 샘플0개.
Enemy/FixedBehaviourUpdate는 부모·자식 포함 시간이며 더해서 독립 비용으로 계산하지 않는다. 현재 전체-frame 평균 기준 Enemy는 PlayerLoop 합산 시간의 약0.41%다.

## 남은 프레임 비용
첫 새 캡처의 긴 프레임(최대132.36ms)은 불투명한 EditorLoop에 대부분 시간이 있었다. 그 기록만으로 세부 에디터 작업/대기 원인을 단정할 수 없다.
별도 profileEditor=true 캡처에서는 Profiler UI의 ChartModelBuilder.UpdateData(누적256.265ms/144회), OnGUI, LineChartWidget.UpdateGeometry 등의 작업을 관찰했다. 이 값은 에디터 상세 캡처 내 누적치이며 앞선132ms 프레임의 직접 하위 분석값은 아니다.
마지막 일반 캡처에서는 EditorLoop 외 SRPBRender.ApplyShader, Profiler.FlushMemoryCounters 등의 비용이 Enemy보다 크다. 실게임 전체 렌더링 최적화나 보호 shader/ProjectSettings 변경으로 범위를 확대하지 않았다.
기존 소스의 값 검사는 남아 있으나 현재 비용은 매우 작다. 측정된 큰 병목이 없는데 새 캐시/스케줄러를 추가하거나 FixedUpdate 주기를 낮추지 않았다.

## 처리한 상태
기존 캡처 파일을 보존한 뒤 Profiler 버퍼 ClearAllFrames, 현재 데이터만 다시 기록했다. 마지막 UI 버퍼는 current-clean과 대응한다. Play는 기존과 같은 일시정지, 기록OFF, DeepOFF, ProfileEditor=false로 복원했다. 사용자 씬 저장/재로드, Play 종료, 코드/프리팹 변경, Git 작업 없음.
