# Inspector 연결 전환 명세

이 문서는 실제 유지 소스의 직렬화 필드를 사람이 찾을 수 있도록 정리한 최종 연결표다. source text에서 뽑은 이름·타입·Tooltip을 저장 자산과 비 Play import 결과로 대조한다. 숨은 빌드 생성 경로·대화 선택 Code는 제작자가 직접 작성하는 값이 아니다. 오브젝트 제작 순서는 [씬 흐름과 수동 프리팹 제작 가이드](<씬 흐름과 수동 프리팹 제작 가이드.md>)를 따른다.

## 연결 방식

| Inspector 값 | 사람이 할 일 | 좌표/수명 기준 |
|---|---|---|
| Transform/CheckpointMarker/컴포넌트 | Hierarchy의 실제 대상 드래그 | 같은 씬. 목표·경로는 이동 Body/적/표현 아래를 피하고 고정 지점 연결 |
| SceneReference | Project의 실제 SceneAsset 드래그 | 내부 runtimePath는 편집/빌드에서 생성. 경로 타이핑 금지 |
| DialogueSelection | 실제 JSON TextAsset 연결 후 목록의 Code 선택 | Bootstrapper의 현재 테이블과 같은 원본. 숫자/문자 키 수기 입력 없음 |
| AudioCuePurpose/enum/LayerMask | 용도·방향·종류·레이어 목록 선택 | 기존 직렬화 enum 번호 보존. LayerMask=0은 지형 없음이므로 적 지형에 사용하지 않음 |
| prefab/Sprite/Texture/AudioClip/AnimationClip/설정 자산 | Project의 실제 자산 드래그 | 사람이 리소스 제작·prefab 교체를 담당 |
| 속도/시간/높이/각도/음량 | 조절할 수치 입력 | Tooltip의 단위·0 의미 사용. 목표 위치 수기 좌표로 대체하지 않음 |
| 실행 중 Actor·Owner·CP Snapshot | 직접 작성하지 않음 | Host/Session이 현재 인스턴스와 단일 원본을 주입 |

## 같은 연결을 중복 설정하지 않는 기준

PressureLinkedPlatform.pressurePlate만 연결한다. PressurePlate에 역방향 linkedPlatform을 쓰지 않는다. PeriodicPlatform의 supportCollider는 실제 비 Trigger BoxCollider이고, motion은 고정 발판이면 비울 수 있다. CameraZoneTrigger의 alignmentPoint는 **Side·Quarter 모두 같은 씬의 고정 Transform을 필수 연결한다.** Side만 해당 월드 Z로 정렬하며 Quarter도 요청 생성 검증에는 참조가 필요하다. Stationary Enemy의 patrolStart/end는 쓰지 않는다. Player의 GameplayInputRouter는 prefab 전체 하나이며 Host가 주입한다. Play 전에 버튼 OnClick에 코드가 바인딩하는 명령을 다시 등록하지 않는다.

TearFragment의 pickupRoot는 전체 눈물 Root, presentationVisual은 물리 없는 Render다. PlayerDamagePresentation의 visualRoot와 cameraAnchor는 실제 ActorBody의 서로 다른 직계 자식이다. Shell의 PlayerDebris/BoxCollider/Rigidbody/HeavyState는 실제 Shell Root에 동거한다. 이 세 가지는 로컬 외형과 월드 물리를 혼동하지 않도록 제작 가이드에서 구체 계층을 설명한다.

Project prefab은 Scene Transform을 저장하지 못하므로 **Scene에 놓은 인스턴스**에서 외부 고정 지점을 드래그한다. IdleEnemy/StationaryEnemy의 순찰4개 빈 슬롯은 실제 Stationary 종류에서 사용하지 않는다. 이 12개/4개를 실제 배치의 필수 누락과 혼동하지 않는다.

새 빈 Root/Body/Marker 프리팹을 제작하면 Marker는 움직이지 않는 논리 Root의 Body 형제에 둘 수 있다. 기존 물리 Root template 다섯 개를 예시 계층 때문에 강제로 감싸거나 재생성하지 않았다. 예전 위치를 키/좌표로 복원해서 입력하는 방식은 쓰지 않는다.

## 오류를 고치는 순서

참조 누락이면 해당 슬롯에 같은 Scene/Project의 실제 대상을 연결한다. 다른 Stage 참조이면 해당 씬 소유자로 바꾼다. 움직이는 Marker 거절이면 경로를 고정 위치로 배치한다. 버튼/AudioSource 중복이면 서로 다른 실제 요소를 연결한다. 저장된 `.cs` GUID가 Missing이면 삭제한 구형 중계 컴포넌트를 새 최종 책임으로 이관한다. 수치를 임의로 넣어 연결 검증을 우회하지 않는다.
