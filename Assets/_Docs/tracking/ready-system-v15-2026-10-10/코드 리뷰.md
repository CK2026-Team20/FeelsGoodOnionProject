## 2026-10-11 조립 오류: 의도된 검사와 잘못된 실행 시점

사용자가 제시한 `Flow revision 1: LoadingGame, busy=True`는 `GameFlowService.Publish` → Bootstrapper의 `Debug.Log`가 출력한 상태다. revision은 전환 요청 번호이고 busy는 로딩·연출·복구가 끝날 때까지 추가 전환을 막는 상태다. 호출 스택이 포함되어도 이 메시지는 예외가 아니다. 별도의 실제 Console에는 장치·적의 준비 오류와 Play 종료 시 `World release failed → Core session cleanup failed → Service scope disposal failed` 집계 예외가 있었다. 사람 실행의 읽기 기록은 `output/Tech_SYM/Execution/bootstrap-start-2026-10-11/console-all-r1.json`과 `console-errors-r1.json`에 보존했다.

Unity의 sceneLoaded는 OnEnable 뒤, Start 앞에 통지된다. App은 씬 전체 단일성 검사가 있어 Start를 사용하며, 이미 주입된 참조만 검사하는 장치/적을 모두 Start로 옮길 필요는 없다. [Unity sceneLoaded API](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/SceneManagement.SceneManager-sceneLoaded.html)

Source commit은 `6dd87e4`다. 전체 컴파일158/158/11과 실제 제품 DLL 비 Play 검사38개, 등록3씬 지점 검사21개가 통과했다. 원래 씬 setup·root 객체·dirty 상태를 보존했다.
