# 문서 변경 검증

## 목표·범위

현재 코드·씬·프리팹·설정을 근거로 프로젝트 동작·협업 경계를 문서화한다. 구버전 README는 근거에서 제외한다. 현재 구현은 의도된 동작이라는 사용자 확인을 적용한다. 코드·씬·프리팹·아트·패키지 변경과 게임 재실행은 이번 작업 범위에 없다.

## 완료 기준

| 확인 항목 | 판정 기준 | 결과 |
|---|---|---|
| 문서 구성 | 루트 두 지침, 핵심 7개, 상태·결정·문제, 허용된 모듈 지침 존재 | 통과: 총 33개, 지역 지침 17개 |
| 루트 지침 | 두 파일 바이트 동일 | 통과: SHA-256 동일 |
| 수정 권한 | 루트 지침·문서 설정, Assets/_Docs 프로젝트 Markdown·대응 메타데이터, Tech_SYM 지역 지침·대응 메타데이터로 제한 | 통과: 권한 밖 변경 0개, 기존 PDF·메타데이터 보존 |
| 현재 근거 | 코드·직렬화 자산과 비교, 구버전 기획 미사용 | 작성자 및 독립 검수자 교차 확인 |
| 실행 주장 | 구현 존재와 실제 검증 통과 분리 | Play·빌드 미실행으로 표시 |
| 독립 검토 | 작성하지 않은 검수자 1명이 원본 교차 확인 | 통과: 지적 3건 수정·재확인, 잔여 지적 없음 |
| 사용자 확인 | 작성 결과 검토 후 최종 확인 | 대기 |

현재 문서 작업의 .meta는 지역 지침 17개, Assets/_Docs의 Markdown 14개와 하위 폴더 2개를 합한 33개다. 기존 PDF·대응 .meta와 기존 _Docs 폴더 .meta는 이 수에 포함하지 않는다. 누락·신규 GUID 중복·권한 범위를 정적 검사한다. git diff --check는 통과했다. 로컬 작업 상태 경로의 Git ignore 적용을 확인했다. 사용자 최종 확인 전에는 초기화 완료 표시를 기록하지 않는다.

일반 게임 테스트를 문서 변경의 성공 근거로 대신하지 않는다. Unity import·Play·빌드는 이번 작업에서 실행하지 않았다. 기존 게임 자산·.meta·코드 변경은 없다.

## 문서 위치 변경 확인

사용자 지시에 따라 핵심·추적 문서 14개를 기존 Assets/_Docs로 이동했다. 이동 직후 모든 문서의 해시가 이전과 동일함을 확인한 뒤 경로 관련 설명만 갱신했다. 기존 PDF 2개와 대응 .meta 2개는 해시가 동일하다. 이전 루트 문서 폴더는 제거했으며 두 루트 지침의 탐색 트리와 읽기 경로를 변경했다. 이동한 문서 14개와 새 하위 폴더 2개에만 .meta를 추가했다. 이전 작성 단계의 문서용 .meta 17개와 합하면 이번 문서 작업의 메타데이터는 총 33개다.

## 프로젝트 루트 전체 경로 검색

점검 범위는 프로젝트 루트 전체다. Assets/_Docs에 한정하지 않고 Assets의 코드·씬·프리팹·설정, Packages, ProjectSettings, 루트 스크립트·설정, 숨김 폴더, Git ignore 대상, Library·Temp·로그·출력 기록을 포함했다. 디렉터리 제외 없이 파일 47,343개를 열거하고 읽을 수 있는 텍스트에서 이전 문서 경로를 검색했다. 바이너리 내부는 텍스트 참조 검증 대상에 포함하지 않았다.

최종 검색에서 이동한 7개 핵심 문서와 tracking을 이전 위치로 가리키는 참조 및 잘못된 Assets/Docs 경로는 0건이었다. 공식 문서 URL, 외부 패키지의 문서 경로, 커밋 유형 이름, Git 이력과 이동 전 원본 경로 기록은 현재 프로젝트 문서 위치가 아니므로 변경하지 않았다.

최종 검색 시 Unity가 사용 중인 Temp/FSTimeGet 파일 3개와 Temp/UnityLockfile은 잠겨 있어 읽지 못했다. 이 파일들을 포함해 모든 파일의 내용을 검사했다고 주장하지 않는다. 검색 범위·일치 파일·읽기 오류는 output/Tech_SYM/documentation/validation/full-root-path-scan.json에, 기존 프로젝트 문서 경로 검색 결과는 같은 폴더의 full-root-old-path-check.json에 기록했다.
