# V1.8 전체 차이 목록

**기존 5가지는 전부가 아니었다.** 당시 목록은 주요 구조 차이였다. 이번에는 V1.8 활성 본문 전체를 현재 소스와 실행 등록 자산에 대조했다.

**이 목록은 V1.6↔V1.8 문서 간 변경표가 아니라 V1.8↔현재 구현 비교다.** 코드는 수정하지 않았다. 과거 사용자 직접 지시가 확인된 구현도 V1.8과의 차이를 그대로 남겼다.

## 표기 기준

- **이전 사용자 직접 지시로 수정·반영된 항목**: 저장된 확정 명세와 현재 소스 양쪽 근거가 있다. 사용자가 이전에 직접 명시하여 수정 및 반영했던 부분임을 뜻한다.
- **일부 확인**: 작업 자체는 사용자 요청이나 개별 수치·정책까지 직접 지정한 기록은 없다.
- **직접 지시 근거 미확인**: 변경 이력·현재 구현만으로 사용자 직접 명세라고 추정하지 않는다.
- 불일치·수치 차이·표현 미연결·해석/실행 확인 필요를 구별한다. 미정 문구는 결함으로 확정하지 않는다.

## 중복과 집계 경계

기존 카메라 항목을 CS-01(경계)과 CS-02(전환 정책)로 분리했다. 기존 5개 범주는 CS-01~04와 UD-01~02의 6행에 대응한다. CS-12와 UD-07의 추격 배치 누락은 같은 문제이며 UD-07에는 일반 대화 미배치도 포함된다. CS-X와 U01도 같은 문제다. p157 장치 입력은 PE-08, 애니메이션은 C05로 구별한다. 이러한 중복과 확인 필요 항목을 합산해 확정 오류 개수라고 보고하지 않는다.

본편 레벨 미배치, 프로토타입 범위, 기획 협의 예정과 시각/물리 미검증은 상세표에 남겼다. 임의의 구현 방안을 확정하거나 과거 직접 지시를 다시 우선 규칙으로 복구하지 않았다.
