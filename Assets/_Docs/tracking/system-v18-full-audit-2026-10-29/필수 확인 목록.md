# V1.8 필수 확인 목록

2026-10-29. 기존 감사 결과에서 정적 일치, 표제·용어 설명, 중복 항목, 단순히 플레이하지 않았다는 이유만으로 붙인 일반 검증 항목을 제외했다. 명세 차이·누락·구체적인 의심 근거가 있는 항목만 24개 확인 단위로 묶었다. 새로운 코드 검사나 실행 결과가 아니라 기존 감사의 선별본이다.

**[이전 직접 지시]**는 기존 지침과 다르게 사용자가 이전에 직접 명시하여 수정 및 반영했던 부분이다. 현재 구현 내용도 함께 기재한다. 이 표시는 V1.8과의 차이를 면제하거나 과거 동작을 다시 우선 적용한다는 뜻이 아니다. **[일부 확인]**은 작업 요청은 확인됐지만 개별 수치까지 사용자가 직접 지정한 근거는 없다는 뜻이다. 표시가 없는 항목은 직접 지시 근거 미확인이다.

상태는 **차이 확인 / 연결 누락 / 판단 필요 / 실행 확인**으로 구분한다. 판단·실행 확인을 확정 결함으로 계산하지 않는다.
