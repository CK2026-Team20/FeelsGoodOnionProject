# 코드 리뷰 — 수정 없는 명세 감사

세 영역을 분담 검토하고 캐릭터·입력 영역 및 결합 경계를 주 담당자가 검토했다. 주요 추가 항목인 EndpointWaitSeconds 상수, Interact/붕괴 애니메이션 null, 최종 대화 완료 장부 우회, 저장 카메라 프로필 및 과거 사용자 확정 문구를 재확인했다.

원본 prefab의 null만으로 씬 override 연결까지 누락이라 판단하지 않았다. variant 제거 컴포넌트, 실행 Stage 연결, 옛 serialized 필드와 현재 코드 소비를 구별했다. Reader 기본 F와 통합 E, Walk/Run 같은 클립, 껍질 곡선을 포함한 폼 클립, GUID가 유효한 옛 EditorClassIdentifier를 오탐에서 제외했다.

눈물 효과 외형·죽은 Actor의 화면 추적·Skip 마지막 컷 노출·수평 끼임 및 적 밀림은 실제 실행 결과로 확정하지 않았다. 단위/속도/높이 차이는 설정과 실측을 구분했다. 추격 배치 및 입력 경계의 영역 간 중복은 전체 차이 목록에 표시했다.

이번 리뷰는 게임 코드를 변경하지 않았다. 문서 작성이 기능 수정 또는 전체 플레이 통과를 의미하지 않는다. 원본 그림 두 장은 확인했으나 실행 화면 비교는 미실행이다.
