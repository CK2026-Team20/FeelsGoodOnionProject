## 검증 수준과 원문 확인

공식 Unity 도구 목록의 unity_cli_status 설명은 현재 프로젝트 Pipeline 인스턴스 미발견/사용 가능한 Editor 도구 없음이었다. Editor 접속·컴파일·Play·Player·자연 입력·API 실행 테스트를 수행하지 않았다. 이하 **정적일치는 현재 소스/저장 데이터의 해당 규칙 일치**이며 런타임 통과가 아니다. Unity 미저장 편집 상태는 조회하지 않았고 디스크 저장본만 검사했다.

- DOCX SHA-256: `783e356d9ec55552867c821fac37cd364aab6310c44895c9998f5642357ff4e4` — 직접 Get-FileHash로 일치 확인.
- 제공 JSON의 실제 인덱스 키는 `p`이다. DOCX `word/document.xml`의 **표 안을 포함한 모든 w:p** 1,222개와 JSON 1,222개를 기준으로 p523~616의 text 및 runs(text/color/strike)를 재대조하여 차이 0. body 직계 문단만 세면 1,146개여서 번호가 달라지므로 사용하지 않았다.
- 파란색 4F81BD는 활성 재정의로 읽고 빨간색 FF0000의 조정/협의 문단은 아래 미정 표로 분리했다. p615의 모든 run은 strike=true로 폐기 본문이다.
- strike 요소 유무만으로 취소선을 판단하지 않고 w:val=0/false를 비취소선으로 처리했다. p437/p478은 담당 범위 밖이며 이번 표에 포함하지 않았다.
- UI Ver2.1 PDF 33쪽의 텍스트를 읽기 전용 추출했다. 시스템과 충돌하는 구버전 E키·컷신 합성 텍스트·timeout 흐름을 V1.8에 덮어쓰지 않았다. PDF/실행 화면의 시각 렌더 검수는 수행하지 않았다.
- 이 보고서의 source file:line은 저장소 상대 경로이며 위 절대 저장소 루트 아래 실제 파일이다. 행은 이번 감사에서 직접 읽은 저장본 기준이다.
