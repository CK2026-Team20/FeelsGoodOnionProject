## 후속 검증 항목과 범위 한계

1. 저장 Stage 정상 동선으로 A~F 시점 전환, C 출구/D/E 순서, 통로 역주행 차단을 확인한다. 설정만으로 충돌체 통과·추락·카메라 후방성을 확정하지 않는다.
2. Side 화면 위치/경사와 원본 그림, Corridor/Quarter Anchor 오프셋의 실측, 전 화면비의 이탈/외부 공간 노출 및 전환 중간 프레임을 확인한다.
3. 같은 시점 CP에서 실제 잠금 시간, 진행 중 다른 CP 접촉, 사망 순간 Follow, held 이동키 종료 gate를 확인한다. CS-X는 메인 입력 담당 항목과 합친다.
4. CP-A→CP-B→CP-A의 V1.8 해석을 확정한다. 미저장 해금→사망→재해금, 미저장 조각 획득/사용→복귀, 저장 중단과 표현 실패의 경계를 각각 확인한다.
5. 추격 연결 후 전신 통과·퇴로 겹침·경로/높이 무시 포획·동시 포포 접촉 우선순위를 검증한다. 현재는 배치 누락 때문에 알고리즘 테스트 이전 연결 단계부터 필요하다.
6. 가림 Controller를 통합했다고 가정하지 않고 실제 연결·지원 재질·다중 물체 복원·씬/Actor 교체 해제를 별도 검증한다.
