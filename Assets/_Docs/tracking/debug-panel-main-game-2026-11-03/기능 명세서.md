# 본편 세션 공용 디버그 패널

목표: DirectSceneTest에만 연결돼 있던 F1 패널을 본편 Bootstrap 조립에서도 사용할 수 있게 한다. 로그 전용 Noto 폰트/임시 아틀라스 생성을 제거하고 본편 IM_Hyemin-Bold SDF를 직접 참조한다.
참고: DebugPanelSession/ViewModel/View, DirectSceneTestRuntime/Presentation, AppComposition, GameRuntimeService.CurrentSession, GameSessionRuntime, CursorPresentationBinding.

적용 범위: Unity Editor의 일반 본편 진입과 직접 씬 테스트 모두. 기존 Editor 전용 경계는 유지하며 배포 Player/Development Build 포함은 이번 구현에 들어가지 않는다.

- AppComposition이 본편 패널과 GameDebugPanelContext를 생성·해제한다. 별도 DirectSceneTestSettings 배치 불필요.
- IDebugPanelContext로 플레이어·세션·흐름·정지·이동 지점·카메라 지원 여부·재생성 명령을 전달한다. ViewModel은 DirectSceneTestRuntime에 의존하지 않는다.
- 타이틀/로딩/세션 없음에도 F1 로그 표시 가능. 본편의 현재 세션/Actor 교체 시 자동으로 구독을 전환한다.
- 체력/조각/능력은 실제 기존 서비스로 전달하며 본편 재생성은 기존 RetryCheckpoint 흐름으로 요청한다.
- 본편 이동 지점은 현재 스테이지의 실제 체크포인트 앵커이며 발바닥 기준이다. 직접 씬 테스트는 기존 시작점 Capsule 중심 계약을 유지한다.
- 본편 카메라는 구간 시스템이 소유하므로 수동 시점 버튼은 비활성화하고 현재 구도만 표시한다. 직접 테스트에서는 기존 시점 선택 유지.
- 패널 표시는 게임/플레이어 입력을 멈추지 않고 공유 커서 정책에 표시 요구만 전달한다. 명시적 Pause는 자기 토큰만 사용한다.
- Actor 제거 때 무적 복원과 자기 Pause 해제. 앱 종료 때 패널을 커서·서비스보다 먼저 정리한다.
- 본편 폰트를 모든 텍스트에 공유한다. 미지원 문자는 표시용 코드포인트 문자열로 치환하여 TMP 누락 경고가 다시 로그를 증가시키는 루프를 막는다. 원본 로그는 보존한다.

완료 기준: 두 실행 환경 조립, 공통 계약 사용, 본편 상태 조작/입력 차단 경계/폰트 소유권/해제 검증, 컴파일 통과. 사용자 미저장 씬과 원본 폰트 불변.
