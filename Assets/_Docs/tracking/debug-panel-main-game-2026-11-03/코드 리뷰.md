# 코드 리뷰

- Runtime/Service 소유권은 그대로 두고 두 환경을 IDebugPanelContext로 연결했다. 본편 컨텍스트는 현재 세션을 빌리며 생성·파괴하지 않는다.
- AppComposition의 UNITY_EDITOR 블록 안에서 패널을 자동 조립하여 직접 테스트 진입 선택과 중복되지 않는다.
- Session RefreshBinding은 패널이 숨겨져 있어도 수행하여 ActorReady/Removing 구독을 현재 세션으로 옮긴다. Stage 등록 전/해제 후에는 지점 없음으로 표시한다.
- ViewModel은 View 직접 참조가 없다. 기존 버튼 Command를 재사용하고 재생성은 한 번 위임한다.
- 디버그 본편 이동은 발바닥→Capsule 중심 변환을 재사용하며 공간 검사를 추가하지 않는다.
- DebugLogFont를 DebugLogText로 교체하고 메타 GUID를 유지했다. 폰트 생성/파괴/아틀라스 수정 없음. 폰트 없는 경우 명확한 실패를 보고한다.
- 기존 별도 Noto 경로가 사라진 뒤에도 코드가 그 경로를 요구해 초기화 예외를 발생시키던 의존성을 제거했다.
- 본편 수동 카메라 조작은 기존 구간 전환 정책을 우회하지 않도록 지원하지 않는다.
