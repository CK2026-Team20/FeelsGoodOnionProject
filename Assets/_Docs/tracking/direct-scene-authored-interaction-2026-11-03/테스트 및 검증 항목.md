# 테스트 및 검증 항목

공식 Unity CLI로 컴파일 실패 없음 확인. PreviewScene에 실제 객체를 배치한 뒤 9개 검사 통과.

1. 빈 씬 자동 대체 생성 없음.
2. 배치된 객체가 있을 때도 추가 루트 생성 없음.
3. 메모의 직접 참조 보존 및 미연결 메모 자동 연결 없음.
4. 배치한 프롬프트에 테스트 카메라 연결.
5. 재바인딩/해제 시 원본 카메라 복원.
6. 외부에서 변경한 카메라 참조 보존.
7. Dispose 이후 배치 객체 생존.
8. Dispose 이후 메모의 화면 부모/화면 프리팹/컨트롤러 참조 보존.
9. Dispose 이후 씬 루트 수 보존.

검증 스크립트와 결과: output/Tech_SYM/DirectSceneInteraction20261103/verify.cs, checks.json.
미연결 메모 경고는 검증 fixture가 의도적으로 발생시킨다. 사용자 씬은 변경하지 않았다. 본편 Play의 F 입력/메모 열기·닫기 전체 통합 플레이는 이번에 실행하지 않았다.
