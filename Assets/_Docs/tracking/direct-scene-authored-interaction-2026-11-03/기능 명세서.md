# 직접 씬 테스트 상호작용 객체의 직접 배치

목표: DirectSceneTestInteraction의 경로 기반 프리팹 생성과 누락 연결 보충을 제거하고 사용자가 씬에 배치·연결한 객체만 조립한다.
참고: DirectSceneTestRuntime/Interaction, WorldPromptView, MemoObject/ScreenController, MemoUIController, SceneComponentLookup.
제약: 소스 프리팹/씬을 삭제·수정하지 않는다. 기존 Player/카메라/디버그 표시 생성은 이번 대상이 아니다. 본편 MemoUIController의 메모 본문 View 생성 수명은 유지한다.

- 현재 테스트 씬에 WorldPromptView가 있으면 사용한다. 없으면 프롬프트 없이 테스트를 계속하며 두 개 이상이면 명확한 오류를 보고한다.
- MemoObject의 ScreenController는 같은 씬의 실제 MemoUIController를 직접 연결한다. 해당 컨트롤러의 화면 부모와 메모 화면 설정도 사용자가 연결한다.
- 누락/다른 씬 참조는 경고하고 자동 생성·자동 연결·ConfigureScreen 덮어쓰기를 하지 않는다.
- 종료 때 직접 배치한 객체는 파괴하지 않으며 테스트가 연결한 서비스/VM만 해제한다. Canvas 카메라는 원래 값으로 복원하고 외부에서 변경한 값은 보존한다.

완료 기준: 생성/프리팹 경로 의존 제거, 씬 객체·참조 보존, 카메라 재바인딩/복원 검사, 컴파일 통과.
