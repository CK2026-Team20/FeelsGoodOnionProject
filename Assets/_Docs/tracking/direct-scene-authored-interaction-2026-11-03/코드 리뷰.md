# 코드 리뷰

Create/AssetDatabase.LoadAssetAtPath/Instantiate/owned 목록과 임시 메모 화면 연결·복구 경로를 제거했다. 같은 씬 검색과 메모의 명시적 ScreenController만 사용한다. 화면과 모델의 기존 책임은 유지한다. F 안내는 기존 ViewModel에 바인딩한다. Bind 재호출 시 먼저 이전 카메라를 복원해 원본 카메라 참조가 유실되지 않도록 했다. Dispose 이후 Bind는 거절한다.

소스 프리팹 자체는 공용 자산이므로 삭제하지 않았다. 제거한 것은 DirectSceneTest의 자동 생성/참조 경로다. 메모 화면 담당자의 기존 본문 View 생성 동작은 이번 변경 범위가 아니다.
