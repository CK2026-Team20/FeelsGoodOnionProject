# 코드 리뷰

- AudioCuePurpose의 기존 정수 번호를 변경하지 않고 누락 용도를 추가했다. 기존 Form ID는 축소에 유지하고 확대 ID를 분리했다.
- AudioCueIds.ResourceForPurpose로 시트 리소스 ID를 추적하며 실제 AssetDatabase 음원을 카탈로그 SerializedObject에 대입해 저장했다. 이름 비슷한 대체 파일은 사용하지 않았다.
- CoreWorldBinding은 HMS 공개 IsSmall만 읽는다. 폼 상태나 성공 판정을 복제하지 않는다. 실제 성공 이벤트당 한 번 재생한다.
- Sfx_Ability 오용과 거절 입력 클릭음을 정리했다. 제거된 해금 효과음 구독/필드도 함께 제거하여 미사용 경로를 남기지 않았다.
- 카탈로그 27행에 null/중복 ID가 없고, 원본 _Audio·HMS·씬을 수정하지 않았다.
- 없는 3종은 null 항목을 넣어 앱 초기화를 실패시키거나 다른 음원을 대신 연결하지 않았다. 상세 목록은 기능 명세서에 기록한다.
- 원본 스냅샷과 이번 이전 파일은 output/Tech_SYM/AudioCatalog20261102/before에 보관한다. Git 작업 없음.
