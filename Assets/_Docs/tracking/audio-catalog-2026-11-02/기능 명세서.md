# 사운드 카탈로그 사전 연결

2026-11-02 후속 직접 지시: 사운드 시트에 맞게 실제 리소스를 모두 카탈로그에 지정하고 단일 폼 전환음을 축소/확대로 분리한다.

참조: 사운드 원본 시트 gid=0의 30행을 재조회, Assets/_Audio 전체 파일, AudioCueCatalog/AudioCue/AudioService/CoreWorldBinding, HMS의 공개 PlayerFormController.IsSmall 및 스킬 성공 통지. 원본 음원·HMS·씬·프리팹은 수정하지 않는다. 기존 작업과 숫자형 enum 식별자를 보존한다. 카탈로그 데이터는 AudioCueCatalog.asset에 실제 저장한다.

확보 27종을 시트 순서로 연결. 중복 Stage2/3 일반 음악 항목은 카탈로그에서 제거하고 숫자 enum/API는 호환 유지. 씬별 stages 매핑은 유지한다. 기본 음량은 기존 항목 값을 보존하고 새 항목 0.5(시트 미지정)다.

기존 FormChange=10은 축소, 추가 FormChangeUp=16은 확대. 성공 통지에서 현재 IsSmall을 읽어 선택한다. 거절된 Q 입력의 Ui_Button 재생은 제거한다. Sfx_Ability는 능력 해금 통지 대신 조각 4→5 전이에서만 선택하고, 1~4 획득은 Sfx_Teardrop을 선택한다.

음악 3종과 Fire/Pot은 Loop, Opening/Ending과 나머지 확보 SFX는 One Shot. 데이터와 실제 AudioSource.Start의 loop 인자가 동일한 AudioCue.Loop을 사용한다.

카탈로그 항목은 재생 가능한 소리의 정의이며 동시에 필요한 AudioSource 채널 수와 다르다. 기존 10채널 소유 구조는 유지한다. 이번 작업은 사전 연결과 기존 소비자의 잘못된 소리 선택 수정이다. 발소리/기름/몬스터/환경음의 전체 발생 이벤트·거리 감쇠·Loop 인스턴스 수명 연결 완료를 의미하지 않는다.
