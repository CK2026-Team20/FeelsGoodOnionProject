# 코드 리뷰

판정·Phase·코루틴은 ShatteredPlatform, Animator·트윈·외형 활성 상태는 PlatformPresentation이 소유한다. Visual만 비활성화하여 Root의 Retry 책임을 유지한다. 정상 완료와 실패/취소를 분리하고 성공으로 위장하지 않는다. 재시도는 비활성 Stage와 활성 상태 모두 처리한다. 완료 시 Root를 끄거나 객체를 삭제하지 않는다. 기존 enum 값은 유지하고 Failed6/Interrupted7을 추가했다.

사용자 씬/Controller/모델 및 원본 프리팹 변경 없음. 재생 실패는 오류를 남기되 이미 사라진 지지를 되살리지 않는다. 실패 표시 정책과 실제 게임 플레이 확인을 구별한다.
