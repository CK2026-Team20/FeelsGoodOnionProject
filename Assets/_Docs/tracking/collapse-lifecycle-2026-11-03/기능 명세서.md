# 붕괴 외형 비활성화

목표: 사용자 승인대로 경고 Tween → 지지 해제/붕괴 재생 → 정상 완료 시 Visual.SetActive(false). 참고: ShatteredPlatform/PlatformPresentation 및 Features 지침. Root와 물리 객체는 유지하고 Retry로 복원한다. 사용자가 연결 중인 씬·원본 모델·Controller는 수정하지 않는다. 완료 기준은 실제 Animator의 완료, 재시도, 실패/취소 수명 검증이다.

정상 완료만 Collapsed 및 Visual 비활성화로 처리한다. 재생 실패는 Failed와 원인 Error 로그, 외형 활성 유지로 처리하며 지지면은 이미 해제한 상태를 유지한다. 중간 비활성화/취소는 Interrupted로 구분하며 정상 완료로 간주하지 않는다. 낡은 코루틴은 version 검사로 후처리를 중단한다. CollapseStarted 관찰자가 수명을 변경하면 재생을 시작하지 않는다.

Retry는 외형 activeSelf=true, 초기 Renderer/Transform/Animator 설정과 지지 Collider를 복구한다. 부모 Stage가 비활성이라 Animator 평가가 불가능하면 OnEnable에서 Ready Rebind를 완료한다. 경고 Tween과 Normal 윗면 접촉 조건은 유지한다.

현재 씬4개 플랫폼의 외형과 붕괴 애니메이터 참조가 다른 객체다. 사용자가 두 필드를 파편 모델의 같은 루트로 연결해야 한다. Base Layer의 Ready/Collapse/Completed와 Collapse Trigger 계약은 유지한다. 실패 시 외형 유지 정책 때문에 연결 오류가 있으면 지지는 사라져도 외형은 보일 수 있으며 Console 원인으로 수정한다.
