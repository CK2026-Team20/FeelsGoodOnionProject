검증 중 첫 TitleView 조회는 이미 Stage 직접 진입한 상태여서 대상 부재로 eval 실패했다. 제품 오류가 아니라 검증 호출 대상 오류이며 이후 실제 Flow 상태를 조회하여 검증했다. 재시도 진행 중 Title 요청은 수락되지 않아 Playing 복귀를 확인한 후 다시 요청했다.

제품 소스 변경 없음. 씬 diff는 적 인스턴스 override 추가232줄이며 기존 행 삭제0. 고정 적 외형/VFX의 월드 pose와 Collider 중심을 유지하며 물리 회전을 이관했고, 순찰 하나를 3cm 올렸다. 스케일 수정 없음. git diff --check 통과.

원본 prefab 자체에는 여전히 Stationary Y180도 회전이 있으므로 다른 씬/신규 인스턴스는 이번 해결 범위에 포함되지 않는다. 전체 동선, 적 접촉 전투, 모든 발판·연출·HUD 상태 전환, 빌드/Player는 미검증이다.

작업 전 씬 사본과 보호 파일 해시는 output/Tech_SYM/PrototypeRecovery에 보관했다. 기존 UI 변경 및 사용자 리소스 변경을 유지했고 Git commit/push/PR은 수행하지 않았다.
