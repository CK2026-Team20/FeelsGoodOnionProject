# 전체 사운드 이벤트 연결

## 목표·근거·제약·완료 기준

사용자 후속 지시에 따라 사운드 명세30종의 재생 경로를 이벤트/메서드에 연결한다. 참고는 Audio/사운드 리소스 상세 명세.md 및 audio-runtime-audit-2026-11-02 전수 조사, 실제 AudioRuntimeHost/AudioService와 각 기능의 성공 판정이다. 적 피격·플레이어·장치·UI·환경 반복음을 포함한다.

중앙 Bootstrapper 오디오 소유권, 소유 객체의 성공 이벤트, 자기 구독 해제를 유지한다. 직접 씬 테스트도 같은 바인딩을 재사용한다. 보호 HMS/아트/원본 프리팹과 미저장 Tutorial 씬은 변경하지 않는다. 없는 음원3종은 다른 소리로 대체하지 않는다. 완료 기준은 재생 경로30종 확인, 컴파일, 이벤트·수명·거리·간격 회귀 검사와 실제 검증 범위 기록이다.

## 구현

- AudioRuntimeHost가 PlayerAudioBinding/WorldAudioBinding을 Actor 준비 시 연결하고 제거 시 해제한다. 이전 CoreWorldBinding의 스킬·조각·체크포인트 재생 구독은 제거해 중복을 막았다.
- 플레이어: Jumped/Landed, AbilitySucceeded, Changed, DamageAccepted, Dying를 사용한다. 발소리는 지상·자체 속도·이동 입력·조작 가능 상태를 검사한다. 이동 시작 즉시, 이후 기본0.5초이며 기름 상태는 Run/Land를 Oil로 대체하고 착지 직후 중복을 방지한다.
- 적: TryStun이 양의 기절 시간을 적용할 때 StunApplied를 발행한다. 재기절도1회 통지하며 적마다 Body 위치에서 출력한다. 정상 상태·청취 범위 안에서 기본10~15초 무작위 기본음을 재생한다. 기절/범위 이탈 후 복귀 시 간격을 새로 정한다.
- 장치: PressedChanged는 압력판의 유효한 누름 전이에, CollapseStarted는 경고 종료와 지지 제거에, OperationStarted는 장치 이동 수락에, AdvanceStarted는 압력 연동 발판이 실제 전진하기 시작할 때 연결한다. Retry/비활성화 초기화는 동작 성공으로 통지하지 않는다.
- 환경: 활성 BurnerDamagePlatform/PotDamagePlatform의 위치 Loop를 개체별로 유지한다. 명시된 첫 피해 Trigger를 위치 기준으로 사용하고 없으면 소유 Root를 사용한다. 컴포넌트 비활성화 또는 Actor/씬 연결 해제 시 해당 출력만 종료한다. 버너의 활성 상태가 켜진 상태라는 기존 배치 계약을 사용한다.
- UI: 타이틀·옵션·대화·컷신·Editor 디버그 패널의 수락된 마우스 좌클릭 명령에 Ui_Button을 연결한다. View는 입력 출처만 VM에 전달하며 재생 구현은 주입한 콜백을 사용한다. ESC/Enter·자동 진행·거절된 명령은 클릭음 대상이 아니다.
- BGM5종은 기존 AudioFlowBinding 정책을 유지한다. 사망 성공은 즉시 음악 페이드아웃을 요청한다. 직접 씬 테스트는 BindFlow와 Stage 매핑 및 Actor 이벤트를 연결한다. 미등록 테스트 씬에 한해 경고 후 카탈로그 일반 음악을 사용하며 본편 매핑 누락은 기존 오류 정책을 유지한다.

## 설정과 출력

AudioCueCatalog의 게임 효과음 설정: 발소리0.5초, 적 기본음10~15초, 최소 청취1m, 최대20m, 거리 감쇠 지수1. 간격과 거리·감쇠는 Inspector에서 변경한다. 거리 값은 미정 명세의 조절 가능한 초기값이며 실제 씬 청취 튜닝이 필요하다.

WorldAudioOutput은 Host 아래 런타임 AudioSource를 생성·재사용한다. 방향감은3D, 감쇠는 PC 위치로 계산하고 최대 거리에서0이 된다. Master×SFX×Cue×거리 감쇠를 Play 전에 적용한다. Loop에는 개별 핸들을 부여하여 다른 Loop를 끊지 않는다. 기존 월드6채널 포화 정책은 일반2D 효과음에 남고 공간음은 별도 출력으로 여러 적의 동시 피격을 보존한다.

## 음원 미확보3종

Sfx_Pc_Hit_Monster / Sfx_Platform_Spawn / Sfx_Pc_Knockback의 enum/ID 및 성공 이벤트 호출은 연결했다. 카탈로그에 실제 Clip을 추가하면 재생된다. 현재 파일이 없어 재생하지 못하며 각 용도 최초 요청에 경고한다. 임의 대체 Clip은 없다. 미확정 재생 방식은 다른 효과음과 같은 One Shot 경로로 준비했으며 음원 전달 시 종료 정책을 함께 확정한다.
