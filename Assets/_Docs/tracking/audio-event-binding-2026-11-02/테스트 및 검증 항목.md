## 확인한 동작

- 이동 시작·반복·정지 및 착지 직후 발소리 간격, 일시정지 중 진행 억제.
- Actor 점프/착지, 눈물 성공, 조각 획득/준비, 피격/사망 이벤트의 오디오 연결.
- 실제 EnemyActor.TryStun의 양수 적용 및 재기절 통지. 다른 적 Collider는 눈물 경로를 막지 않고 지형은 계속 막음.
- 압력판·붕괴·장치 이벤트의 Clip 선택과 위치 출력, 적 기본음 및 환경 Loop.
- PC 거리 감쇠, 개별 Loop 정지, 이동 대상 위치 추적, 옵션 Pause/Resume.
- 해제 후 구독 없음, 재바인딩 중복 없음, 거절된 UI 명령 무음 및 수락된 명령 클릭1회.
- 없는3종은 최초 경고, 실제 Clip 임의 대체 없음.
- 사망 시 음악 종료 요청·월드음 정리·전환 채널 사망음 유지.

## 검증 경계 및 인계

PreviewScene의 임시 객체와 이벤트/API 호출, 가짜2D 드라이버 및 실제 공간 AudioSource 속성을 사용했다. 실제 게임 입력·청취·전체 씬 진행·빌드 실행을 검증한 결과가 아니다. 테스트 초기의 불완전한 PlayerBridge fixture로 발생한 오류는 제어 서비스 분리 후 재검사하여 해결했다. 임시 객체를 정리하고 Random 상태를 복원했다.

현재 Tutorial 씬은 미저장 상태를 유지했다. 실제 Play/Player를 시작하거나 씬 저장·재로드를 수행하지 않았다. 기존 사용자 스프라이트 편집을 덮어쓰지 않았다.

후속 실제 확인: 본편/직접 씬 진입, 여러 적 중첩 피격, 모든 장치 작동, 버너·냄비 동시 Loop, 옵션 정지/재개, 사망/재시도, 타이틀 복귀 뒤 잔존음 없음, 마우스/키보드 UI 구별. 기본 발소리0.5초·적 기본음10~15초·거리1~20m는 Inspector에서 청취 튜닝한다. 실제 음원이 없는3종은 제공·카탈로그 연결 후 청취와 종료 정책을 확정한다. 새 동적 생성 적은 별도 등록 계약이 필요하며 현재 바인딩은 준비된 씬 객체를 대상으로 한다.
