# 중앙 대화 테이블과 Inspector 키 연동

목표: Bootstrapper의 Cooked_Dialogue.json 하나를 실행 데이터의 원본으로 사용하고 트리거는 키만 저장한다. 새 Dialogues 스키마와 키 목록을 Inspector에 반영한다.

참고: DialogueTableService, DialogueSelection, StageService, AuthoringPropertyDrawers, AppComposition, ArchitectureInstallation, UI Ver2.1, 새 JSON.

제약: 미저장 Tutorial 보존, 원본 JSON 내용·아트·HMS 수정 금지. 기존 세션/회차/최종 대화 취소 계약 유지. 키 이름 변경은 안정 ID가 없으므로 기존 선택을 추측 치환하지 않고 명시적 경고 및 재선택 제공.

완료 기준: 새 JSON 파싱/오류 경계, 중앙 테이블 기반 선택, JSON 내용 변경 후 목록 갱신/사라진 키 경고, 컴파일, 실제 Play의 시네마틱·UI·대화 표시와 콘솔 점검. 실행하지 못한 범위는 별도 기록.
