# 현재 명세와 문서 운영 기준

2026-10-05 사용자 직접 승인: 앞선 Markdown 감사의 해결안을 적용하고 최신 지침에 따라 프로젝트를 정비하되 파일 소유권 경계를 준수한다.

## 결정

제품 명세는 최신 직접 지시 → 해당 분야의 최신 지정 기획 → 기존 구현 설명 순서다. 이전 구현이 의도됐다는 종전 결정은 새 명세를 막지 않는다. 0002의 서버·네트워크 불필요 결정은 유지한다.

현재 규칙, 최신 상태, 과거 증거를 분리한다. 현재 상태는 status, 열린 문제는 findings, 원본 버전은 planning-index, 권한은 security가 소유한다. 지역 지침은 고유 계약만 유지하며 상위 경계를 함께 적용한다. 날짜별 증거는 보존하고 적용 시점을 넘겨 현재 지시로 읽지 않는다.

에이전트 운영은 적용 스킬에 위임하며 고정 인원·메인 직접 수행 금지를 두지 않는다. 사용자 지시·파일별 권한·미저장 작업 보호·Git 승인 경계는 유지한다. 문서 이관 초기화와 게임 실행 검증·최종 사용자 수락을 같은 상태로 기록하지 않는다.

## 결과

공통 문단과 동일 사본의 중복 읽기를 줄이고, 현재 명세가 바뀔 때 소비하는 지역 지침을 함께 갱신한다. 과거 원본·실행 실패·승인 제한을 삭제하거나 권한을 확대하지 않는다.
