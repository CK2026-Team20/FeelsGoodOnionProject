# 작업자별 소유권과 아트 원본 보호

## 배경

Unity 씬·프리팹과 .meta를 여러 작업자가 함께 수정하면 Git 충돌과 참조 손상 위험이 커진다. 동일 기능을 연동하더라도 원본 소유자와 소비자의 수정 권한은 같지 않다.

## 결정

Tech_이니셜·art_이니셜·QA_이니셜 폴더는 해당 작업자만 수정한다. 현재 작업자는 Tech_SYM이다. 다른 작업자 폴더는 읽고 참조할 수 있다. _Art는 아트 원본 공간이며 비아트 작업자는 수정하지 않는다. 같은 직군끼리는 파일과 범위를 명시한 특별 지시가 있을 때만 타인 파일 수정이 가능하다.

이번 문서 작성·재배치·정합성 수정에는 루트 지침·Assets/_Docs의 프로젝트 Markdown과 대응 문서·폴더 메타데이터·필요한 문서 설정만 예외로 허용했다. 기존 PDF와 그 메타데이터는 보존한다. 사용자의 재배치 지시에 따라 프로젝트 공통 문서는 프로젝트 루트 기준 Assets/_Docs/ 아래에 둔다. 다른 작업자 모듈에는 새 AGENTS.md도 생성하지 않고 루트에서 경계를 설명한다.

## 비교한 방식과 결과

모든 작업자가 공용 파일을 직접 수정하면 즉시 연동하기 쉽지만 소유권 격리 목적을 잃으므로 사용하지 않는다. 타인 코드 읽기까지 막는 방식은 현재 사용자가 읽기 전용 참조를 허용했으므로 적용하지 않는다.

소유권을 넘는 결함은 발견해도 임의 수정할 수 없다. _Art 원본 변경을 전제로 한 구현은 현재 작업자 권한만으로 완료할 수 없으며 별도 협업이 필요하다. 이 규칙은 작업자가 HMS로 바뀌면 자기 폴더가 HMS로 바뀌는 동일 원칙이다.
