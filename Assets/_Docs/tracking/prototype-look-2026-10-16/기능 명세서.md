2026-10-16. 최신 사용자 승인 계획에 따른 외관 설정. 게임 코드·새 스크립트·Shader·아트 원본·카메라 구도·물리·배치는 변경하지 않는다.

## 목표와 참고 자료

A~C는 따뜻한 주방, D~F는 청보라색 공간으로 구별하며 캐릭터와 착지면의 식별성을 유지한다. 실제 01_Stage_Prototype, Bootstrap 출력 Camera, 활성 Core RenderSettings, URP17.6과 실제 Play 화면을 기준으로 한다. 사용자 첨부 라벤더색 모델은 색감 참고 자료이며 기존 목재 재질을 교체하라는 지시는 아니다.

## 작성 결과

- Stage의 Lighting 루트에 Realtime Spot 6개, Point 2개. 기존 Core KitchenLight(Realtime Directional, Soft Shadow, intensity1.5)를 그대로 유일 주광으로 사용한다. 따라서 Lighting 루트는 추가 보조광만 끈다. Core의 기존 주광 및 Core 환경광은 별도다. 중복 주광은 만들지 않는다.
- Warm Spot: X=-6/-20/-33, Y=9/Z=-3, range17, angle100/inner55, intensity5, RGB(1,.72,.46).
- Bug Spot: X=-42/-49/-56, 같은 높이·범위, intensity25, RGB(.57,.39,1). 따뜻한 기존 주광과 목재 재질 아래에서 실제 화면으로 조정한 값이다.
- Point 강조광: (-44,4,3) 청록(.25,.72,1), (-53,4,3) 자홍(.9,.25,.65), range7, intensity1.5. 모든 추가광 그림자는 None.
- 별도 PostProcessing 루트에 Base Global 및 Warm/Bug Local Volume. 기본 Layer0, 카메라 위치 기준, 콜라이더는 이벤트 연결 없는 영역용 Box Trigger다.
- Warm: center(-13.5,6,0), size(49,32,48), priority20, blend2m. Bug: center(-54.5,6,0), size(31,32,48), priority30, blend2m. Base priority10.
- BootstrapCamera의 씬 인스턴스 m_RenderPostProcessing=1만 override. 공유 프리팹은 보존한다.
- Core: Linear Fog RGB(.43,.42,.46), 시작6m/끝24m. Gradient 환경광 Sky(.28,.29,.34), Equator(.18,.18,.22), Ground(.10,.09,.12). Core를 쓰는 인게임 전체에 적용한다.

## 저장 경계와 완료 기준

Bootstrap/Core 및 전용 Profiles는 저장했다.
