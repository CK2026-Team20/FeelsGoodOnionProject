# 설정 변경 리뷰

2026-10-16. 이번 작업에 게임 코드 또는 새 C# 파일은 없다. 아래는 메인의 실제 자산·실행 근거 대조이며 독립 리뷰 완료를 의미하지 않는다.

- Bootstrap의 작업 시작 디스크 대비 diff는 카메라 인스턴스 m_RenderPostProcessing=1 override 하나다. 공유 Camera prefab은 수정하지 않았다.
- Core의 작업 시작 디스크 대비 diff는 RenderSettings Fog/Gradient 환경광이다. 기존 KitchenLight, 카메라 리그, 게임 연결은 보존했다.
- Stage의 새 루트는 Lighting/PostProcessing 두 개다. 새로운 추가 조명8개는 전부Realtime이며 그림자None. 유일 주광은 기존 Core KitchenLight다.
- Local Volume BoxCollider에는 StageTrigger·Rigidbody·이벤트 연결이 없다. 실제 출력 카메라 위치와 Layer0 기반으로 Volume가 평가된다. 게임 체크포인트 데이터에 의존하지 않는다.
- Profile 세 개의 VolumeComponent는 네이티브 subasset으로 저장되고 파라미터 override가 활성화되어 있다. Bloom 외 제외 효과는 Base에서 명시적으로 껐다.
- 기존 Transform1484개의 pose/scale이 동일하다. 아트 백페이스에 대한 회전·양면화, 물리 변경은 없다.
- 미저장 사용자 Plane/ProBuilder 편집과 이번 변경을 구분했다. 원본 Stage 파일은 저장하지 않았으며 시작 상태·최종 상태의 native 복사본을 output에 보관했다.
- 실행 검증의 준비/API 호출/합성 입력/실제 물리 관찰을 구분해 기록했다. Patrol 기존 오류 및 할당 수명 경고를 성공으로 덮지 않았다.
- 성능은 제한된 Editor 표본이다. 순간 지연과 최종 사용자 색감 승인·원본 Stage 저장 대기를 남긴다.
- Git 커밋·push·브랜치 변경은 수행하지 않았다. diff/status 조회만 사용했다.
