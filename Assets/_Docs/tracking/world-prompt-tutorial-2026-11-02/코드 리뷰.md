# 코드 리뷰

- WorldPromptViewModel의 표시값을 기존 명세의 F 한 개로 통일했다. 기존 SetPrompt 시그니처는 호출 호환을 위해 유지한다. 상태 소유권과 입력 경로는 바꾸지 않았다.
- GameUiRoot, InteractionPromptCanvas, MultiFuncPlatforms의 WorldPromptView 참조 TMP에 IM_Hyemin-Bold SDF와 대응 머테리얼, NoWrap을 적용했다. RectTransform/스프라이트 크기는 변경하지 않았다.
- 기존 한글 깨짐은 LiberationSans의 한글 글리프 부재, 줄바꿈은 85×80 텍스트 영역에 fontSize68의 F 상호작용 문자열을 넣은 결과였다. 폰트와 표시 문자열 양쪽을 수정했다.
- MultiFuncPlatforms 저장 때 Unity가 추가한 비관련 직렬화 갱신은 작업 전 백업 기준으로 제외하고 해당 TMP 블록만 남겼다.
- 메모와 트레이 등 상호작용은 공용 프롬프트를 사용한다. 메모 본문은 별도 Screen Canvas/Sprite이므로 월드 텍스트로 변환하지 않았다.
- Tutorial/Installation/EntrySettings는 수정하지 않았다.
