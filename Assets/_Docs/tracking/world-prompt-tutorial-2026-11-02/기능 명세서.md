# 월드 프롬프트 및 Tutorial 연결 조사

목표: 메모·상호작용 공용 월드 프롬프트의 폰트를 IM_Hyemin-Bold SDF로 통일하고 깨짐/줄바꿈을 제거한다. Tutorial 진입 실패는 읽기 전용으로 조사한다.

참고: WorldPromptView/WorldPromptViewModel, DirectSceneTestInteraction, CoreUiBinding, 세 프롬프트 소비 프리팹, StageService/StageTrigger, Installation/EntrySettings.

제약: 원본 아트/폰트/import 변경 금지. Tutorial 씬과 연결 설정은 변경하지 않는다. 기존 변경 보존. ViewModel 상태·명령 계약 유지.

완료 기준: 세 프롬프트의 폰트 참조, 한글 글리프, 한 줄 메시 검사; 실제 바인딩/해제 점검; Tutorial 누락 항목과 Inspector 작성 순서 기록. Play 진입 성공으로 표현하지 않는다.
