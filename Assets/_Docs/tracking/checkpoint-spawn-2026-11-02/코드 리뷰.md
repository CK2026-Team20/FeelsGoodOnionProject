# 코드 리뷰

SpawnPlacement는 발바닥/중심 계산과 물리 검사를 공유한다. CheckpointSpawnPoint는 작성 참조와 에디터 표시만, StageService는 저장/활성화 장부만, SessionActorHost는 생성·정리만 소유한다. ViewModel이나 전역 검색을 추가하지 않았다. LevelCameraService는 현재 폼에 맞춰 보정 목적지를 계산한다.

체크포인트 Position 의미를 발바닥으로 통일하고 추격 저장 소비도 변환했다. 별도 직접 테스트 StartPoint는 기존 중심 계약을 명시적으로 보존한다. snapshot에 대체 위치/폼/월드 상태를 추가하지 않았다. Host는 실패 시 기존 정리 경로를 사용한다. 캡슐 로컬 center가0이 아니어도 기존 PlaceColliderCenter를 재사용해 발 위치를 맞춘다.

기존 보호 HMS/프리팹/아트 원본 수정 없음. 현재 Tutorial에는 Undo 가능한 Anchor·참조 override만 추가했으며 씬 저장/재로드 없음. 다른 씬의 체크포인트 원본을 일괄 변경하지 않았다. 현재 플레이 중 세션은 없으며 메모리 스냅샷이므로 영속 세이브 마이그레이션은 없다.

한계: 물리 Collider 없는 외형, 실제 모델 발끝과 Capsule 최하단 차이, 접지 면적/움직이는 지지면/사망 Retry 전체 흐름은 실제 플레이 확인이 필요하다. Inspector의 Normal Capsule은 실제 Host 프리팹과 일치시켜야 한다. Host의 실제 형상 재검사로 잘못된 프리뷰 형상을 최종 안전 판정으로 사용하지 않는다.
