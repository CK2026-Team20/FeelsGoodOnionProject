## 경고 분류

- ParticleSystem Renderer의 Sphere1개 Read/Write 비활성: 현 엔진의 빌드 자동 보정 경고. 향후 버전 대응 필요.
- MeshCollider가 참조한 메시34개의 triangle/convex pre-baked collision 비활성: 현 빌드가 자동 준비했으며 향후 import/메시 작성 정책 검토 필요. 원본 아트 import를 이 작업에서 임의 수정하지 않았다.
- 기존 DemiLib/DOTween/DOTweenPro PluginImporter 구버전 메타 경고가 반복 집계된다.
- ChaseRuntimeDriver의 obsolete Physics.autoSyncTransforms 경고1개.
- Hidden/Core DebugOccluder·DebugOcclusionTest 파이프라인 불일치 stripping 경고 및 TMP debug pragma 경고.
- RuntimePipelineConfig 없음: Player에서 에이전트 Pipeline 연결 기능이 비활성이라는 경고다. 게임 실행 실패라는 뜻이 아니며, 이번에 Player 원격 제어 설정을 추가하지 않았다.

52는 반복을 포함한 보고서 합계이며52개의 서로 다른 제품 결함이라는 뜻이 아니다. 오류0을 경고0이나 전체 게임 QA 완료로 표현하지 않는다.

## 자동 생성·보존

빌드 중 PerformanceTestRunInfo/Settings 임시 Resources가 생성됐으나 빌드 완료 후 제거됐다. 제품 자산으로 커밋하지 않는다. URP GlobalSettings의 m_RuntimeSettings17항목 생성은 빌드에서 관측한 자동 직렬화 차이로 분류하여 포함한다. PC_RPAsset/GraphicsSettings/TimeManager의 상태 표시는 최종 Git 정규화 후 의미 diff와 구분한다. 기존 ProBuilder 설정 및 사용자 아트/import 변경은 이번 빌드의 신규 수동 수정으로 귀속하지 않는다.

코드 diff-check에는 오류가 없었다. Unity가 저장한 씬 YAML의 빈 value 뒤 공백은 원본 포맷을 직접 재작성하지 않는다. 원본 코드·자산의 공개 커밋 이력은 재작성하지 않는다.
