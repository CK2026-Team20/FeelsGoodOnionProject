# 빌드·PR 범위 리뷰

2026-10-16 메인 대조 검토. 독립 리뷰어 승인으로 표현하지 않는다.

- 기준 main과 HEAD 일치를 확인했다. 기존 공개 커밋을 다시 쓰지 않고 현재 브랜치에 누적 로컬 변경을 새 커밋으로 기록한다.
- HMS 소스 diff2개를 실제 메서드와 SYM 소비자까지 읽었다. CharacterMovement의 접지 상태 소유권은 유지되고 선택적 필터 계약만 추가된다. OilSurface는 명시 기름 영역의 실제 겹침을 검증하고 기존 효과 담당으로 위임한다. 상세는 변경 내역 및 HMS 검토.md다.
- 씬 흐름·수명·음악·발판·플레이어 표현 변경은 실제 코드 diff와 각 단계 기록을 대조했다. 기록의 과거 비Play/Editor Play 범위를 Windows 빌드 전체 QA로 확대하지 않는다.
- GUID 이동과 삭제를 구분했다. 같은 GUID 목적지29개, 목적지 없는 삭제7개를 분류했다. 남은 CheckpointMarker GUID는 기존 보존씬 한 곳이며 현재4씬 빌드 대상에 없다.
- 프로필은 Windows64와 정확한4씬을 지정한다. 빌드 직전 설치 Catalog·Entry·Audio 유효성을 검증하고 성공한 BuildReport와 생성된 exe/Data를 확인했다.
- build-files.json의219파일과 PE machine0x8664를 확인했다. 4개의 level0~3 데이터가 존재한다. 빌드 이후 게임 코드를 추가 변경하지 않았다.
- 아트/import·ProBuilder·TMP 변경의 실제 작성 주체를 미커밋 파일만으로 추정하지 않는다. URP RuntimeSettings 캐시는 이번 빌드 중 발생한 자동 직렬화 차이로 분류했다.
- 빌드 출력과 output 검증 파일은 커밋에서 제외한다. 코드 diff-check와 민감 키 패턴 파일명 검사는 발견0이다. Unity 직렬화 YAML의 빈 value 공백은 직접 정리하지 않는다.
- 실제 Windows Player 실행/인간의 최종 QA는 미수행이며 기존 Patrol·백페이스·콘텐츠·기절 관측 한계는 남긴다.
