# 문서와 원본 교차 검토

코드 변경은 없다. 검토 범위는 현재 구현에 대한 문서 설명과 작업자 권한이다.

## 확인한 핵심 경계

- GameFlowService·GameSessionRuntime·SessionActorHost: 앱·세션·Actor의 수명과 재시도·제목 복귀 차이.
- GameSessionService·StageService: 스냅샷 식별자와 재로드 후 위치 원본의 분리.
- PlayerBridgeService·GameplayInputRouter: 요청 수락과 발동 성공, F 상호작용과 기존 E 입력 분리.
- DialogueTableService·DialogueService: 데이터 경계 검증과 표시·진행·로그·옵션 취소.
- ChaseModel·ChaseSettings·ChaseDefinition: 거리 기반 포획과 실제 자산 수치.
- Features/TearFragment·LevelTearFragment: 가득 찬 인벤토리에서 서로 다른 현재 소비 규칙.
- ArchitectureInstallation·IntegrationBuildPipeline·EditorBuildSettings: 전용 여섯 씬 빌드와 일반 씬 목록의 차이.

## 확인이 필요한 자산

IntegrationEntrySettings.asset의 abilities 문자열에 숫자 외 접미사가 있다. Editor 로드 결과를 확인하지 않았으므로 런타임 실패라고 단정하지 않는다. 문서 범위를 벗어나 자동 수정하지 않는다.

## 독립 검토 결과

2026-10-04 작성자와 다른 검수자 1명이 한국어 문서의 내용·형식·필수 구성·원본 일치를 읽기 전용으로 검토했다.

| 지적 | 반영 내용 | 재확인 |
|---|---|---|
| 대화 JSON 입력 범위 | 공백 문자열 거절과 float.MaxValue 상한 명시 | 해소 |
| 탈출 진행도 조건 | 큰 진행도·동일/이전 진행도·유효 체크포인트 부재 구분 | 해소 |
| 플레이어 연결 실패 | 입력·수명·재진입 예외와 부분 진행 가능성 명시 | 해소 |

최초 내용 검수의 수정 문장 재검토에서 남은 차단·권고 사항은 없었다. 실제 Unity 로드·Play·빌드를 통과한 것으로 해석하지 않는다. 최초 배치 시 지역 지침 17개에 대응하는 .meta를 생성했고 이후 재배치에서 추가된 메타데이터는 아래 기록과 구분한다. 기존 게임 자산·메타데이터는 변경하지 않았다.

후속 경로 변경: 사용자 지시로 프로젝트 문서를 Assets/_Docs로 재배치했다. 이동 전후 문서 내용과 기존 PDF·메타데이터의 해시 보존을 확인하고 경로 설명만 수정했다. 루트 두 지침은 동일하게 갱신했고 이동 문서·폴더용 .meta 16개를 추가했다. 기존 게임 자산은 수정하지 않았다.

경로 정합성 검토: 검증 표에 Assets/_Docs 수정 예외가 빠진 부분을 보완하고, 최초 메타데이터 수와 현재 총수를 구분했다. 프로젝트 공통 문서 경로를 Assets/_Docs/로 명시하고 기존 PDF 보존 범위를 구분했다. 이 후속 검토는 경로·권한·기록에 대한 정적 검사이며 최초 기능 설명의 독립 검수와 구분한다.


## 2026-10-04 시스템 기획 초안 DOCX·PDF 제작 검토

Dryforge go의 `.dryforge/handoff.md`, `spec.md`, `plan.md`에 따라 문서 제작만 수행했다. 결과는 `output/Tech_SYM/system-planning/`에 원고·편집본·PDF·근거·검증으로 분류했다. 게임 동작은 현재 의도된 구현으로 기술하며 기존 README·과거 기획 PDF를 동작 근거로 사용하지 않았다.

14개 분류·46개 기능 카드, 시스템도·메뉴 트리·핵심 흐름도 6개, 데이터/보존 정책, 사운드 28행·VFX 23행 대조 및 QA 시나리오를 작성했다. 자체 코드 224개를 기능에 연결하고 루트 조사 파일 2,289개를 포함/제외 이유와 함께 분류했다.

독립 검토자 `system_spec_final_review`가 현재 원본과 초안을 대조했다. HP-01 치명적 피해의 동기 사건 순서를 정정하고, ObjectRotation 설명 누락을 AV-03으로 보완했다. MovingPlatform을 ENV-06으로 분리하고 관련 코드/리소스 ID의 오매핑을 수정했다. 수정본 재검토 결과는 **approved**, 제기된 blocking 잔여 0이다. 상세 기록: `output/Tech_SYM/system-planning/validation/독립 내용 검토.md`.

중요 확인 표시는 I01 Stage2/3 직접 진입 능력 직렬화, I02 눈물 판정/연출 시점 차이, I03 HP 사망/추격 포획 표현, I04 옵션 중 제목 음악 정책의 4건이다. 이를 게임 버그나 신규 구현 승인으로 단정하지 않았다. 시트 링크의 음원·영상 및 셀 색상은 검토하지 않았다.

최종 98쪽을 렌더하여 시각 검사했다. 표의 오른쪽 잘림, 흐름도 분기 라벨 위치, 표 머리글 고립, 씬 안내 문자열의 Unicode 표시를 수정했다. 기존 게임 코드·씬·프리팹·아트·.meta·설정·PDF는 보존했다. 커밋·스테이징·푸시·PR·병합과 Unity 컴파일·Play·빌드는 수행하지 않았다.
