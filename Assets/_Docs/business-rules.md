## 플레이어와 상호작용

방향키 이동, Space 점프, Q 형태 전환, E 눈물, F 상호작용을 사용한다. Side는 X, Quarter는 XZ 이동이며 두 폼의 속도는5m/s다. 대각선 입력으로 속도가 늘지 않으며 공중 조향과 손을 뗀 뒤 감속을 지원한다. 접지 상태의 새 Space 입력만 기본3m/작은2m 점프를 실행한다. 선입력·이중 점프는 없다.

Q는 즉시 작은 폼으로 바뀌면서 껍질 한 개를 남긴다. 작은 상태의 Q는 공간 검사가 성공할 때 껍질 회수와 기본 복귀를 한 행동으로 처리한다. 거리는 제한하지 않는다. 공간 부족이면 둘 다 보존하고 이동 후 다시 Q를 눌러야 한다. 실제 성공한 크기 전환 사이 Q입력은1초 제한이며 표현 완료와 무관하다. 별도 회수 키는 없다. 이동·점프는 가능하다.

E는 조각5개를 즉시 모두 소비한다. 범위에 겹쳐도 벽/사물에 막힌 대상은 적용하지 않으며, 실제 적 Hurt Collider까지 가림 없는 직접 피격이 성립한 대상에만 기절2초를 한 번 적용한다. 루트 중심3차원 구의 기존 후보 탐색과 루트→실제 적 몸체 Raycast를 사용하고 기존 재기절 계약을 유지한다. 미선택 상한/다른적차단 정책은 추가하지 않는다. 지상·공중과 두 폼에서 사용할 수 있고 이동·점프를 막지 않는다. 대상이 없어도 환급하지 않으며 투사체·준비·쿨다운은 없다.

F는2.5m, 전방±60도, 차폐 없는 가까운 유효 대상 하나를 선택한다. 안내는 대상 중심 위에 한 개만 표시한다. 문과 트레이, 서랍3개는 각기 독립된 두 종점 상태를 가진다. 한 번의 입력이 종점까지 작동시키며 장치와 공통 Interact 표현은 동시에 시작한다. 장치 작동 중 PC 이동·점프는 허용한다. 추가 F차단 범위는 기능 명세서의 확정 규칙을 따른다.

메모는 F로 열고 닫는다. Opening 중 닫기는 가능하고 Closing이 완료될 때까지 PC 입력을 막는다. 메모는 자기 월드정지 토큰을 가진다. 대화·로그 자체는 월드를 정지하지 않고 중첩 메모/옵션 토큰을 존중한다. 위에 옵션이 열리면 F를 아래 메모로 전달하지 않는다. 메모와 자동 대화의 중첩은 기능 명세서의 확정 규칙을 따른다.

## 피격·사망·체크포인트

HP최대3, 피해당1, 모든 피해원의 공통 무적2초를 사용한다. 넉백은 수평 반대 방향과 상향의 공통 규칙이다. 피해 제공자가 하나의 넉백 클립 길이를 공통 밀리초 조작제한 시간으로 전달하고 기존 시간 기반 기능을 유지한다. 무적이 끝나면 이어진 접촉도 다시 피해를 줄 수 있다. PC피격이 적 기절을 지우지 않는다.

일반 HP0와 추격 포획은 Dead 표현 완료→Fade→retry 순서다. 데드존은 HP·무적을 무시하고 HP0으로 만들며 Dead 표현을 생략한다. 사망 시 미완료 동작·메모·대화를 취소한다. retry는 HP최대·Normal·껍질0, 속도·피격·넉백·무적 초기화이며 별도 재등장 무적은 없다. 실제 clip이 없으면 안전한 완료 대체로 영구 대기를 막되 실제 재생 성공으로 기록하지 않는다.

**체크포인트 저장값은 현재 ActorBody의 월드 위치(Position)와 보유 눈물조각 수(Fragments) 두 항목뿐이다.** 원본 또는 이후 문서에 모호성이나 다른 저장 요구가 있어도 이 직접 지시가 우선한다. HP·폼·능력·대화·카메라·적·장치·필드·남은 시간·StageId/CheckpointId는 저장 payload에 넣지 않는다. World snapshot·상태 등록자·객체별 저장 ID·앱 재시작용 진행 파일을 만들지 않는다.

유한한 XYZ와 조각0..5를 모두 검증한 뒤 두 값을 함께 교체한다. 실패 시 이전 값이 유지된다. 저장 위치를 Marker의 고정 Pose로 대신하지 않는다. 같은 CP의 중복 입력은 실행 문맥에서 억제하며 ID는 저장·복원 항목이 아니다. 초기 진입은 명시된 Stage/Entry 위치와 초기 조각을 사용한다. retry는 Stage를 초기 재준비하고 PC위치·조각만 저장값으로 복원한다. 적·장치·필드 진행은 복원하지 않는다.

능력 해금과 완료 대화는 한 판의 일반 런타임 상태이며 checkpoint에 저장하지 않는다. 현재 Stage에서 얻은 능력과 연결 안내 완료만 사망 retry에 다시 잠그며 트리거 재접촉으로 활성화한다. 이전 Stage 능력은 유지하고 새 게임·제목 종료에서 비운다. 해금은 지정 구간의 UI·안내 DialogCode로 처리하며 CP에만 종속하지 않는다. Q회수는 별도 능력이 아니다. 앱 종료 후 이어하기는 추가하지 않는다.

## 기믹·적·추격

고정 발판은 별도 스크립트가 필요 없다. 부유는 고정 위치에서 한 착지당 반동, 이동은 부모 로컬 XYZ/속도와 양 끝0.5초 대기, 주기는5초 존재/2초 부재/3초 비충돌 생성과 개별 시차다. 붕괴는 기본 PC윗면만 경고1초 종료 즉시 지지Collider 해제/붕괴다. 작은 폼·껍질 발동, 이탈 취소, 자동 복구는 없다. 압력은 기본 PC·껍질이 누르는 동안 목표로 움직이고 해제 시 복귀하며 재압력은 현재 진행에서 반전한다.

트레이·서랍은 PC와 일반 물체를 운반한다. 기름은 이탈 후3초의 미끄러짐을 갱신하고 HP피해는 없다. 열·끓는물은 공통 피해를 적용한다. 조각은1개가 실제 추가됐을 때만 소비하며 최대5이면 남는다.

일반 적은 Stationary/Shuttle/PatrolChase이며 순찰은 X 또는 Y 한 축이다. X/Y 순찰·Idle·Stunned만 가지며 일반 적 Chase/Return은 제거한다. 기절 중 이동·공격이 멈추고 해제 후 현재 조건을 다시 판정한다. 종류/직렬화 배치의 의미는 실제 자산에서 명시적으로 이관한다. 머리 밟기·적 HP·처치·사망 기름·몸체 bob은 없다.

마지막 무리는 전신의 시작선 통과와 새 캡처 없는 시작 수락 이후 후퇴문을 닫는다.8m 뒤에서4m/s로 진행하고 경로상 gap<=0.8m면 강제 사망이다. Y와 점프로 포획을 피하지 않는다. 옵션은 진행·포획도 정지한다. retry 뒤 새 시작선 통과가 필요하다. Poppo에서 무리를 멈추고 최종 DialogCode 완료 뒤 Ending으로 간다. 구출·껍질 래치·눈물 게이트의 옛 추가 조건은 제거한다.

## 대화·연출·옵션·카메라

대화 코드별 Sequence는1..N이다. Enter/창 클릭은 reveal완성 또는 다음 행 한 동작만 처리하며0.3초 입력 간격을 둔다. Auto는 완전 표시 뒤3초다. 완전 표시 행만 로그에 넣고, 로그는 Auto를 끄고 표시를 정지하며 닫아도 Auto를 재개하지 않는다. 완료 코드는 반복하지 않고 취소는 완료가 아니며 retry 뒤row1부터 다시 시작한다.

Opening/Ending은 순서 있는 원화 한 장과 하단 문구를 컷4초씩 자동 표시한다. 클릭/Enter 다음 컷은 없고 전체 Skip을 제공한다. 컷 수4개 제한·분할·scale 호환은 제거한다. 옵션은 월드와 표시 시계를 모두 멈추고 닫을 때 자기 제한만 해제한다. Esc/X가 같은 닫기 명령이며 수동 Retry/Resume버튼·이어하기는 없다. 음량은 유한0..1, 기본1/.7/1과 PlayerPrefs를 사용하고 기존 저장 실패 시 런타임값 보존·다음 저장 재시도를 유지한다.

App에 출력 Camera/Brain/Listener를 각1개 두고, Core Side/Quarter가상 카메라는 Actor를 명시적으로 추적한다. 전환은 트리거로 시작하며0.6초 기본값과 완료까지 PC입력 제한을 사용한다. 실제 Brain과 Side Z정렬이 끝난 뒤 축을 확정한다. Back/Corridor·Actor 자식 리그·두 출력 교대는 제거한다. 초기 모드는 배치 설정에서 결정하며 checkpoint에 저장하지 않는다.

HUD는HP3/0..5와 필요한 해금 표시를 구독한다. CPID·독립 Recover·거리 Instruction은 제거한다. 화면은 ScreenSpaceOverlay, 월드 안내는 별도 WorldSpaceCanvas다. App/Core/Stage수명과 설치의 정확한6씬·비대상 직접 Play는 유지한다. 실제 아트·clip 연결과 새 실행 결과는 tracking에서 따로 기록한다.
