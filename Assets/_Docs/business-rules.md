# 현재 확정 게임 규칙

> V1.8을 목표로 기술하며 코드 식별자·기존 자산값은 구현 설명이다. 현재 미반영 항목은 [구조 차이 목록](tracking/system-v18-2026-10-29/구조%20차이%20목록.md)을 참조한다.

> 현행 시스템 권위는 V1.8 활성 본문 → 이전 사용자 기능 명세 → 기존 구현 설명 순서다. 지정 원본·예외는 [planning-index](planning-index.md)를 따른다. 구현과 검증 상태는 tracking/status.md 및 실제 증거로 확인하며 문서 개정만으로 완료를 선언하지 않는다.

> 현재 목표는 V1.8 활성 본문이다. 자산 연결·실행 완료는 별도 검증한다.

## 플레이어와 상호작용

방향키 이동, Space 점프, Q 형태 전환, E 눈물, F 상호작용을 사용한다. Side는 X, Corridor와 Quarter는 XZ 이동이며 V1.8 기본 이동 속도는 두 폼 모두5m/s다. 현재 PlayerRoot 설정1.8m/s는 기존 조절값으로 구분하며 이번에 변경하지 않는다. 대각선 입력으로 속도가 늘지 않으며 공중 조향과 손을 뗀 뒤 감속을 지원한다. 접지 상태의 새 Space 입력만 점프를 실행한다. V1.8 목표 높이는 기본3m/작은 폼2m이며 기존 설정 정상1m/Small.5m는 목표 수치와 구분한다. 중력은12m/s²이며 실제 정점은 물리 프레임에서 별도로 확인한다. 선입력·이중 점프는 없다.

Q는 즉시 작은 폼으로 바뀌면서 껍질 한 개를 남긴다. 작은 상태의 Q는 공간 검사가 성공할 때 껍질 회수와 기본 복귀를 한 행동으로 처리한다. 거리는 제한하지 않는다. 공간 부족이면 둘 다 보존하고 이동 후 다시 Q를 눌러야 한다. 실제 성공한 크기 전환 사이 Q입력은1초 제한이며 표현 완료와 무관하다. 별도 회수 키는 없다. 이동·점프는 가능하다.

E는 조각5개를 즉시 모두 소비한다. 범위에 겹쳐도 벽/사물에 막힌 대상은 적용하지 않으며, 실제 적 Hurt Collider까지 가림 없는 직접 피격이 성립한 대상에만 기절2초를 한 번 적용한다. 루트 중심3차원 구의 기존 후보 탐색과 루트→실제 적 몸체 Raycast를 사용하고 기존 재기절 계약을 유지한다. 미선택 상한/다른적차단 정책은 추가하지 않는다. 지상·공중과 두 폼에서 사용할 수 있고 이동·점프를 막지 않는다. 대상이 없어도 환급하지 않으며 투사체·준비·쿨다운은 없다.

F는2.5m, 전방±60도, 차폐 없는 가까운 유효 대상 하나를 선택한다. 안내는 대상 중심 위에 한 개만 표시한다. 문과 트레이, 서랍3개는 각기 독립된 두 종점 상태를 가진다. 한 번의 입력이 종점까지 작동시키며 장치와 공통 Interact 표현은 동시에 시작한다. 장치 작동 중 PC 이동·점프는 허용한다. 추가 F차단 범위는 기능 명세서의 확정 규칙을 따른다.

메모는 F로 열고 닫는다. Opening 중 닫기는 가능하고 Closing이 완료될 때까지 PC 입력을 막는다. 메모는 자기 월드정지 토큰을 가진다. 대화·로그 자체는 월드를 정지하지 않고 중첩 메모/옵션 토큰을 존중한다. 위에 옵션이 열리면 F를 아래 메모로 전달하지 않는다. 메모와 자동 대화의 중첩은 기능 명세서의 확정 규칙을 따른다.

## 피격·사망·체크포인트

HP최대3, 피해당1, 모든 피해원의 공통 무적2초를 사용한다. 넉백은 수평 반대 방향과 상향의 공통 규칙이다. 피해 제공자가 하나의 넉백 클립 길이를 공통 밀리초 조작제한 시간으로 전달하고 기존 시간 기반 기능을 유지한다. 무적이 끝나면 이어진 접촉도 다시 피해를 줄 수 있다. PC피격이 적 기절을 지우지 않는다.

일반 HP0와 추격 포획은 Dead 표현 완료→Fade→retry 순서다. 데드존은 HP·무적을 무시하고 HP0으로 만들며 Dead 표현을 생략한다. 사망 시 미완료 동작·메모·대화를 취소한다. retry는 HP최대·Normal·껍질0, 속도·피격·넉백·무적 초기화이며 별도 재등장 무적은 없다. 실제 clip이 없으면 안전한 완료 대체로 영구 대기를 막되 실제 재생 성공으로 기록하지 않는다.

체크포인트 payload는 체크포인트 StageTrigger의 유한한 월드 Position, 정수 Fragments 0..5, UnlockedAbilities 마스크 None=0/FormChange=1/Tear=2/Both=3의 정확히 세 항목이다. 플레이어 CapsuleCollider 월드 중심을 Position에 맞춰 등장·복귀한다. 수락 전 모든 값을 검증하고 스냅샷과 소비 이력을 원자 확정한다. 수락 전 실패는 이전 snapshot을 지키며 수락 후 표현 취소·사망은 마지막 수락 저장을 유지한다. 첫 저장 전에는 같은 컴포넌트의 시작 체크포인트와 초기 진입 조각·마스크를 사용한다. 같은 체크포인트 재접촉은 갱신하지 않는다. 추격 저장은 V1.8의 시작선 기준이며 기존 플레이어 Collider 중심 저장과 차이가 있다. StageId/CheckpointId·월드 상태·HP·폼·카메라·시간·대화 완료는 저장하지 않는다.

사망은 같은 Stage의 초기 배치·기믹·소비 조각 Root/Collider를 재준비하고 저장 위치·조각·마스크를 새 Normal/HP3 Actor에 복원한다. Stage 출처별 능력 초기화는 사용하지 않는다. 완료/Skipped 대화 장부는 한 판 동안 유지하고 일반 대화는 Cancelled만 재시작 가능하다. 최종 포포 Escape(7)만 완료 장부를 지우지 않고 재접촉 후 새 회차를 허용한다. 추가 재등장 무적·월드 저장 등록자를 만들지 않는다.

해금은 지정 구간의 실제 Trigger/UI/선택한 대화 Code로 처리한다. 현재 해금은 Session 한 원본이며 저장과 복원은 위 snapshot 계약을 따른다. Q 회수는 별도 능력이 아니다. 앱 종료 후 이어하기는 만들지 않는다.

## 기믹·적·추격

고정 발판은 별도 스크립트가 필요 없다. 부유는 고정 위치에서 한 착지당 반동, 이동은 실제 고정 startPoint/endPoint의 월드 위치와 이동속도를 사용하고 양 끝에서0.5초 대기한다. 주기는 초기5초 존재/2초 부재/3초 비충돌 생성과 개별 시차이며 시간을 조절할 수 있다. 실제 메시/몸체 교차의 세로 침투 비율<1/4는 유효한 지지면에 착지 보정하고, 벽·급경사이면 메시 Bounds 중심을 향해 수평으로만 겹침을 해소하며, 정확히1/4 이상은 실제 몸체를 위로 분리하며 사망한다. 껍질은 독립 분리하고 데드존에서 같은 소유 껍질을 현재 플레이어로 반환한다. 붕괴는 기본 PC윗면만 경고1초 종료 즉시 지지Collider 해제/붕괴다. 작은 폼·껍질 발동, 이탈 취소, 자동 복구는 없다. 압력은 기본 PC·껍질이 누르는 동안 목표로 움직이고 해제 시 복귀하며 재압력은 현재 진행에서 반전한다.

트레이·서랍은 PC와 일반 물체를 운반한다. 기름은 이탈 후3초의 미끄러짐을 갱신하고 HP피해는 없다. 열·끓는물은 공통 피해를 적용한다. 조각은1개가 실제 추가됐을 때만 소비하며 최대5이면 남는다.

일반 적은 Stationary/X 순찰/Y 순찰의 세 배치이며 EnemyActor가 Idle/Patrol/Stunned 상태를 직접 소유한다. 추적·복귀·HP·처치·사망 기름·몸체 bob은 없다. 기절 중 이동과 접촉 공격을 멈추고 재기절은 기존 남은 시간 추가 계약을 따른다. 종류·순찰 방향의 이전 저장값은 실제 자산별로 이관하며 enum 값을 추정해서 재해석하지 않는다.

추격은 살아 있는 캐릭터의 몸 전체가 시작선을 넘어간 뒤 시작선 기준 체크포인트에 상태를 저장하고 시작한다. 몸이 시작선이나 퇴로 문에 일부 겹친 동안은 시작·문 닫힘을 기다린다. 추격 경로 기준8m 뒤에서 기본4m/s로 경로를 따라 이동하며 경로상 간격0.8m 이하에서 포획한다. 점프 높이 차이는 무시한다. 사망·타이틀 복귀는 시도를 종료하고 재등장 뒤 시작선 재통과로 새 시도를 시작한다. 포포 도달 시 추격 종료 후 대화·엔딩으로 진행하며 동시 포획은 사망이 우선한다. 현재 접촉/+X/몸체 판정은 미반영 구조다.

## 대화·연출·옵션·카메라

대화 코드별 Sequence는1..N이다. Enter/창 클릭은 reveal완성 또는 다음 행 한 동작만 처리하며0.3초 입력 간격을 둔다. Auto는 완전 표시 뒤3초다. 완전 표시 행만 로그에 넣고, 로그는 Auto를 끄고 표시를 정지하며 닫아도 Auto를 재개하지 않는다. 일반 완료/Skipped 코드는 반복하지 않고 취소는 완료가 아니며 retry 뒤row1부터 다시 시작한다. 포포 최종 Escape 대화만 장부와 별개로 새 회차를 허용한다. 실제 Stage/Trigger/선택 객체/Table/Code/Actor 세대/Round/Session을 확인하고 완료·Skipped 뒤 Ending을 한 번 예약한다. 동시 사망·포획·Cancelled·낡은 콜백은 Ending으로 연결하지 않는다.

Opening/Ending은 순서 있는 원화 한 장과 하단 문구를 컷4초씩 자동 표시한다. 클릭/Enter 다음 컷은 없고 전체 Skip을 제공한다. 컷 수4개 제한·분할·scale 호환은 제거한다. 옵션은 월드와 표시 시계를 모두 멈추고 닫을 때 자기 제한만 해제한다. Esc/X가 같은 닫기 명령이며 수동 Retry/Resume버튼·이어하기는 없다. 음량은 유한0..1, 기본1/.7/1과 PlayerPrefs를 사용하고 기존 저장 실패 시 런타임값 보존·다음 저장 재시도를 유지한다.

App 출력 Camera/Brain/AudioListener는 각1개이고 Core의 Side·Corridor·Quarter 리그를 LevelCameraService가 표현한다. 편집 구도 원본은 StageService의 세 프로필이다. 피사체 중심 반경(m), 수평각·수직각·롤(도), 시선 중심 오프셋·화면 위치·감쇠·시야각을 조절한다. V1.8은 씬별 카메라 이동 경계를 적용하며 경계는 추적 데드존보다 우선한다. 플레이어 이동은 경계로 제한하지 않는다. 현재 프로필 구조에는 이동 경계가 없어 구현이 필요하다. 특정 Confiner 컴포넌트 사용을 명세 자체의 요구로 간주하지 않는다. 플레이어 CameraAnchor는 추적 중심을 제공한다. Side는 X, Corridor/Quarter는 XZ 이동이며 보호 HMS 입력 구현은 유지한다.

현재 구현은 새 시작 체크포인트마다 플레이어 Capsule 중심을 해당 시작 위치로 DOMove 보정한다. 이 보정 방식과 차단 장치 이동 시점은 구현 설명이며 V1.8의 검토 예정 사항을 확정하지 않는다. 끝은 저장만 하고 현재 구간·시점을 바꾸지 않는다. 같은 시점의 새 시작은 카메라 재선택·blend 재시작만 생략하며 보정·저장·음악은 수행한다. V1.8에서는 전환 중 같은 종류·다른 종류의 추가 전환을 금지하고 완료 후 다음 조건을 판단한다. 기존 최신 요청 대체 동작은 미반영 차이다. 사망·취소·Actor/Stage 해제 때 자기 트윈·보정 소유권·입력 제한을 반환하며 낡은 callback은 상태를 바꾸지 못한다. 사용 중인 차단 장치만 플레이어 보정 뒤 고정 목표로 이동한다.

StageService가 같은 씬의 논리 구간, 첫 구간, 현재 구간, 활성화한 체크포인트 집합, 마지막 스냅샷과 그 복귀 구간을 소유한다. 구간에는 서로 다른 시작·끝 StageTrigger, 시점 종류, 실제 음악 Clip·음량·전환 시간, 진입 보정·카메라 전환 시간을 연결한다. 이름·배열 순번은 저장 키가 아니다. Trigger는 접촉을 전달하며 시점·음악·저장 장부를 별도로 편집하지 않는다. 재시도는 같은 Core/Stage와 StageService의 소비 이력을 유지하고 마지막 유효 저장 및 당시 구간·음악·시점을 직접 복원한다. 소비한 센서를 다시 발동하지 않는다. 현재 해금은 GameSessionService 원본이고 저장 시점의 해금은 별도 불변 스냅샷 값이다. Title 복귀에서 세션 종료 후 Stage 전체→Core 순서로 언로드하며 새 게임은 새 객체와 빈 체크포인트 장부로 시작한다.

HUD는HP3/조각0..5와 세션의 Q/E 해금을 구독한다. 해금 전 alpha0.3, 기존 트리거 수락 후 alpha1을 유지하고 snapshot 마스크 복원 때 같은 상태 원본으로 음영과 실행 수락 조건을 갱신한다. CPID·Recover·거리 Instruction 폐기 소비를 제거했다. 시작·접촉 체크포인트는 같은 StageTrigger이고 구형 생성 ID를 사람이 입력하지 않는다. 화면은 ScreenSpaceOverlay, F 안내는 별도 WorldSpaceCanvas에 유효 대상1개다. Core와 01_Stage_Prototype 하나를 additive 로드한다. retry는 같은 씬을 유지하며 옵션·엔딩 이후 Title 복귀는 세션 종료 후 Stage 전체와 Core를 언로드한다. 설치·통합 진입·빌드는 Bootstrap/Title/Core/01_Stage_Prototype 네 씬이다. 실제 실행 검증은 최신 사용자 지시에 따라 수행하며 Editor/API 준비/합성 입력/빌드/Player/팀 평가의 증거를 구분한다.

구간 음악은 StageService의 실제 Clip·음량·전환 시간으로 작성하고 새 구간 시작 및 복귀 맥락에서 요청한다. 같은 실제 Clip이면 재생 위치·게인·진행 중 fade를 다시 시작하지 않는다. 첫 구간 선택을 Opening 동안 유지해 Playing에서 적용하며, 타이틀·오프닝·엔딩·추격 음악의 기존 우선순위는 유지한다.

## 2026-10-10 포포 최종 대화 재생 예외

2026-10-10 사용자 직접 선택: “2번 예외를 허용하는 방안으로 지속합니다”. 포포 최종 대화만 Completed/Skipped 기록이 있어도 재도착 시 첫 행부터 새 대화 회차로 다시 재생할 수 있다. 일반 안내 대화의 완료 장부는 유지하며 반복을 허용하지 않는다. 예외는 실제 포포 종료 트리거(StageTriggerKind.Escape) 접촉과 현재 활성 Stage·살아 있는 Actor·세대·회차 검증을 통과한 경로에만 사용한다. 다시 재생한 최종 대화의 Completed/Skipped만 엔딩을 한 번 예약하며, 같은 프레임 사망·포획, Cancelled, 낡은 callback은 엔딩으로 연결하지 않는다. Options/로그/입력·해제 계약은 동일하다.


## 메시 플랫폼 작성 후속 기준 (2026-10-14)

플레이어 최대 접지각과 현재 캡슐을 사용하며 아래 반구 접촉은 플랫폼이 판정한다. 같은 Rigidbody의 명시된 Collider 목록이 지지면이고 Trigger는 제외한다. Pan은 지지, Oil은 Convex Trigger 미끄러짐이다. Pot·Gratan·Burner 피해 Trigger는 공통 피해 규칙을 사용한다. 메모·단순 프랍·기능상 Box 감지 영역은 메시 전환에서 제외한다. 기하가 검증된 원형 지지면은 쿼터뷰에도 배치할 수 있다. 충분한 내부 통과 공간은 작성 전제이며 별도 안전 위치 복귀는 추가하지 않는다.

## 체크포인트 수락과 아트 배치

CheckpointSnapshot은 접촉한 체크포인트 Transform의 유한 월드 Position, 접촉 순간 Fragments 정수0..5, UnlockedAbilities 마스크0/1/2/3의 정확히 세 값이다. StageService가 유효한 최초 접촉에서 스냅샷과 활성화 이력을 콜백 전에 원자 확정한다. 수락 전 실패는 이전 저장을 유지하고, 수락 후 표현 취소·사망은 이미 수락한 저장과 소비 이력을 유지한다. CapsuleCollider 월드 중심을 Position에 맞추며 HP·폼·껍질·음악·시점·세계 상태는 payload에 추가하지 않는다. 첫 저장 전에는 첫 구간 시작과 Entry 초기 값을 사용하고, 추격 직전 Capsule 중심 저장은 현재 구현이며 목표는 V1.8 시작선 기준 저장이다.

뒷면 메시를 생략한 아트는 구도·추적·전환 중간에서도 뒷면을 노출하지 않도록 배치한다. 최신 사용자 정정으로 반대편 카메라 이동은 철회했고 기존 방향을 유지한다. 사용자가 오브젝트 배치를 회전하는 작업은 에이전트가 완료한 것으로 기록하지 않는다. 보호 아트의 임의 수정·양면화나 HMS 입력 변환으로 우회하지 않으며 현재 백페이스 노출은 미해결 시각 항목이다.

## V1.8 타이틀·컷신 요구

오프닝·엔딩 중 옵션에서 타이틀 복귀를 허용하고 진행 중 컷신을 종료한다. 기존 Playing 전용 복귀와 busy 거절은 미반영이다. 이미지와 하단 텍스트를 분리하는 현재 CinematicView는 목표와 일치한다. V1.7 수정 이력의 이미지 내부 텍스트는 적용하지 않는다.

별도 Title 씬에 실제 3D 배경·오브젝트와 고정 카메라 구도를 구성하고 로고·메뉴를 겹쳐 표시한다. 추적·시점 전환·줌 트리거·체크포인트 연동과 게임플레이 장치·AI·입력은 타이틀에 적용하지 않는다. 메뉴·옵션만 조작하고 지원 화면비에서 잘림을 확인한다. 배경 연출·타이틀 전환·BGM의 검토 예정 사항을 확정 구현으로 적지 않는다.
