# 현재 게임 규칙

2026-10-05 승인 명세와 현재 구현 기준이다. 사용자 직접 지시와 최신 지정 기획서가 우선한다. 실제 검증 완료 여부는 tracking/status.md와 T9 실행 기록을 별도로 참조한다.

## 시작·재시도·종료

- 새 게임은 제목 상태에서만 시작하며 첫 스테이지와 오프닝으로 진입한다. Editor의 스테이지 직접 진입은 해당 진입 설정을 사용하고 오프닝을 생략한다.
- 씬·게임 흐름 전환 중에는 또 다른 흐름 전환 요청을 받지 않는다. 재시도는 플레이 중에만, 제목 복귀는 플레이 또는 복구 실패 상태에서 허용한다.
- 재시도는 현재 세션의 체크포인트와 능력 해금을 유지한다. 플레이어는 다시 생성되어 체력을 회복하고 저장된 조각 수로 복원한다. 현재 게임 진행은 실행 중 세션에 보관하며 앱 재시작 후 이어하기로 간주하지 않는다.
- 같은 스테이지·같은 체크포인트를 다시 밟아도 조각 수 스냅샷을 덮어쓰지 않는다. 새로운 체크포인트를 얻었을 때 갱신한다.
- 형태 전환 해금 시 껍질 회수도 함께 해금한다. 한 판을 끝내면 체크포인트와 해금 상태를 비운다.
- 전환 실패 시 제목 복귀를 시도한다. 그 정리마저 실패하면 가림과 제어 차단을 유지한 실패 상태로 남긴다. 실패를 플레이 성공으로 취급하지 않는다.

## 플레이어·눈물·수집

- 체력은 0~최대 체력 범위다. 사망 후 일반 회복으로 부활하지 않는다. 피해·회복·조각 추가는 실제 변화량을 결과로 사용한다.
- 눈물은 준비 요청과 실제 발동을 구분한다. 실제 발동 시 조각을 지불하고 범위 내 대상마다 한 번씩 기절을 시도한다. 자기 자신과 자기 자식 충돌체는 제외한다. 이미 발동한 후 취소해도 지불한 조각과 적용한 기절은 되돌리지 않는다.
- Architecture의 현재 눈물 자산 값은 조각 5개, 준비 0초, 반경 3m, 기절 2초, 쿨다운 0초다. 이 값은 다른 테스트 자산의 기본값으로 일반화하지 않는다.
- Architecture 스테이지의 조각은 실제 추가량이 양수일 때만 사라진다. 가득 찼거나 사망한 플레이어는 소비시키지 않는다.
- 별도 기존 수집 컴포넌트는 활성 플레이어 접촉 시 추가량과 무관하게 조각 루트를 비활성화한다. 두 수집 경로의 차이는 현재 의도된 동작이며 자동 통일하지 않는다.

## 전투·기믹·상호작용

- 일반 적의 밟아 죽이기와 추격 상태는 제거했다. 기절한 적은 접촉 피해를 주지 않는다. 접촉 피해가 실제로 들어간 경우에만 해당 접촉의 피해 소비와 넉백을 처리한다. 입력 차단만으로 무적이 되지는 않는다.
- 압력판은 활성 무게 표시가 있는 점유자로 눌린다. 눌림·복귀는 현재 진행률부터 움직이며 연결 발판도 같은 진행을 따른다.
- 신규 프로토타입 붕괴 발판은 canRegenerate=false로 저장하며 붕괴 후 복구하지 않는다. 기존 공유 프리팹의 설정을 일반화하지 않는다.
- 선형 발판은 시작점에서 부모 기준 X/Y/Z 도착점 이동량만큼 왕복한다. 부모의 위치·회전·배율 변화가 양 끝점에 반영되고 초당 월드 경로 속도는 설정값을 사용한다. 편도시간은 현재 월드 거리/속도이며 끝점에서 기다리지 않는다. 이동량 0은 정지다. 잘못된 수치가 비정상 위치나 운반 속도를 만들지 않아야 한다.
- 붕괴 발판은 무거운 플레이어의 윗면 접촉으로 경고를 한 번 시작한다. 작은 상태·옆면·밑면은 시작하지 않으며 시작 후 플레이어 이탈은 경고를 취소하지 않는다. 경고 완료 → 지지 충돌체 해제 → 실제 붕괴 애니메이션 완료 → 외형 숨김·설정된 제거/복구 순서다. 클립 미연결 상태는 한 실행에 경고 한 번을 남기고 충돌체 해제·숨김·후처리를 진행한다. 정지 중 경고·붕괴·복구 시간이 진행되지 않으며 비활성화·재사용에서 이전 작업이 남지 않는다.
- 트레이는 닫힘·열림의 두 종점 사이를 이동한다. 이동 중에는 새 상호작용을 거절한다. 비활성화로 멈췄다면 남은 이동 시간으로 이어간다.
- 메모 상호작용은 E로만 열고 닫는다. 마우스 종료 버튼은 제공하지 않는다. 열린 메모의 닫기가 월드 상호작용보다 우선하며 메모가 열려 있는 동안 플레이어 입력을 차단한다. 2026-10-05 후속 직접 지시가 이전 E/X 명세를 대체한다.
- 방향키 이동·Space 점프·F 눈물·E 상호작용·Q 상태 전환을 사용한다. 별도 껍질 회수 키는 없다. Q 복귀 공간이 부족하면 작은 상태와 껍질을 유지하고, 복귀가 가능하면 거리와 무관하게 껍질을 회수한다. 입력 소비자는 하나만 설치한다.

## 스테이지와 추격

새 게임은 기능 응집 Prototype/1_Stage 하나를 로드하고 오프닝→플레이→엔딩→제목으로 진행한다. 기존 Stage2/3 직접 진입 계약은 유지한다. 능력은 체크포인트에서 해금하며 눈물로 길 열기는 사용하지 않는다. 탈출에는 구출과 유효한 체크포인트 이후 껍질 퍼즐 해결, 추격 시작 수락이 필요하다.

카메라는 지정 트리거 접촉으로만 전환한다. side는 X, 통로는 월드 Z, quarter는 XZ 이동을 허용한다. 전환 중 입력을 차단하고 실제 화면 블렌드와 통로 X/side Z 정렬 보간이 모두 끝난 뒤 물리 축 제한을 확정한다. 같은 구간 재접촉은 중복 실행하지 않으며 다른 구간 접촉은 이전 전환을 취소하고 최신 요청을 처리한다. 옵션 정지 중에는 화면·정렬·모드 확정을 멈춘다. 가까운 구역 자동 선택은 없다. 모드별 이동 속도 5m/s와 일반 블렌드 약 0.6초는 Inspector 조정 가능 기본값이다.

별도 추격 무리는 경로상 거리로 진행한다. 거리 간격만으로 포획하지 않으며 앞 충돌 트리거가 실제 플레이어와 접촉하면 저장된 체크포인트에서 재시도한다. 일반 적의 추격과 별개다. 세부 물리 동선 검증 상태는 T9 기록에 구분한다.

정렬 위치는 트리거 자신의 로컬 오프셋을 월드 위치로 변환한 점이며 파란 기즈모로 항상 표시한다. 부모·트리거의 위치·회전·배율이 바뀌면 정렬점도 함께 바뀐다. Side에서는 그 점의 월드 Z, 통로에서는 월드 X를 사용하고 Quarter는 위치 정렬을 하지 않는다. 빈 구간 ID·잘못된 수치·지원하지 않는 모드는 진행 중인 정상 전환을 취소하거나 차단을 누출하지 않는다.

## 대화·연출·옵션·소리

- 대화는 한 번에 하나다. 같은 프레임 진행 요청을 중복 처리하지 않는다. 표시 중 진행 입력은 현재 문장을 완성하고, 표시 완료 후 입력은 다음 문장으로 넘긴다.
- 현재 대화 입력 간격은 0.3초, 자동 진행 대기는 3초다. 로그를 열면 자동 진행을 끄고 표시·타이머를 멈춘다. 옵션도 대화 표시를 멈추며 종료·취소 시 자기 입력 차단만 해제한다.
- 컷신은 지정 순서의 단일 원화를 한 장씩 전체화면에 표시하며 레이아웃/스케일 트윈을 적용하지 않는다. 오프닝·엔딩은 완료와 건너뛰기를 정상 종료로 구분하며 취소는 정상 완료가 아니다. 마지막 연출 프레임은 숨김 처리 전까지 유지한다. 옵션으로 표시가 멈춘 동안에는 건너뛰기를 받지 않는다.
- 옵션은 제목·플레이의 안정 상태와 오프닝·엔딩에서 열 수 있다. 플레이 중 옵션의 재시도·제목 복귀만 허용하며 로딩 중 재진입하지 않는다.
- 음량은 0~1의 유한값이며 현재 기본값은 전체 1, 음악 0.7, 효과음 1이다. 옵션을 닫을 때 저장 실패가 나도 옵션은 닫고 실행 중 음량은 유지하며 다음 저장 때 재시도한다.
- 옵션 중 음악과 UI 소리는 유지한다. 월드 정지 중 월드 효과음 요청은 거절하며, 월드 효과음 정리는 전환 전용 소리를 함께 끊지 않는다.

HUD를 제외한 화면 모달은 월드 정지 토큰을 보유한다. 메모는 월드 프롬프트와 화면 본문의 두 Canvas를 사용하며 E로 닫는다. 옵션 중 아래 메모로 입력을 흘리지 않고, 옵션을 닫아도 메모의 정지는 유지한다.

피격 발판은 성공한 피해당 HP1, 같은 대상의 다음 피해까지 최소1초를 보장한다. 접촉 이탈·재진입은 유효 쿨다운을 초기화하지 않는다. 플랫폼 비활성화 또는 대상 파괴에서는 보유 상태를 해제한다.
