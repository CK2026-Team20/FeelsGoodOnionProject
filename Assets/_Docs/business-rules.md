# 현재 게임 규칙

2026-10-04 사용자 확인: 현재 기능은 명세에 따라 구현된 의도된 동작이다. 이후 변경할 사항은 사용자가 별도로 지정한다. 현재 구현된 규칙과 직렬화된 자산 값을 기준으로 하며, 과거 기획의 조건을 덧붙이지 않는다.

## 시작·재시도·종료

- 새 게임은 제목 상태에서만 시작하며 첫 스테이지와 오프닝으로 진입한다. Editor의 스테이지 직접 진입은 해당 진입 설정을 사용하고 오프닝을 생략한다.
- 전환 중에는 또 다른 전환 요청을 받지 않는다. 재시도는 플레이 중에만, 제목 복귀는 플레이 또는 복구 실패 상태에서 허용한다.
- 재시도는 현재 세션의 체크포인트와 능력 해금을 유지한다. 플레이어는 다시 생성되어 체력을 회복하고 저장된 조각 수로 복원한다. 현재 게임 진행은 실행 중 세션에 보관하며 앱 재시작 후 이어하기로 간주하지 않는다.
- 같은 스테이지·같은 체크포인트를 다시 밟아도 조각 수 스냅샷을 덮어쓰지 않는다. 새로운 체크포인트를 얻었을 때 갱신한다.
- 형태 전환 해금 시 껍질 회수도 함께 해금한다. 한 판을 끝내면 체크포인트와 해금 상태를 비운다.
- 전환 실패 시 제목 복귀를 시도한다. 그 정리마저 실패하면 가림과 제어 차단을 유지한 실패 상태로 남긴다. 실패를 플레이 성공으로 취급하지 않는다.

## 플레이어·눈물·수집

- 체력은 0~최대 체력 범위다. 사망 후 일반 회복으로 부활하지 않는다. 피해·회복·조각 추가는 실제 변화량을 결과로 사용한다.
- 눈물은 준비 요청과 실제 발동을 구분한다. 실제 발동 시 조각을 지불하고 범위 내 대상마다 한 번씩 기절을 시도한다. 자기 자신과 자기 자식 충돌체는 제외한다. 이미 발동한 후 취소해도 지불한 조각과 적용한 기절은 되돌리지 않는다.
- Architecture의 현재 눈물 자산 값은 조각 1개, 준비 0초, 반경 3m, 기절 2초, 쿨다운 3초다. 이 값은 다른 테스트 자산의 기본값으로 일반화하지 않는다.
- Architecture 스테이지의 조각은 실제 추가량이 양수일 때만 사라진다. 가득 찼거나 사망한 플레이어는 소비시키지 않는다.
- 별도 기존 수집 컴포넌트는 활성 플레이어 접촉 시 추가량과 무관하게 조각 루트를 비활성화한다. 두 수집 경로의 차이는 현재 의도된 동작이며 자동 통일하지 않는다.

## 전투·기믹·상호작용

- 적 머리를 하강하며 통과하는 밟기와 몸통 접촉 피해를 구분한다. 접촉 피해가 실제로 들어간 경우에만 해당 접촉의 피해 소비와 넉백을 처리한다. 입력 차단만으로 무적이 되지는 않는다.
- 압력판은 활성 무게 표시가 있는 점유자로 눌린다. 눌림·복귀는 현재 진행률부터 움직이며 연결 발판도 같은 진행을 따른다.
- 붕괴 발판은 준비 → 경고 → 붕괴 → 재생성 또는 파괴 예약 순서다. 붕괴 중 지지 충돌을 제거하며 재생성 중에도 지지를 먼저 복구하지 않는다.
- 트레이는 닫힘·열림의 두 종점 사이를 이동한다. 이동 중에는 새 상호작용을 거절한다. 비활성화로 멈췄다면 남은 이동 시간으로 이어간다.
- 기존 메모 상호작용은 E 입력이고, 열린 메모의 닫기가 월드 상호작용보다 우선한다. 메모가 열려 있는 동안 플레이어 입력을 차단한다.
- Architecture는 F로 상호작용하고 E로 눈물을 사용한다. 기존 E 상호작용 처리를 동시에 설치하지 않는다.

## 스테이지와 추격

스테이지 2에서 깊이 이동과 안전 대화를 허용한다. 탈출에는 구출이 필요하며, 스테이지 3에는 추격 시작 수락도 필요하다. 현재 스테이지의 유효한 체크포인트보다 진행도가 큰 미해결 껍질 퍼즐이 있으면 탈출을 막는다. 같은 진행도 또는 이전 퍼즐은 이 조건으로 막지 않으며, 유효한 같은 스테이지 체크포인트가 없으면 모든 미해결 껍질 퍼즐을 검사한다.

스테이지 3 추격은 경로상의 거리로 판정한다. 시작 시 뒤로 8m의 경로와 앞쪽 탈출 공간이 필요하고 플레이어는 경로에서 2m 이내에 있어야 한다. 현재 자산 속도는 4m/s, 포획 간격은 0.8m다.

벌레 진행도 = min(경로 길이, 이전 진행도 + 속도 × 경과 시간). 플레이어 진행도에서 벌레 진행도를 뺀 간격이 포획 간격 이하(수치 오차 허용 0.00001m)이면 잡힌다. 매 프레임 벌레 위치를 플레이어 뒤 8m로 재설정하지 않으며 프레임 지연 시간도 버리지 않는다. 경로 끝에 도달한 것만으로 구출·탈출 성공이 되지는 않는다.

추격 시작 전에 S3_CHASE 체크포인트 확보와 후퇴문을 안전하게 닫을 수 있는지 확인한다. 추격 시작 수락 후에만 문을 닫는다. 재시도에는 새 추격 시도를 만든다.

## 대화·연출·옵션·소리

- 대화는 한 번에 하나다. 같은 프레임 진행 요청을 중복 처리하지 않는다. 표시 중 진행 입력은 현재 문장을 완성하고, 표시 완료 후 입력은 다음 문장으로 넘긴다.
- 현재 대화 입력 간격은 0.3초, 자동 진행 대기는 3초다. 로그를 열면 자동 진행을 끄고 표시·타이머를 멈춘다. 옵션도 대화 표시를 멈추며 종료·취소 시 자기 입력 차단만 해제한다.
- 오프닝·엔딩은 완료와 건너뛰기를 정상 종료로 구분하며 취소는 정상 완료가 아니다. 마지막 연출 프레임은 숨김 처리 전까지 유지한다. 옵션으로 표시가 멈춘 동안에는 건너뛰기를 받지 않는다.
- 옵션은 제목·플레이의 안정 상태와 오프닝·엔딩에서 열 수 있다. 플레이 중 옵션의 재시도·제목 복귀만 허용하며 로딩 중 재진입하지 않는다.
- 음량은 0~1의 유한값이며 현재 기본값은 전체 1, 음악 0.7, 효과음 1이다. 옵션을 닫을 때 저장 실패가 나도 옵션은 닫고 실행 중 음량은 유지하며 다음 저장 때 재시도한다.
- 옵션 중 음악과 UI 소리는 유지한다. 월드 정지 중 월드 효과음 요청은 거절하며, 월드 효과음 정리는 전환 전용 소리를 함께 끊지 않는다.
