## 2026-11-06 효과음 정책 분리

효과음은 카탈로그 SfxPlaybackPolicy로 AlwaysPlay17/ LimitedOneShot3/ VirtualLoop2개를 구분한다. 동일 ID2개·0.08초 제한은 LimitedOneShot에만 적용한다. AlwaysPlay는 기존 SFX를 선점하지 않는 풀 출력이며 음악2채널과 분리한다. VirtualLoop는 거리20m 및 무음 시 Stop·풀 반환하고 논리 위상을 유지한다. 아래 전 효과음 동일 제한·고정 SFX채널 수 설명을 대체한다. BGM 정지/재시도 유지 정책은 보존한다. 실제 결과와 미검증은 Assets/_Docs/tracking/tutorial-render-audio-2026-11-06/를 참조한다.

# 소리

## 책임과 경계

앱 수명 AudioService, Cue 카탈로그와 Unity 재생·음악 크로스페이드 드라이버를 소유한다. 플레이어 성공 판정이나 게임 흐름 결정은 소유하지 않는다.

## 유지할 계약

음악 2채널·UI 1·전환 1·월드 6으로 구분한다. 월드 정리는 전환음을 지우지 않는다. 스킬 요청 수락이 아니라 발동 성공 통지에서 효과음을 실행한다.

게인 계산은 master × music/sfx × cue gain × envelope다. 새 소리 시작 전에 게인을 설정한다. 옵션은 음악과 진행 중인 전환을 Pause/Resume한다. 앱 카탈로그의 씬별 Clip·게인·전환 시간으로 일반 음악을 선택한다. Cue ID가 달라도 같은 실제 Clip이면 재생·게인·진행 중인 fade를 유지한다. 다른 Clip은 현재 envelope의 페이드아웃을 완료한 후 재생한다. 첫 구간 선택을 Opening→LoadingGame에서도 보존하고 Playing에서 적용한다. 기존 타이틀·연출·추격 음악 우선순위를 유지한다.

## 검증

잘못된 Cue, 중복 음악, 크로스페이드 도중 전환, 월드 음성 포화 교체, 옵션·월드 정지와 전체 종료 시 채널 잔존 여부를 검증한다.

현행 지침: Inspector 위치/대상은 실물 참조, 수치는 목적·단위가 명확한 값이다. 씬 월드 객체를 관리자 자식에 묶지 않는다. 에이전트 Play 금지는 철회됐으며 공식 Unity 도구로 승인된 검증을 실행한다. 기존 프리팹 삭제/재생성/Apply·자동 Builder 실행은 해당 작업의 명시 허용 범위를 따른다. 이전 실행 관찰 수는 당시 증거이고 이번 통과가 아니다.
