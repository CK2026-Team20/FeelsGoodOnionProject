# 소리

## 책임과 경계

앱 수명 AudioService, Cue 카탈로그와 Unity 재생·음악 크로스페이드 드라이버를 소유한다. 플레이어 성공 판정이나 게임 흐름 결정은 소유하지 않는다.

## 유지할 계약

음악 2채널·UI 1·전환 1·월드 6으로 구분한다. 월드 정리는 전환음을 지우지 않는다. 스킬 요청 수락이 아니라 발동 성공 통지에서 효과음을 실행한다.

게인 계산은 master × music/sfx × cue gain × envelope다. 새 소리 시작 전에 게인을 설정한다. 옵션 중 음악을 멈추지 않으며 자기 트윈만 취소한다. StageService 구간의 Clip·게인·전환 시간으로 구간 음악을 요청한다. Cue ID가 달라도 같은 실제 Clip이면 재생·게인·진행 중인 fade를 유지한다. 다른 Clip만 현재 envelope에서 교차 전환한다. 첫 구간 선택을 Opening→LoadingGame에서도 보존하고 Playing에서 적용한다. 기존 타이틀·연출·추격 음악 우선순위를 유지한다.

## 검증

잘못된 Cue, 중복 음악, 크로스페이드 도중 전환, 월드 음성 포화 교체, 옵션·월드 정지와 전체 종료 시 채널 잔존 여부를 검증한다.

현행 지침: Inspector 위치/대상은 실물 참조, 수치는 목적·단위가 명확한 값이다. 씬 월드 객체를 관리자 자식에 묶지 않는다. 에이전트 Play 금지는 철회됐으며 공식 Unity 도구로 승인된 검증을 실행한다. 기존 프리팹 삭제/재생성/Apply·자동 Builder 실행은 해당 작업의 명시 허용 범위를 따른다. 이전 실행 관찰 수는 당시 증거이고 이번 통과가 아니다.
