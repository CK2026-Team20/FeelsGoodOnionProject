# 스테이지 구간과 카메라

시스템 동작은 V1.8 활성 본문을 이전 사용자 기능 명세와 기존 구현보다 우선한다. 작업 권한·파일 소유권·공식 Unity 도구 사용·미저장 편집 보호는 별도 경계로 유지한다. 색상·취소선·검토 예정 사항과 수정 이력을 구별하며, 폐기된 변경 이력을 현행 요구로 적용하지 않는다.

V1.8 목표는 씬별 카메라 이동 경계와 전환 중 추가 전환 금지다. 아래는 현재 구현이며 경계 없음·기존 전환 취소/대체·추격 Capsule 중심 저장은 목표와 다르다. 상세: `Assets/_Docs/tracking/system-v18-2026-10-29/구조 차이 목록.md`.

StageService가 같은 씬의 논리 구간, 첫 구간, 현재 구간, 활성화한 체크포인트 집합, 마지막 스냅샷과 그 복귀 구간을 소유한다. 구간에는 서로 다른 시작·끝 StageTrigger, 시점 종류, 진입 보정·카메라 전환 시간을 연결한다. 이름·배열 순번은 저장 키가 아니다. Trigger는 접촉을 전달하며 시점·음악·저장 장부를 별도로 편집하지 않는다.

CheckpointSnapshot은 접촉한 체크포인트 Transform의 유한 월드 Position, 접촉 순간 Fragments 정수0..5, UnlockedAbilities 마스크0/1/2/3의 정확히 세 값이다. StageService가 유효한 최초 접촉에서 스냅샷과 활성화 이력을 콜백 전에 원자 확정한다. 수락 전 실패는 이전 저장을 유지하고, 수락 후 표현 취소·사망은 이미 수락한 저장과 소비 이력을 유지한다. CapsuleCollider 월드 중심을 Position에 맞추며 HP·폼·껍질·음악·시점·세계 상태는 payload에 추가하지 않는다. 첫 저장 전에는 첫 구간 시작과 Entry 초기 값을 사용하고, 추격 직전 예외만 당시 플레이어 Capsule 중심을 저장한다.

새 시작 체크포인트마다 플레이어 Capsule 중심을 해당 시작 위치로 DOMove 보정한다. 끝은 저장만 하고 현재 구간·시점을 바꾸지 않는다. 같은 시점의 새 시작은 카메라 재선택·blend 재시작만 생략하며 보정·저장은 수행한다. BGM은 앱의 씬별 설정을 유지한다. [현재 구현·V1.8 미반영] 새 유효 시작은 이전 보정·전환을 취소하고 최신 요청이 완료하도록 한다. 사망·취소·Actor/Stage 해제 때 자기 트윈·보정 소유권·입력 제한을 반환하며 낡은 callback은 상태를 바꾸지 못한다. 사용 중인 차단 장치만 플레이어 보정 뒤 고정 목표로 이동한다.

재시도는 같은 Core/Stage와 StageService의 소비 이력을 유지하고 마지막 유효 저장과 당시 구간·시점을 직접 복원하고 일반 BGM은 앱 정책으로 처음부터 재생한다. 소비한 센서를 다시 발동하지 않는다. 현재 해금은 GameSessionService 원본이고 저장 시점의 해금은 별도 불변 스냅샷 값이다. Title 복귀에서 세션 종료 후 Stage 전체→Core 순서로 언로드하며 새 게임은 새 객체와 빈 체크포인트 장부로 시작한다.

App의 게임 출력 Camera/Brain/AudioListener와 Title 씬의 전용 Camera/AudioListener를 분리한다. 타이틀 표시 중 게임 출력은 비활성화하고 Title 해제 시 원래 상태를 복원하여 활성 출력·Listener는 하나만 유지한다. Core의 Side·Corridor·Quarter 리그는 게임 출력만 구동한다. 편집 구도 원본은 StageService의 세 프로필이다. 피사체 중심 반경(m), 수평각·수직각·롤(도), 시선 중심 오프셋·화면 위치·감쇠·시야각을 조절한다. [현재 구현·V1.8 미반영] 카메라 위치 바운더리와 Confiner, 별도 CameraZoneTrigger·SafeAnchor·Alignment는 사용하지 않는다. 플레이어 CameraAnchor는 추적 중심을 제공한다. Side는 X, Corridor/Quarter는 XZ 이동이며 보호 HMS 입력 구현은 유지한다.

일반 BGM은 Bootstrapper의 AudioCueCatalog에 SceneAsset별로 작성한다. Integration은 StageId만 전달하고 AudioFlowBinding이 곡을 선택한다. 구간 트리거에는 음악 설정이 없다. 같은 Clip은 재시작하지 않으며 사망 후 복귀는 정지 후 처음부터 재생한다.

뒷면 메시를 생략한 아트는 구도·추적·전환 중간에서도 뒷면을 노출하지 않도록 배치한다. 최신 사용자 정정으로 반대편 카메라 이동은 철회했고 기존 방향을 유지한다. 사용자가 오브젝트 배치를 회전하는 작업은 에이전트가 완료한 것으로 기록하지 않는다. 보호 아트의 임의 수정·양면화나 HMS 입력 변환으로 우회하지 않으며 현재 백페이스 노출은 미해결 시각 항목이다.

StageTrigger의 Fall·해금·일반 대화·추격·Escape는 각 기존 계약을 유지한다. 체크포인트 1회성을 반복 데드존까지 확대하지 않는다. 추격 무리·퇴로는 같은 씬의 실제 참조이며 고정 센서를 움직이는 무리 아래에 두지 않는다. 최종 Escape는 현재 Stage/Trigger/Table/Code/Actor 세대/회차를 확인하고 Completed/Skipped만 Ending을 한 번 예약한다. 사망·취소·낡은 callback은 종료를 예약하지 않는다.

2026-10-15 직접 지시로 에이전트 Play/Player 금지와 과거 검증·QA 역할 고정을 철회했다. 승인된 기능의 실제 Editor Play를 공식 Unity 플러그인으로 수행하고 실행 근거대로 판정한다. API 위치 준비, 실제 InputSystem 합성 입력, 사람 직접 조작, 빌드·Player 실행, 팀 평가를 구분한다. 미저장 작업·파일 소유권·Git 승인 경계는 유지하며 실행하지 않은 항목을 통과로 기록하지 않는다.
