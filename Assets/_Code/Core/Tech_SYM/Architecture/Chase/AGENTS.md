# 추격

최신 적용 기준은 `Assets/_Docs/planning-index.md`와 `tracking/ready-system-v11-refactor-2026-10-06/기능 명세서.md`다. 이 지침은 새 목표이며 기존 코드의 실행 완료를 뜻하지 않는다.

## 책임과 경계

추격은 경로 투영·진행 거리·포획 상태와 벌레 표현을 소유한다. Stage는 전체 플레이어 Collider의 시작선 통과, 후퇴문, Poppo와 최종 대화 연결을 소유한다. 사망·재시도는 Session의 단일 경로를 사용한다.

## 유지할 계약

한 시도는 한 번 시작한다. 시작 전 현재 ActorBody의 월드 위치와 보유 눈물조각 두 값만 캡처하고, 캡처와 추격 시작이 수락된 뒤 문을 닫는다. 적·기믹·HP·폼·카메라·시간·ID를 저장하지 않는다. 동일 체크포인트라는 이유로 추격 직전의 두 값 캡처를 생략하지 않는다.

무리는 처음에 플레이어의 경로상 위치보다 8m 뒤에서 시작하며 4m/s로 전진한다. 높이를 제외한 경로상 간격이 0.8m 이하이면 무적을 무시하는 강제 사망을 한 번 요청한다. 기존 FrontContact의 접촉 판정은 이관 후 제거한다. 경과 시간을 버리지 않고 경로 끝으로 제한한다.

옵션은 전체 추격 시간을 정지한다. 메모·대화는 월드를 멈추지 않는다. 포획 사망은 실제 사망 표현 완료 후 재시도한다. 재시도에는 새 추격 모델을 만들고 시작선의 새로운 전신 통과를 요구한다. 이미 시작선 안쪽에 복원됐다는 이유로 자동 재시작하지 않는다. Poppo에 도달하면 추격을 멈추고 최종 대화 완료 후 Ending으로 이동한다. 이전 구출/탈출 퍼즐 상태는 제거한다.

## 검증

경로 없음·비유한 좌표·전체 Collider 통과 경계·시작 거절과 문 상태·초기 간격·포획 0.8m 경계·큰 deltaTime·옵션·Actor 소실·포획 후 사망 완료·재시도 재통과·Poppo/최종 대화 취소를 사용자 기능으로 검증한다. 실제 실행 전 통과로 기록하지 않는다.
