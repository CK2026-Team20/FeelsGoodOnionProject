# 추격

## 책임과 경계

경로 투영·거리 진행·포획 상태, 런타임 갱신과 벌레 표현을 소유한다. 구출·탈출·후퇴문 판정은 Level 소유다.

## 유지할 계약

한 시도는 한 번 시작하며 재시도에는 새 모델을 만든다. 초기 간격 8m를 매 Tick 재설정하지 않는다. 경과 시간을 버리지 않고 경로 끝으로 제한한다.

현재 Stage 3 전용 연결을 임의로 전 스테이지에 확대하지 않는다. 시작 거절은 문 닫기 성공으로 취급하지 않으며 정지 이유를 유지한다.

현재 작업자는 Tech_SYM이며 변경은 승인된 Tech_SYM 범위에 한정한다. Tech_HMS 등 다른 작업자 폴더, 공용 Interfaces, _Art 원본과 그 .meta는 참조 전용이다. 같은 직군의 별도 명시적 파일 허용이 없는 한 수정하지 않는다.

## 검증

경로 없음·비유한 좌표, 시작 뒤 공간 부족, 경로 이탈, 포획 경계, 큰 deltaTime, 일시정지·Actor 소실·재시도 상태를 검증한다.

실행하지 않은 검증을 통과로 기록하지 않는다. Editor의 자산 생성 메뉴와 읽기·검증 메뉴를 구분하며 다른 기능의 씬을 재생성하지 않는다.
