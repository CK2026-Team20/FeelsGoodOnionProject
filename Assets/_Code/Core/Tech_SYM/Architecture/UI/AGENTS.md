# 화면·옵션

2026-10-10 최신 목표는 Assets/_Docs/planning-index.md와 ready-system-v15-2026-10-10 명세를 따른다. 이 문서는 구현 완료 기록이 아니다. 기존 지침의 다른 동작을 새 목표로 승계하지 않는다. 보호 원본/메타/아트 수정은 파일별 허가가 필요하다.

Service/Model→ViewModel→View의 상태/명령 연결을 지킨다. VM은 View를 직접 참조하지 않고 View가 전역서비스 검색/업무 판정/저장을 실행하지 않는다. 자기 구독/버튼리스너만 해제하고 재바인딩1입력1명령을 확인한다.

옵션은 Esc/X닫기, 월드+표시 정지, 겹친 메모/대화의 제한은 유지한다. 수동Retry/Resume버튼/이어하기는 제외하고 사망자동retry는 남긴다. Title/연출에서 제목복귀를 노출하지 않는다. 음량은0..1유한/기본1,.7,1·PlayerPrefs이며 기존 저장실패의 런타임값보존/다음저장 재시도를 유지한다.

HUD는HP3/0..5와 Q/E 능력의 해금 전 음영·해금 후 활성 표시, 안내는DialogCode다. 현재 Stage retry의 재잠금과 재접촉을 같은 세션 원본에 바인딩한다. CPID/독립Recover/거리Instruction은 제거한다. WorldPrompt한 경로로 통합하고 대상중심 위F를 App출력 방향으로 표시한다. 실제 아트원본은 수정하지 않는다. 화면종료/사망·옵션중첩/저장실패·구독중복을 검증한다.

현행 지침: Inspector 위치/대상은 실물 참조, 수치는 목적·단위가 명확한 값이다. 씬 월드 객체를 관리자 자식에 묶지 않는다. 에이전트 Play 실행·기존 프리팹 삭제/재생성/Apply·자동 Builder 실행은 금지다. 이전 실행 관찰 수는 당시 증거이고 이번 통과가 아니다.
