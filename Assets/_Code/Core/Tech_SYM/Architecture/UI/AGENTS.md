# 화면·옵션

UI 레이아웃과 UI 기능의 필수 기준은 `Assets/_Docs/Cooked!_UI기획서Ver2.1.pdf`와 최신 사용자 직접 지시다. 배치·아이콘·텍스트뿐 아니라 버튼/단축키 동작·화면 전환·표시 조건·입력과 상태 변화도 이 기획서를 읽고 구현·수정·검증한다. 시스템 연동은 planning-index의 V1.8을 이전 지시와 UI 문서보다 우선한다. 일반 플레이 옵션 버튼 제거·ESC 옵션 유지·플레이 중 포인터 숨김은 V1.8과 충돌하지 않는 범위에서 적용한다. 구현·검증 완료는 tracking/status.md와 실제 증거로 확인한다. 보호 원본·메타·아트의 쓰기 권한은 최신 파일별 허용 범위로 한정한다.

Service/Model→ViewModel→View의 상태/명령 연결을 지킨다. VM은 View를 직접 참조하지 않고 View가 전역서비스 검색/업무 판정/저장을 실행하지 않는다. 자기 구독/버튼리스너만 해제하고 재바인딩1입력1명령을 확인한다.

옵션은 Esc/X닫기, 월드+표시 정지, 겹친 메모/대화의 제한은 유지한다. 수동Retry/Resume버튼/이어하기는 제외하고 사망자동retry는 남긴다. Title 자체에는 제목복귀를 노출하지 않는다. 오프닝·엔딩 중에는 옵션의 제목복귀를 허용하고 컷신을 종료해야 한다. 현재 OptionsService/GameFlowService는 미반영이며 버튼만 바꿔 완료로 판정하지 않는다. 음량은0..1유한/기본1,.7,1·PlayerPrefs이며 기존 저장실패의 런타임값보존/다음저장 재시도를 유지한다.

HUD는HP3/0..5와 Q/E 능력의 해금 전 음영·해금 후 활성 표시, 안내는DialogCode다. Retry는 저장된 해금 마스크를 복원하고 HUD 음영과 스킬 조건을 같은 세션 원본에 바인딩한다. 일반 완료 대화 장부를 재잠금 목적으로 지우지 않는다. CPID/독립Recover/거리Instruction은 제거한다. WorldPrompt한 경로로 통합하고 대상중심 위F를 App출력 방향으로 표시한다. 실제 아트원본은 수정하지 않는다. 화면종료/사망·옵션중첩/저장실패·구독중복을 검증한다.

현행 지침: Inspector 위치/대상은 실물 참조, 수치는 목적·단위가 명확한 값이다. 씬 월드 객체를 관리자 자식에 묶지 않는다. 에이전트 Play 금지는 철회됐으며 공식 Unity 도구로 승인된 검증을 실행한다. 기존 프리팹 삭제/재생성/Apply·자동 Builder 실행은 해당 작업의 명시 허용 범위를 따른다. 이전 실행 관찰 수는 당시 증거이고 이번 통과가 아니다.

V1.8 타이틀은 별도 씬의 실제 3D 배경·오브젝트와 고정 구도 위에 UI를 표시한다. 현재 TitleUiRoot 중심 구성은 미반영이며 컷신 이미지·하단 텍스트 분리는 이미 일치한다.
