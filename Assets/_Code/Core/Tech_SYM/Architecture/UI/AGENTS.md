# 화면과 옵션

## 책임과 경계

ViewModel·View·옵션·음량 설정·페이드와 UI 조립을 소유한다. View가 게임 판정·저장·씬 전환을 직접 실행하지 않는다.

## 유지할 계약

ViewModel은 View를 직접 참조하지 않는다. OptionsService가 자기 차단 토큰을 소유하며 전환이 시작되면 동기적으로 닫는다. SettingsService는 유한한 0~1 값만 받고 저장 실패를 성공으로 숨기지 않는다.

재바인딩은 자기 리스너만 해제한다. 구성 지점에서 서비스를 주입하고 UI 요소의 표시 갱신이 명령을 재발생시키지 않게 한다. 실제 아트 원본은 변경하지 않는다.

## 검증

클릭·단축키 단일 명령, 중복 바인딩·해제 후 이벤트, 옵션 중 재시도·제목 복귀, 저장 실패 후 다음 저장, 실제 해상도별 표시를 확인한다.
