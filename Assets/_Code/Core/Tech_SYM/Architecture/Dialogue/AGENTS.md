# 대화

## 책임과 경계

테이블 검증, 대화 진행·기록·입력 잠금·타이머와 표시 바인딩을 소유한다. 대화가 시작될 안전한 스테이지인지 결정하는 것은 통합 호출자 책임이다.

## 유지할 계약

JSON 전체 검증 뒤 읽기 전용 목록을 게시한다. 같은 프레임에는 한 번만 진행하고 이전 SessionId·RowId의 표시 완료를 무시한다. 로그는 자동 진행을 끄고 표시를 멈춘다.

View는 ViewModel을 사용한다. 옵션·로그 정지와 종료 취소를 타이머 수명에 반영한다. 자기 입력 토큰만 해제하고 직접 월드 상태를 다시 설정하지 않는다.

## 검증

잘못된 JSON·중복 키·행 순서, 현재 문장 완료와 다음 문장 구분, 자동 진행·로그·옵션 조합, 재바인딩·폐기 후 예약 콜백을 검증한다.
