# 오프닝·엔딩

## 책임과 경계

Timeline 재생·프레임 상태·ViewModel·화면 표시를 소유한다. 게임 흐름의 다음 씬 결정이나 세션 체크포인트를 소유하지 않는다.

## 유지할 계약

Prepare → Play → Hide 순서를 지킨다. 취소와 건너뛰기를 구분하고 마지막 프레임은 Hide 전까지 유지한다. 옵션 표시 정지 중 Skip을 실행하지 않는다.

PlayableDirector와 Clip 트윈은 자기 수명에서 해제한다. 이전 revision 콜백은 현재 재생에 영향을 주지 않는다. 아트 원본은 참조하고 가공·배치는 Tech_SYM 자산에서 수행한다.

현재 작업자는 Tech_SYM이며 변경은 승인된 Tech_SYM 범위에 한정한다. Tech_HMS 등 다른 작업자 폴더, 공용 Interfaces, _Art 원본과 그 .meta는 참조 전용이다. 같은 직군의 별도 명시적 파일 허용이 없는 한 수정하지 않는다.

## 검증

잘못된 Timeline, Prepare 실패, 완료·Skip·취소, 중간 Dispose와 재생 재진입, 옵션·페이드 렌더 순서를 실제 출력으로 검증한다.

실행하지 않은 검증을 통과로 기록하지 않는다. Editor의 자산 생성 메뉴와 읽기·검증 메뉴를 구분하며 다른 기능의 씬을 재생성하지 않는다.
