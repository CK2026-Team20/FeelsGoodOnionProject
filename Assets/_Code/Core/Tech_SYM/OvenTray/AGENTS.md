# 오븐 트레이

## 책임과 경계

트레이의 두 종점 이동과 상호작용 수락 상태를 소유한다. 승객 이동은 KinematicPlatformMotion에 맡기며 플레이어·UI 상태를 직접 소유하지 않는다.

## 유지할 계약

Closed·Opening·Open·Closing의 전이를 지키고 이동 중 요청은 false다. 부모 기준 로컬 종점을 월드 좌표로 변환해 이동한다. 비활성화 시 남은 시간을 보존한다.

같은 오브젝트의 Motion·PromptAnchor 계약과 초기 닫힘 좌표를 유지한다. 아트 원본 오븐을 수정하지 않고 소유 프리팹에서 연결한다.

현재 작업자는 Tech_SYM이며 변경은 승인된 Tech_SYM 범위에 한정한다. Tech_HMS 등 다른 작업자 폴더, 공용 Interfaces, _Art 원본과 그 .meta는 참조 전용이다. 같은 직군의 별도 명시적 파일 허용이 없는 한 수정하지 않는다.

## 검증

반복 E, 부모 회전·이동, 중간 비활성화 후 재개, 프롬프트 잠금·복원, 승객 탑승과 종점 Gizmo를 확인한다.

실행하지 않은 검증을 통과로 기록하지 않는다. Editor의 자산 생성 메뉴와 읽기·검증 메뉴를 구분하며 다른 기능의 씬을 재생성하지 않는다.
