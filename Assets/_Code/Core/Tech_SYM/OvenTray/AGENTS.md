# 오븐·트레이·서랍 공통 장치

현재 시스템 기준은 Assets/_Docs/planning-index.md의 V1.8이며 이전 사용자 기능 명세와 기존 구현보다 우선한다. 구현·검증 완료는 tracking/status.md와 실제 증거로 확인한다. 보호 원본·메타·아트의 쓰기 권한은 최신 파일별 허용 범위로 한정한다.

문은 트레이와 독립이며 서랍3개도 각기 독립 상태를 가진다. 이름별 전달자/하위 클래스 대신 같은 두 종점 컨트롤러를 설정 조립한다. OvenHandle의 트레이 위임은 제거한다. F 한 번이 목표 종점까지 작동시키고 키 hold 길이는 이동량을 바꾸지 않는다.

Closed/Opening/Open/Closing 전이, 이동 중 자체 재조작 거절, 실제 closedPose/openPose의 월드 위치·회전 기준, 옵션 시간 정지와 자기 작업 종료를 명시한다. PC 이동/점프는 가능하고 장치 작동과 Interact 표현은 동시에 시작한다. 기존 장치의 이동 중 Busy 수락 규칙을 유지한다. 장치 작동을 이유로 새 전역 F 차단을 추가하지 않는다.

실제 물리 이동은 단일 KinematicPlatformMotion, 탑승 접촉은 PhysicsBody의 Contacts가 맡으며 트레이/서랍은 PC 및 일반 물체를 운반한다. 플레이어/UI 상태를 장치에 복제하지 않는다. 아트 원본을 Apply하지 않고 소유 자산에서 연결한다. 장치 상태는 체크포인트에 저장하지 않는다.

반복 F·다른 대상 F·상호작용 표현·부모 변환·물체 운반·작동 도중 옵션/비활성화·종점/Prompt를 결합 검증한다.

현행 지침: Inspector 위치/대상은 실물 참조, 수치는 목적·단위가 명확한 값이다. 씬 월드 객체를 관리자 자식에 묶지 않는다. 에이전트 Play 금지는 철회됐으며 공식 Unity 도구로 승인된 검증을 실행한다. 기존 프리팹 삭제/재생성/Apply·자동 Builder 실행은 해당 작업의 명시 허용 범위를 따른다. 이전 실행 관찰 수는 당시 증거이고 이번 통과가 아니다.
