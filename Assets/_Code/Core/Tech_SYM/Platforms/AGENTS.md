# 물리 발판

## 책임과 경계

KinematicPlatformMotion·PlatformContacts와 왕복·주기·부유·압력·피해 발판을 소유한다. 플레이어 입력과 폼 판정 원본은 소유하지 않는다.

## 유지할 계약

압력판과 연결 발판의 상호 연결을 유지하고 눌림 진행률 하나를 전달한다. ManualUpdate 트윈을 물리 단계에서 전진시킨다. 비활성화 시 자기 트윈·점유자 상태를 해제한다.

탑승 이동과 시각적 부유를 구분한다. 접촉 대상의 Rigidbody와 HeavyState 경계를 확인하고 HMS 이동 코드를 수정하지 않는다.

LinearShuttlePlatform은 부모 기준 X/Y/Z 도착점 이동량과 초당 월드 이동 속도를 사용한다. 시작 시 경로와 속도를 캡처하고 부모 Transform 변화는 두 끝점에 반영한다. 편도시간은 현재 월드 거리에서 계산하며 끝점 대기 없이 왕복한다. 이동량 0은 정지다. 런타임 중 부모 교체는 지원하지 않는다. 실제 운반은 KinematicPlatformMotion 하나가 담당하며 HMS MovingPlatform을 같은 물체에 중복 연결하지 않는다.

## 검증

사용자용 기능 케이스는 발판 하나의 결합 동작으로 작성한다. 선형 이동 플랫폼은 왕복·탑승·점프와 정지·접촉 해제를 핵심 케이스로 묶고 KinematicPlatformMotion·PlatformContacts 등을 각각 전수 케이스로 분해하지 않는다. 아래 항목은 변경한 기능에 영향을 주는 중요 조건과 기존 회귀 근거이며 실행 환경·QA 인계는 Assets/_Docs/standards.md의 기능 테스트와 QA 인계를 따른다.

복수 점유자, 일부 이탈, 중간 누름·복귀, 승객 이동, 콜백 누락 시 접촉 정리, 비활성화·재활성화와 실제 물리 시간을 검증한다.

피격 발판의 성공한 피해는 대상별 1초 deadline을 보관한다. 넉백으로 잠시 접촉이 없어져도 deadline 이전에는 지우지 않는다. 만료된 비점유자·파괴된 대상·플랫폼 비활성화에서 정리한다. 검증은 실제 피해 이벤트의 피해량/HP/시각과 이탈·재접촉을 관찰한다. 주기 발판은 완전한 phase의5/2/3초를 측정하고 일부 phase 관찰만으로 시간값 통과를 선언하지 않는다.
