# 적

## 책임과 경계

EnemyActor와 상태·Motor·Combat·효과의 조합을 소유한다. 플레이어의 무적·피해 수치 원본은 PlayerFacade가 소유한다.

## 유지할 계약

하강 중 머리 통과 밟기와 몸통 접촉을 구분한다. Damage 반환값이 양수일 때만 접촉 소비·넉백을 적용한다. 기절·사망 상태에서는 몸통 접촉 공격을 막는다.

배치된 센서와 플레이어 Rigidbody 소유자를 함께 확인한다. 죽음 기름 생성과 플레이어 기름 수신 기능은 별도 책임이다. HMS 원본을 수정해 조건을 맞추지 않는다.

현재 작업자는 Tech_SYM이며 변경은 승인된 Tech_SYM 범위에 한정한다. Tech_HMS 등 다른 작업자 폴더, 공용 Interfaces, _Art 원본과 그 .meta는 참조 전용이다. 같은 직군의 별도 명시적 파일 허용이 없는 한 수정하지 않는다.

## 검증

콜백 순서, 복수 Collider, 접촉 이탈·비활성화, 무적 중 접촉, 기절·재기절·사망, 기름 생성 및 수명 종료를 검증한다.

실행하지 않은 검증을 통과로 기록하지 않는다. Editor의 자산 생성 메뉴와 읽기·검증 메뉴를 구분하며 다른 기능의 씬을 재생성하지 않는다.
