# 붕괴·수집 기능

현재 기준은 Assets/_Docs/planning-index.md의 V1.6과 최신 직접 지시다. 구현·검증 완료는 tracking/status.md와 실제 증거로 확인한다. 보호 원본·메타·아트의 쓰기 권한은 최신 파일별 허용 범위로 한정한다.

ShatteredPlatform은 기본 상태 플레이어의 윗면만 판정하며 작은 폼/껍질/옆면/밑면은 발동하지 않는다. 경고1초 종료 즉시 지지 Collider 해제·붕괴 표현, 이탈 취소/자동 복구 없음이다. HeavyState는 압력판 무게에 남고 붕괴의 기본 폼 판정과 같지 않다. 자동 복구 필드/분기와 SYM 붕괴의 IBrokenable 소비는 참조 이관 후 제거했다. 보호 공용 계약이나 다른 소비자를 삭제하지 않는다.

PlatformPresentation은 자기 경고/Animator/Visual을 소유하고 지지 Collider 판정은 로직이 한다. 실제 클립이 없으면 경고와 물리 후처리로 끝내고 실제 재생 성공이라고 쓰지 않는다. 기존 Controller/아트 원본은 참조하며 새 연결은 소유 자산에서 한다. 새 Root 로직/자식 Physics·Visual 참조를 코드와 함께 이관한다.

TearFragment는 LevelTearFragment의 성공 후 소비를 흡수한 단일 수집자다.1개가 실제 추가되면 자신의 Root만 비활성화하고 최대5에서는 남는다. 회전/상하 운동은 수집물 Root 전체에 적용하고 재활성 수명을 맞춘다. 기존 두 소비 정책을 의도된 영구 차이로 남기지 않는다.

검증은 기본/작은/껍질과 접촉 방향·중간 이탈·경고1초 종료·자동 복구 없음·실제/누락 clip, 수집 최대치·중복 Collider/Stay·재활성화를 확인한다. 체크포인트에는 이 기능 상태를 저장하지 않는다. 동일 시도의 자동 복구와 별개로, Stage retry는 기존 조각 객체의 활성·Collider·소비 플래그·표현과 붕괴 발판의 초기 배치를 기능 소유자의 명시적 reset으로 복구한다. 씬 재로드나 월드 저장 등록자를 사용하지 않는다.

현행 지침: Inspector 위치/대상은 실물 참조, 수치는 목적·단위가 명확한 값이다. 씬 월드 객체를 관리자 자식에 묶지 않는다. 에이전트 Play 실행·기존 프리팹 삭제/재생성/Apply·자동 Builder 실행은 금지다. 이전 실행 관찰 수는 당시 증거이고 이번 통과가 아니다.
