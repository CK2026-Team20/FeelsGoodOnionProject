# Tech_SYM 적 시스템

## 씬과 에셋

실제 배치는 기존 `Assets/_Scenes/Tech_SYM/03_InGame.unity`의 `Enemies` 루트 아래에 있습니다.

| 개체 | 시작 위치 | 동작 |
| --- | --- | --- |
| StationaryEnemy | (20, 2.75, 0) | 고정 기준점 + 상하 부유 |
| PatrolEnemy | (45.17, 5.88, 0) | 우상향 3m 왕복 + 추격 |
| OilPatrolEnemy | (94.56, 5.54, 0) | 좌향 3m 왕복 + 추격 + 사망 기름 |

프리팹, SO, 재질은 `Assets/_Scenes/Tech_SYM/Enemies`에서 관리합니다.
외형은 기능 확인용 기본 도형입니다. `Body/Visual`, `EyeLeft`, `EyeRight`를 교체할 수 있으며,
현재 외형에 맞춘 몸통과 머리 Collider도 교체한 외형에 맞춰 조정해야 합니다.
기존 프로젝트 리소스는 수정하거나 대체하지 않았습니다.

## 사용

1. 적 프리팹을 씬에 놓고 `EnemyActor.Target`에 플레이어의 `PlayerFacade`를 연결합니다.
   동적 생성 시에는 `BindTarget(player)`를 호출합니다. 타깃이 없으면 순찰·부유·피해 수신만 동작합니다.
2. `Definition`에서 유형, 초기 체력, 속도, 피해, 초기 IDLE 시간, 부유 진폭/주기를 설정합니다.
   연결된 SO를 선택하여 기본 Inspector에서 편집하며 **동일 SO를 쓰는 모든 적에 적용**됩니다.
   런타임 중 설정 변경을 보장하지 않으며 변경된 설정은 다음 활성화부터 적용합니다.
3. 순찰 방향·거리·반경, 시야각·거리, 지형 레이어, 상하 탐색 거리, 간격, 수동 높이는 개체에서 설정합니다.
   각도는 전체 시야각입니다. 순찰 반경은 최초 기준 위치 중심이며 순찰 거리 이상이어야 합니다.
4. 위아래 플랫폼은 시작 시 탐색합니다. 없는 쪽은 시작 Y에서 수동 거리로 제한합니다.
   플랫폼이 움직여도 이 높이 구간은 갱신하지 않습니다. 현재 지형 관통은 별도의 몸체 구간 검사로 방지합니다.
5. `EnemyOilOnDeath.Spawn Oil On Death`로 기름 생성을 켭니다. 기름 크기·지면 탐색 거리·유지 시간을 설정할 수 있습니다.
   유지 시간 0은 씬 종료까지입니다. 효과 시간은 기름 프리팹의 기존 `OilSurface`에서 설정합니다.
6. 커스텀 Editor와 테스트 버튼은 제거했습니다. 스턴/피해는 `IStunnable.TryStun(int)`와
   `IDamageable.Damage(int)` 계약으로 전달합니다. 기존 커스텀 Inspector의 실행 상태 패널도 제거되었습니다.
   기본 Inspector에는 직렬화된 설정을 표시하며, 실행 상태는 EnemyActor의 공개 조회 속성으로 제공합니다.

## 이동·전투·센서 역할

- `EnemyMotor`: 상태 머신이 지정한 목표를 향해 실제 위치를 이동합니다. XY/Z 고정,
  높이 제한, 지형 관통 방지, 지형 겹침 해소와 부유 오프셋 합성이 책임입니다.
  순찰/추격 여부를 결정하거나 피해·사망을 판정하지 않습니다.
- `EnemyCombat`: 플레이어 접촉당 피해 1회, 무적/스턴 차단, 다중 Collider 중복 억제,
  발과 머리 윗면의 하강 통과 및 밟기 우선순위를 판정합니다. 이동 경로는 결정하지 않습니다.
- `EnemyContactSensor`: 자식 Collider의 Trigger Enter/Stay/Exit를 EnemyActor에 전달합니다.
  전달 경로는 Sensor → Actor.RecordContact → Combat.Record입니다.
  현재 머리 이벤트는 Combat.Record에서 제외되며, 밟기는 머리 Collider의 영역을 직접 비교합니다.
  따라서 몸통 Sensor는 접촉 기록에 쓰이지만 머리 Sensor의 이벤트 전달은 현재 판정에 쓰이지 않습니다.
- `EnemyActor`: 위 기능을 조합하고 공통 인터페이스·초기화·사망/비활성화를 처리합니다.

순찰/시야/높이 기즈모는 별도 Editor 스크립트 없이 `EnemyActor.OnDrawGizmosSelected`에서 표시합니다.

적 및 조상/자식에는 Rigidbody를 두지 않습니다. 물리 루트/Body는 단위 스케일과 월드 축 정렬을 사용합니다.
외형만 자식에서 회전/확대합니다. `Body`는 루트의 직접 자식, `HeadSensor`는 Body 하위의 별도 얇은 Box Trigger입니다.
머리의 윗면은 보이는 몸체 윗면과 일치시키고 가로·깊이는 외형보다 좁게 둡니다.
현재 밟기 판정은 프로젝트 플레이어의 수직 CapsuleCollider와 회전 고정 계약을 사용합니다.

## 계약과 수명

- 기존 `IDamageable`, `IStunnable`을 그대로 사용합니다. 스턴 인자는 **밀리초**이며 반환값은 추가된 시간입니다.
- `TryStun(3000)`을 잔여 1초 상태에서 호출하면 4초가 됩니다. 스턴 동안 두 유형 모두 공격하지 않고 부유는 계속합니다.
- Damage는 실제 체력 감소량을 반환합니다. 밟기는 체력량/무적과 무관한 별도 즉사 처리입니다.
- `Died`는 사망당 한 번 호출된 뒤 적 루트가 비활성화됩니다. 단순 비활성화는 사망 이벤트가 아닙니다.
- 재활성화는 현재 루트 위치를 새 시작점으로 삼고 체력·스턴·접촉·부유를 초기화합니다.
- 순찰 중단 위치에는 부유량을 포함하지 않습니다. 복귀 중에도 시야/범위 조건을 충족하면 재추격합니다.
- 플레이어가 지면에 서서 중심점이 부유 하한보다 낮더라도 충돌체가 허용 높이와 겹치면 추격할 수 있습니다.
  추격 목표는 플레이어 충돌체 중심을 적의 이동 높이 안으로 제한한 점입니다.
- 피해는 접촉당 1회입니다. 무적/스턴으로 차단된 접촉은 해제 후 계속 겹치면 1회 적용합니다.
- 머리와 몸통의 전 물리 단계 정보를 함께 판정하여 유효한 밟기가 몸통 피해에 우선합니다.
  발의 실제 최하단 점이 머리 안쪽을 하강 통과해야 하며, 부유 상승만으로는 밟기가 성립하지 않습니다.
- 타깃은 현재 단일 플레이어입니다. 눈물 발사·입력·소비·쿨다운과 우회 길찾기는 포함하지 않습니다.

## 검증

적의 Editor·Testing 폴더와 제작/검증 메뉴는 포함하지 않습니다.
구현 과정에서 Play Mode로 56개 항목을 검증했습니다. 검증 실행 코드·결과 파일·참고 캡처는 현재 작업본에 포함하지 않습니다.
이 기록은 구현 과정의 검증 이력이며, 이후 조정된 씬 배치를 포함한 자동 재검증 결과를 뜻하지 않습니다.

전체 검증에는 8방향 실제 왕복, 높이/벽/시야 제한, 부유 유지, 스턴 누적, 체력 반환값,
실제 Trigger 중복 억제, 실제 고속 낙하 밟기, 기름 효과/수명/플랫폼 추종이 포함됩니다.
기존 `PlayerFacade`, TECH_HMS의 기름/미끄러짐 기능, 공통 인터페이스는 참조만 합니다.
